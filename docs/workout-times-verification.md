# 실제 운동 시각 기록 — 2026-09-17

## 범위

한국 날짜로 하루 한 운동 구간의 시작·종료를 직접 입력한다. 확인 전에는 저장하지 않으며 저장·수정·삭제를 검토 후 실행한다. 실제 운동 완료·세트·유산소·메모와 분리된 테이블이므로 시각 입력이 완료 기록을 생성하지 않는다. 운동 달력의 선택 날짜와 식단의 날짜 입력에서 사용할 수 있다.

- 같은 날의 시작보다 늦은 종료만 지원한다. 미래 시각, 잘못된 날짜/시각, 자정을 넘는 구간은 거부한다. 표시 분수는 휴식 포함 경과 시간이다.
- 식단은 해당 날짜에 저장된 마지막 식사 시각과 비교한다. 오늘 입력 중인 시각·기본값·저장 시각을 쓰지 않으며 식사 적절성·운동 효과를 판정하지 않는다.
- 계정별 날짜 중복 제한·RLS·열별 최소 권한, 수정/삭제의 revision 일치 조건으로 이후 수정과 삭제 후 재생성 보호. 응답 유실은 GET으로 확인하며 불확실 상태의 재확인은 GET만 실행한다.
- 운동 기록 초기화 표식이 바뀌면 해당 계정의 시각 기록도 정리한다. 식단 초기화는 운동 시각을 지우지 않는다. 기존 초기화 화면의 다른 탭 작업 종료 안내를 유지한다.
- 별도 시각 삭제는 기존 운동/식단 데이터를 변경하지 않는다. 별도 자동 시각 측정·공통 명령 이력·하루 여러 구간은 이번 범위가 아니다.
