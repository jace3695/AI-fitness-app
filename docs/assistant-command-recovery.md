# 6단계 후속 — 확인 대기 할 일 명령 복구

2026-09-15. 대화·빠른 명령에서 받은 할 일 확인 화면을 같은 브라우저 탭의 sessionStorage에 보관한다. 새로고침하거나 두 화면 사이를 이동해도 같은 요청 ID·확정된 날짜·변경 전 스냅샷으로 복구한다. 서버 저장은 여전히 확인 버튼을 눌렀을 때만 실행한다.

- 저장 시도 상태를 브라우저에 먼저 기록한다. 응답 유실 후 새로고침하면 **같은 요청으로 다시 확인**으로 기존 DB의 멱등 처리를 사용한다. 명령을 재해석해 새 요청 번호로 자동 실행하지 않는다.
- 빠른 명령 URL은 한 번 소비하고 주소에서 제거한다. 취소·저장 뒤 새로고침으로 같은 URL을 다시 해석하지 않는다. 다시 실행하려면 직접 입력한다.
- 미확인 요청은 15분 후 저장 버튼을 잠근다. 시도한 요청은 만료 뒤에도 기존 저장 결과를 재확인할 수 있으며, 서버에서 미저장·만료 요청을 새로 실행하지 않는다. 불확실한 요청을 닫을 때는 실행 이력 확인을 안내한다.
- 최대 20개 대기 명령을 보관한다. 공간 초과·브라우저 저장 실패·손상된 복구 자료를 오류로 안내한다. 저장 시도 표시를 보관하지 못하면 실제 저장을 보내지 않는다.
- 현재 로그인 사용자와 보관한 소유자가 같을 때만 표시한다. 저장 전 현재 계정을 다시 대조한다. 인증 변경을 받으면 이전 화면을 비우며, 로그아웃 이벤트를 받으면 이 탭의 임시 내용을 제거한다. 인증 토큰은 이 보관함에 넣지 않는다. 서버의 기존 인증·소유자·초기화·충돌 검사를 유지한다.
- 브라우저 탭의 임시 보관이다. 다른 기기·별도 탭의 대기 요청 공유나 탭 종료 후 영구 복구를 보장하지 않는다. 기록 내용이 브라우저 저장 공간에 있으므로 전용 권한 저장소나 암호화 보관이라고 설명하지 않는다.
