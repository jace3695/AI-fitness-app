# 무료 식단 사진 분석

식단 사진은 `gemini-3.5-flash-lite`를 사용하는 별도 무료 전용 경로로 처리한다. 기존 `OPENAI_API_KEY`, `GEMINI_API_KEY`, 공통 유료 AI 라우터, 비용 예약/확정 함수를 사용하지 않는다. 무료 한도/오류 시 한 번의 요청으로 종료하며 재시도·유료 전환·유료 기능 호출을 자동으로 하지 않는다.

2026-09-13 실제 Preview에서 이전 `gemini-2.5-flash-lite` 요청이 Google `404 NOT_FOUND`로 거절됐다. 이것만으로 모델 전체 종료나 키 오류를 단정하지 않는다. [현재 이미지 입력 지원 모델](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)과 [무료 요금 구간](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite)을 확인하여 전용 모델을 변경했다. Gemini 3에 맞는 `thinkingLevel: minimal`, 출력 상한 768을 사용하고, 잘린 답변은 여전히 거부한다. 자동 모델 탐색·대체·재시도는 추가하지 않았다. 변경 후 실제 Google 판독은 200으로 성공했으며 [호스팅 검증 기록](./free-diet-photo-hosted-verification.md)에 범위와 원본 보존 결과를 정리했다.

## 서버 연결 전 확인

1. [Google AI Studio Projects](https://aistudio.google.com/projects)에서 사용할 프로젝트의 Billing Tier가 **Free**이고 결제 계정이 연결되지 않았음을 확인한다. Google Cloud 무료 체험 크레딧이나 결제 계정에 연결된 Tier 1은 이 확인을 대체하지 않는다. 다른 기능이 사용하는 기존 프로젝트에서 결제를 해제하지 않는다.
2. 해당 프로젝트의 전용 키를 `GEMINI_FREE_API_KEY`라는 서버 전용 Secret으로 등록한다. 값은 채팅·소스·로그·공개 첨부에 넣지 않는다. 기존 유료 키를 복사해 무료로 간주하지 않는다.
3. 1번을 실제로 확인한 후에만 서버 설정 `GEMINI_FREE_TIER_CONFIRMED=true`를 등록한다. 우선 PR **Preview**에만 적용하고 새 Preview를 만든다. 운영 반영은 별도 배포 단계다.
4. `GEMINI_FREE_TIER_CONFIRMED`는 관리자가 확인했다는 표시다. Google의 실시간 결제 상태를 조회하거나 요금을 강제로 0원으로 만드는 기능이 아니다. 무료 프로젝트에 결제를 연결하지 않아야 하며, 향후 결제 상태나 키가 바뀌면 먼저 이 설정을 제거하고 다시 확인한다.

전용 키 또는 확인 설정이 없으면 인증된 사진 요청도 **503**으로 종료하며 외부 AI에는 전송하지 않는다. 두 환경변수는 브라우저에 노출하지 않으며 `NEXT_PUBLIC_` 접두사를 사용하지 않는다.

## 사용자 흐름

- 사진은 기존과 같이 긴 변 최대 1280px JPEG로 압축된다.
- 선택한 사진에 대해 Google 무료 서비스의 데이터 활용 안내를 확인해야 분석을 요청할 수 있다. 서버도 `freeDataUseAcknowledged === true`를 요구한다. 사진을 바꾸거나 지우면 확인 상태가 초기화된다.
- 개인정보가 없는 음식 사진을 사용한다. Google 무료 서비스는 입력·응답을 서비스 개선에 활용하고 담당자가 검토할 수 있다. 앱의 사진 미저장은 제공업체의 데이터 미보관을 의미하지 않는다.
- 무료 한도 도달 시 **429**와 직접 입력 안내를 반환한다. 연결/권한 오류는 **503**, 판단 불가·잘린 답변은 **422**다.
- 결과는 사용자가 수치 확인 후 입력칸에 반영하며, 별도의 식단 저장 버튼을 눌러야 기록된다. 사진은 DB/localStorage에 저장하지 않는다.
- 이미지 전송 중에는 사진 교체·삭제와 식사 종류 변경을 막아 다른 사진/식사에 이전 결과를 적용하지 않게 한다.

## 검증과 범위

- 단위 검사는 전용 키/무료 확인/데이터 활용 확인이 없는 경우 외부 요청 0회, 정확한 Gemini 사진 요청, 오류 시 요청 1회, 유료 키 미사용, 민감한 오류 본문 미노출, 불완전한 추정값 거부를 확인한다. 모든 키·사진·응답은 합성/모의 데이터다.
- CI 실제 앱/Auth/DB 검사는 미설정 경로에서 인증·입력 검증·503 종료와 비용 예약 0건을 검사한다. 320px 브라우저에서 데이터 활용 확인, 사진 재선택, 추정값 검토·저장, 한도 오류 후 입력 유지·사진 정리를 검사한다.
- CI의 성공 추정값과 한도 오류는 **모의 응답**이다. 실제 Google 모델 정확도·계정별 무료 한도·무료 여부가 검증됐다는 뜻이 아니다.
- 실제 호스팅 분석은 Free 프로젝트와 전용 키가 확인된 뒤 합성 사진으로 먼저 검사한다. 테스트 계정의 전체 원본 상태를 실행 전후 대조하고 사진 선택을 정리한다.
- 이 변경은 식단 사진에 한정된다. 언어 회화·필기 평가·다른 앱의 AI·음성 서비스까지 모두 무료로 전환한 것은 아니다.
- 기존 공통 유료 예산 코드의 이미지 토큰 누락 및 예약액을 넘는 실제 비용 확정 제한은 별도 미해결 항목이다. 이번 무료 사진 경로는 그 코드를 통과하지 않는다. DB 마이그레이션을 수행하지 않는다.
