# 식단 28일 기록 비교 검증 — 2026-09-17

## 범위

기존 식단 7일 요약 아래에 최근 28일과 이전 28일의 소화 불편·야식 응답을 비교한다. 오늘은 제외하고 어제까지의 서로 겹치지 않는 기간을 사용한다. 날짜별 근거를 펼칠 수 있다.

- 소화 상태가 편안함·속쓰림·더부룩함·메스꺼움으로 저장된 날만 소화 분모에 포함한다. 편안함 외 세 응답을 소화 불편으로 집계한다.
- 야식의 예·아니요만 야식 분모에 포함한다. 미응답과 잘못된 값은 지표별로 제외한다.
- 각 기간의 해당 지표 응답이 7일 이상일 때만 비율 차이를 %p로 표시한다. 이는 화면의 최소 기록 기준이며 통계적 유의성이나 건강 상태 판정 기준이 아니다.
- 날짜별 목록에는 기간 안의 저장 행을 표시하고 미응답을 명시한다. 기록이 없으면 0%로 표시하지 않는다.
- 원인 추정·식단 계획 변경·AI 호출·DB 구조나 저장 경로 변경이 없다. 입력 중인 오늘 값은 비교에 반영하지 않는다.
