# AI 연이 앱 전체 개선 — 구현 및 검증 기록

작성: 2026-09-09 KST

작업 브랜치: `fix/app-wide-reliability`

기준 운영 커밋: `902cd27579892a56ca68caceb6419f43b709b24b`

## 현재 상태

- 앱 전체 검토에서 재현한 저장·동기화 문제 4건과 관련 입력·조회·공통 사용성을 개선했다.
- 자동 검사 196개, 린트, TypeScript 검사, 프로덕션 빌드가 통과했다.
- 새 SQL은 격리된 PGlite PostgreSQL에서 실행하여 트랜잭션·재시도·계정별 접근 제한을 확인했다. 운영 Supabase에 적용한 결과가 아니다.
- 운영 DB 마이그레이션, 운영 병합·배포는 실행하지 않았다. 새 RPC를 사용하는 가계부 묶음 저장·반복 할 일 완료·성장 코칭 적용은 DB 반영 전에는 미리보기에서도 완료되지 않는다.
- 브라우저 연결은 정상이며 현재 로그인 화면이 표시된다. 새 코드의 인증 후 저장·재조회·좁은 화면 검증은 아직 완료하지 않았다.
- 이번 작업에서 개인 기록을 수정하거나 합성 기록을 운영 DB에 추가하지 않았다.

## DB 변경 준비

마이그레이션: `supabase/migrations/20260908223431_app_wide_reliability.sql`

추가 항목:

1. 가계부 요청 결과를 식별하는 `budget_save_batches` 및 소유자 RLS.
2. `save_budget_batch(uuid, jsonb)`.
3. 반복 항목의 부모 식별자, 중복 방지 인덱스, 동일 소유자 외래 키.
4. `set_assistant_item_completion(uuid, boolean, timestamptz)`.
5. `decide_growth_review(uuid, jsonb, jsonb)`.

함수는 `SECURITY INVOKER`, 빈 `search_path`, 로그인·소유자 검사를 사용한다. 공개·익명 실행 권한을 제거하고 로그인한 계정에만 실행 권한을 부여한다. 기존 기록의 수정·삭제·중복 정리는 포함하지 않는다.

운영 프로젝트의 읽기 전용 보안 점검에서는 기존의 유출 비밀번호 보호 비활성화 경고 1건이 확인됐다. 이 작업에서 인증 설정을 변경하지 않았다.

## 새 코드 실검증 대기 항목

검증 브라우저에서 허가된 계정으로 로그인하고 DB 변경을 테스트할 환경이 준비된 뒤 다음을 확인한다. `AGENTS.md`에 따라 로그인 화면만 확인한 것을 기록·저장 검증으로 처리하지 않으며, 이 단계 전에는 운영 병합·배포를 하지 않는다.

1. 가계부 혼합 내역 저장, 오류 후 재시도, 저장 확인 중 새로고침, 삭제 취소·확정.
2. 반복 할 일 완료·재클릭·다음 회차 재조회와 성장 코칭 적용·보류·오래된 루틴 충돌.
3. 동기화 응답 중 새 입력 보존, 이어지는 원격 반영, 독립 세션 재조회, 기존 45세트 회귀 확인.
4. 운동 미응답 저장·수정, 허리 증상과 제안 보류, 식단 실패 후 작성 내용 보존.
5. 홈·캘린더의 조회 오류·마지막 값·복귀 갱신, 작성 중 새로고침 보류.
6. 320px/390px에서 하단 안내·메뉴, 대화상자 키보드 초점과 취소, 타이머의 화면 복귀.
7. 허가된 합성 데이터만 사용하고 종료 시 제거한 뒤 시작 전 원본·설정과 대조.
