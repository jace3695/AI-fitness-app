### 합성 데이터 정리와 원본 보존

- 운동 기록 전체와 운동 설정의 전후 해시가 각각 동일했다. 테스트 날짜 운동 값은 제거됐고 기존 4일의 기록은 그대로였다.
- 테스트 날짜의 식단·수분 값이 제거됐다. 전체 클라우드 JSON이 바이트 단위로 같다는 주장은 하지 않는다. 앱의 빈 저장소 초기화 항목은 생길 수 있다.
- 가계부 합성 지출·수입·저축 각 0건. 확인된 테스트 요청 결과 1건도 정확한 식별자로 제거해 0건이다.
- 비서 할 일은 시작 전과 동일한 0건이다.
- 합성 성장 루틴 2개와 코칭 1개를 정확한 식별자로 제거했다. 원본 루틴 2개의 전체 값 해시가 시작 전과 같고 코칭은 0건이다.
- 테스트 오류를 만들기 위한 새 실패 제약이나 인증 설정 변경은 운영 DB에 추가하지 않았다.

### 후속 수정 및 남은 실검증

- 후속 미리보기에서 운동 화면 진입만으로 동기화되는지, 가계부 오늘 날짜와 지출 상세 삭제 확인·취소, 비서 대화 반복 완료를 확인할 예정이다.
- 이번 브라우저가 제공하는 실제 화면은 1359×936이다. 홈에서 가로 넘침이 없음을 확인했으나 320px/390px을 실제 시험한 결과가 아니다.
- 독립 세션 동기화 경합·요청 중 새 입력 보존·전체 요청별 네트워크 대조, 저장 결과 불명확 상태에서 새로고침, 조회 오류·복귀 갱신, 타이머 백그라운드 복귀 및 PWA 업데이트 보류의 전체 실제 조작은 남아 있다. 관련 단위·SQL 테스트 통과와 구분한다.
- `AGENTS.md`의 작은 화면·핵심 흐름 검증 요구에 따라 PR은 draft로 유지하고 운영 앱 병합·배포는 하지 않는다.
