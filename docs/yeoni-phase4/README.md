# PHASE 4 — 고양이 연이 기본 애니메이션 PoC

작성일: 2026-09-29 (한국시간)

## 구현한 내용

공식 고양이 연이의 흰 몸·보라색 귀와 꼬리·민트 네 갈래 별을 유지한 분리 자산을 만들고, Canvas에서 눈 깜빡임·미세 숨쉬기·꼬리 흔들기를 구현했다. 기존 운영 스프라이트는 교체하지 않았다. 인간형은 선택한 A안 그대로 유지하며 이번 단계에서 추가 제작하지 않았다.

새 컴포넌트는 독립 검증 화면에서만 사용한다. 앱 운영 페이지·메뉴·계정·기록·음성 API에 연결하지 않았다. 새 런타임 패키지와 DB 변경은 없다.

- 최대 30fps 이내로 그리기. 프레임마다 React 상태를 갱신하지 않음.
- 기존 표시/움직임 설정 재사용. 기본 `reactions` 설정에서는 대기 반복을 켜지 않음.
- 입력 중, 모달 표시, 화면 밖, 문서 숨김, 동작 줄이기, 사용자 정지에 반응.
- 재개 시 밀린 동작을 몰아 재생하지 않음.
- 자산 로드 실패·Canvas 사용 불가 시 기존 고양이 정지 이미지와 안내 유지.
- 언마운트 시 프레임·이벤트·관찰자 정리.

## 발견·수정한 문제와 한계

1. 생성된 자산은 요청한 균일 격자를 따르지 않았다. 실제 파츠 영역을 측정해 소스 좌표를 정했다.
2. 가장자리의 떨어진 잔상을 이미지 편집으로 줄였다. 작은 밝은/어두운 화면은 확인했지만 원본 확대 크기의 미세 경계는 최종 자산 제작 때 보완해야 한다.
3. 검증용 번들이 린트에 잡히는 문제를 기존 생성물 전용 경로로 이동해 해결했다. 소스 린트 규칙은 약화하지 않았다.
4. 로컬 WebKit 시스템 라이브러리 설치는 환경 권한 제한으로 실패했다. 독립 GitHub Actions에서 검증하도록 구성했다.
5. 첫 WebKit 실행에서 지연된 초기 ResizeObserver가 정지 상태의 동일 크기 이미지를 다시 그리는 현상을 발견했다. 첫 그리기 전에 크기를 정하고 실제 크기 변화에만 다시 그리도록 수정했다. 검사 기준은 완화하지 않았다.
6. 현재 몸 파츠에 코·입·귀가 고정되어 있다. PHASE 4에 필요한 눈/꼬리 분리를 검증한 것이며, 전체 리깅·말하기 자산은 아직 아니다.

## 다음 단계

PHASE 5는 **고양이 한국어 립싱크 PoC**다. 먼저 실제 발화문·음성과 입모양 타임라인을 맞추는 방법을 검증한다. 현재 Google Zephyr 응답에 음소 타이밍이 없으므로, 임의 입 벌리기나 글자별 균등 배분을 정확한 립싱크로 처리하지 않는다. 새로운 유료 서비스 도입이나 운영 반영은 별도 승인 없이 진행하지 않는다.
