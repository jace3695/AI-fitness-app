## 사용할 수 있도록 준비한 화면

- 가계부 AI 상담의 답변 읽기를 공통 Zephyr 재생에 연결했다. 기존 자동 읽기 토글과 자동 호출을 제거했다.
- 비서 대화의 답변, Siri 빠른 명령 결과, 네 분야 무료 조언, 저장된 ChatGPT 조언에 같은 버튼을 추가했다.
- 화면을 열거나 답변이 도착하는 것만으로 음성 API를 호출하지 않는다. `speak=1` 주소도 음성을 자동 생성하지 않는다.
- 버튼 옆에 읽을 문자수와 Google 전송 안내를 표시한다. URL과 마크다운 표시를 정리하고, 1,200자를 넘는 답변은 앞부분만 읽는다고 안내한다.
- 버튼 클릭 → 로그인 계정 확인 → 서버 한도 조회 → 요청 번호 보관 → 서버 문자수 예약 → 음성 생성 → 브라우저 재생 순서다.

## 중복 호출과 재생 처리

- 같은 계정·월·정리된 답변의 동시 요청은 한 번의 생성으로 합친다. 받은 음성은 메모리에 최대 8개 보관하고, 재생 중지·재생 완료·다시 재생을 구분한다.
- 재생이 브라우저 정책으로 막히면 받은 음성의 재생 버튼을 안내한다. 다시 재생할 때 추가 TTS 호출을 하지 않는다.
- 생성 전 보관하는 시도 기록은 계정/월/문장의 SHA-256과 요청 UUID만 포함한다. 문장과 음성은 브라우저 영구 저장소에 보관하지 않는다.
- 같은 탭에서 새로고침으로 오디오를 잃거나 응답이 유실되면 같은 답변을 다시 생성하지 않는다. 한도 확인에서 차단된 요청은 음성 생성 시도로 기록하지 않아 나중에 상태를 다시 확인할 수 있다.
- 시도 기록은 `sessionStorage` 범위다. 새 탭·다른 기기·탭 종료 이후의 동일 문장까지 전역으로 금지하는 기능은 아니다. 서버의 요청 번호 중복 금지와 앱 전체 월/일/속도 한도는 계속 적용된다.
- 문장이 바뀌거나 화면을 떠나거나 계정이 바뀌면 이전 음성의 재생을 중단한다. 늦게 도착한 이전 응답을 자동 재생하지 않는다. 다른 답변을 재생하면 앞서 재생 중인 음성을 멈춘다.
- 기기 음성이나 다른 유료 모델로 자동 전환하지 않는다. 실패한 Google 요청의 예약 문자수는 기존 정책대로 돌려주지 않는다.
