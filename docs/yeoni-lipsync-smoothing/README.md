# 연이 입 전환 보완 — 정상 속도 A/B 검토본

2026-10-01. 기준 `cee57128dbc37298b2aa5657b2b5b57c91fe0c53`.
사용자가 올린 실제 재생 영상에서 입이 글자마다 급하게 교체되는 느낌을 지적했다.
기존 39자 Zephyr MP3, 60개 자동 정렬 음소, 고양이 v3/인간형 v4 외형을 그대로 사용한다.

## 확인 방법

`Yeoni_Smooth_Mouth_Preview.html`을 내려받아 Chrome 또는 Edge로 연다.
ChatGPT 파일 뷰어에서는 HTML 소스가 표시될 수 있다.
‘저장된 연이 음성 불러오기’ → ‘재생’ 후 ‘부드러운 전환’과 ‘기존 전환’을 비교한다.
버튼을 바꿔도 같은 오디오와 재생 위치가 이어진다. 자연스러움은 정상 속도에서 먼저 확인하고,
‘조금 쉬는’·‘좋겠어요’ 구간과 0.5배속은 세부 경계 확인에 사용한다.

## 변경

- 원래 음소 투영 `viseme`와 표시용 `mouth(from/to/mix)`를 분리했다.
- 짧은 비입술 자음마다 작은 입으로 돌아가던 동작을 앞뒤 모음의 연속 전환으로 연결했다.
- 30ms 미만 활음은 독립적인 최대 입 모양을 강제하지 않는다. 음소 기록 자체는 그대로 둔다.
- 모음 내부 기준점과 최대 60ms 가장자리 구간에 부드러운 곡선을 적용한다.
  모든 측정된 무음과 ㅁ·ㅂ 계열의 폐쇄 구간은 완전히 닫힌 상태를 유지한다.
- 입꼬리·입술 외곽·안쪽 경계를 같은 중간 형태로 변형한 뒤 색을 보간한다.
  단순 반투명 겹치기로 생기던 이중 윤곽을 줄인다. 고양이는 닫힌 W형 입에 존재하지 않는
  구강 내부를 흰 털로 늘리지 않도록 기존 열린 입 텍스처를 수축하며, 코 윗부분을 고정한다.
- 얼굴·목·몸통 변형 및 원본 이미지 파일은 바꾸지 않는다. 이전 HTML도 보존한다.

## 검증과 한계

- 실제 Chromium 153.0.8010.12 / WebKit 26.6에서 신규 흐름 각 10개 및 공통 렌더러 계약 각 3개, **26개 통과**.
- 정지 입 8개 × 눈 3개 × 외형 2개, 48개 조합이 기준 커밋 렌더러와 동일하다(브라우저별 확인).
- 중간 입 보간 외부의 픽셀 변화 0, 끝 모양 불일치 0, 불투명 입 영역 유지 및 정지 원본 복귀 확인.
- 실제 MP3의 재생 시각으로 두 캔버스의 표시 곡선을 대조했다. 배속·탐색·정지·숨김·외형 해제/복귀와
  320/390/1280px 화면, 외부 요청 0건, 실행 오류 0건을 확인했다.
- 고정 30fps 입 영역의 프레임 차이 95백분위는 고양이 약 23.6%, 인간형 약 42.5% 감소했다.
  이는 픽셀 변화량 지표이며, 그 비율만큼 자연스러움이 좋아졌다는 뜻이 아니다.
- 코드 703개, lint·빌드·타입 검사 통과. 상세 수치는 `evidence/verification.json`.
- 기존 자산·MP3·영상·HTML·검증 JSON 277개의 해시를 보존했다. 이전 원본 비교/영상 검사 61개는 재실행하지 않았다.

원래 자동 음소 정렬의 경계 정확도, 새 보간의 청취 자연스러움, 물리 iPhone/Bluetooth 지연·발열은
최종 확인되지 않았다. 데스크톱 WebKit은 물리 Safari 검증을 대신하지 않는다.
기술 진도는 **9/16**을 유지한다. 이번 보완을 PHASE 5 또는 PHASE 11 완료로 집계하지 않는다.
PR #207은 Draft이며 운영 병합·배포는 진행하지 않는다.
