# 남은 WebKit 검증 2건 — 2026-09-19

기준 코드 `27a40ee3a6b920027d53cd36575d88ed84732e0f`의 CI 35434259594는 214/216이었다. 메뉴 겹침 4/4는 통과했지만 아래 두 실패가 남았다.

- 성장 조회 실패/복구: `/growth` 이동의 `load` 대기 중 WebKit 내부 오류. 조회 장애 주입 이전이었다. DOM 로딩 후 기존 화면·오류·재조회 결과를 검증하도록 대기 기준을 조정한다. 브라우저 내부 오류의 근본 원인을 확정한 것은 아니다.
- 실제 운동 시각: 최초 `20:00 ~ 20:40` 확인 영역을 찾지 못했다. 당시 입력값 로그가 없어 앱 검증 실패와 입력 도구/조회 경합을 단정할 수 없다. 날짜 입력을 확정하고 해당 날짜 GET 응답과 입력 활성화를 확인한 뒤 시간을 입력한다. 실패 시 합성 날짜·시작/종료·안내 문구만 기록한다.

두 시나리오를 WebKit에서 각각 3회 실행하는 CI 단계를 전체 브라우저 검사 앞에 둔다. 로그인·계정 보존 의존성, 오류/재조회·실제 저장·수정·삭제·원본 비교, 전체 검사, 실패 판정과 정리는 유지한다. 자동 재시도와 시간 제한 완화는 추가하지 않는다.

앱·DB·권한은 변경하지 않았다. 타입·변경 파일 린트 통과. 반복/전체 CI 및 호스팅 결과는 PR #189에 기록하며, 확인 전 성공이나 운영 배포로 표시하지 않는다.
