# 루틴 시작 시간대별 패턴 — 2026-09-17

7단계 개인화의 후속 범위다. 자기계발 → 주간 코칭에서 선택한 루틴의 어제까지 최근 28일 기록을 실제 시작 시각으로 비교한다. 기존 요일별·운동 기록별 비교를 유지한다.

## 집계 기준

- 시작 시각 `started_at`만 한국 시간(UTC+09:00)으로 바꿔 새벽 00:00~05:59, 오전 06:00~11:59, 오후 12:00~17:59, 저녁 18:00~23:59로 구분한다. 생성·수정·종료 시각이나 목표/실제 수행 시간으로 시작을 역산하지 않는다.
- 최근 28일·선택 루틴·유효 날짜·완료 > 진행 > 중단의 하루 우선순위는 기존 요일별 집계를 재사용한다. 같은 날 같은 우선순위의 기록들이 한 시간대에 모일 때만 하루로 센다. 낮은 우선순위 기록의 시각을 빌려 쓰지 않는다.
- 시작 시각 미기록, 잘못된 시각/종료 역전, 한국 시간의 시작 날짜와 기록 날짜 불일치, 같은 우선순위의 여러 시간대가 겹친 날은 비교에서 제외하고 근거 표에 이유를 표시한다. 자정을 넘긴 기록이나 여행지의 과거 시간대를 추정하지 않는다. 기록 자체는 그대로 보존한다.
- 각 시간대에 서로 다른 기록일이 4일 이상 있고 그런 시간대가 두 개 이상일 때만 완료 비율을 비교한다. 가장 높은 비율과 낮은 비율의 차이가 25%p 이상일 때 일정 검토 문구를 표시한다. 표본 부족과 기록 없는 날을 실패로 추정하지 않고 시간대의 인과관계·피로·건강 효과를 주장하지 않는다.
- 시작 시각이 여러 개지만 같은 시간대라면 가장 이른 시각과 다른 고유 시각 수를 표시한다. 날짜별 근거에는 시간대·시각 또는 제외 이유와 루틴 상태가 함께 나온다.
- 기존 인증된 세션 조회 결과만 사용한다. DB 구조·저장 함수·설정·AI/TTS·추가 API 요청 변경은 없다. 기존 조회 오류·1,000건 이상 불완전한 조회 때 패턴을 표시하지 않는 기준을 유지한다.
