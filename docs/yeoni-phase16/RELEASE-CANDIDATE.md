# 연이 실제 비서 화면 운영 적용 후보

2026-10-07 23:06 KST의 다음 단계 요청에 따라 준비했다. iPhone의 새 배치 확인은 완료했다. **이번 후보 준비까지는 Preview 작업이며 main 병합·운영 설정 변경·운영 배포는 별도 승인 대상이다.** PHASE 16은 운영 적용 전 상태로 유지한다.

## 제공 기능과 범위

- 실제 `/assistant`에서 고양이형·인간형 전환, 움직임 설정과 캐릭터 숨기기를 사용한다.
- 채팅·무료 조언의 최종 문장에 규칙 기반 표정/몸짓 계획을 연결한다. 기존 대화 저장·기록 변경 확인·조언 동의를 유지한다.
- 검증된 저장 한국어/선택 일본어 음성과 문장·언어·voice가 모두 일치하는 답변에만 해당 음성과 립싱크를 연결한다. 새 답변은 글로 표시하고 기존 수동 답변 읽기를 유지한다. 일반 답변의 자동 TTS·자동 음소 정렬은 이번 제공 범위가 아니다.
- 캐릭터와 답변 읽기의 동시 재생을 막고, 화면 이동/숨김/새 요청 뒤 늦게 준비된 음성의 자동 재생을 방지한다. 복원된 대화는 자동 재생하지 않는다.
- 원본 그림, 두 음성 파일, 정렬 타임라인을 유지한다. 새 TTS나 정렬 공급자 호출을 추가하지 않는다.

## 운영 연결과 중지

`lib/yeoni/assistant-feature.ts`는 실제 비서 화면에만 쓰인다. 검수 화면의 `characterReplyEnabled`와 분리했다.

| 환경/설정 | 실제 `/assistant` 캐릭터 | 검수 화면 |
| --- | --- | --- |
| 승인된 작업 브랜치 Preview, 설정 없음 | 켜짐 | 기존 Preview 제한 유지 |
| 다른 Preview/개발 환경 | 꺼짐 | 기존 제한 유지 |
| Production, 설정 없음/잘못된 값 | 꺼짐 | 차단 |
| Production, `YEONI_ASSISTANT_CHARACTER_ENABLED=1` | 켜짐 | 차단 |
| `YEONI_ASSISTANT_CHARACTER_ENABLED=0` | 꺼짐 | 기존 제한 유지 |

이 값은 비밀이 아닌 서버용 Config이며 운영에만 `1`을 설정하는 것을 제안한다. 아직 Vercel 설정에 추가하지 않았다. `/assistant`는 빌드 시 정적으로 생성되므로 **설정 변경 후 새 배포가 필요하며 즉시 전환되는 스위치가 아니다.** 꺼지면 기존 AppCompanion 화면으로 돌아간다.

## 승인 후 적용 순서

1. 승인할 후보 SHA, main 기준과 현재 운영 배포를 다시 대조한다. main이 변했으면 차이를 확인하고 후보를 다시 검증한다.
2. Vercel 프로젝트 `prj_UDkVoWjM3D1EMRJk9hcBaFvq2sj3`, 팀 `team_infdz4ulqNZRy7vk5BTGUXmt`의 Production에만 `YEONI_ASSISTANT_CHARACTER_ENABLED=1` Config를 설정한다. 기존 배포 자체는 이 설정만으로 바뀌지 않는다.
3. 후보 SHA의 필수 검사 충족을 확인하고 PR #207의 해당 head를 main에 병합한다. 이 main push가 Vercel의 운영 배포를 시작한다. 따라서 이 병합은 운영 배포 승인 후에만 한다. 검수 전용 화면/API는 계속 차단한다.
4. 자동 생성된 운영 배포의 commit/main/project/READY 상태와 도메인 연결을 대조한다. 실제 운영 주소에서 로그인·캐릭터 표시·응답·기록 보존·오류 상태를 확인한다. 저장을 포함한 점검은 허가된 테스트 데이터로만 수행한다. 실패하면 아래 기준 배포로 복구한다. 결과/배포 식별자를 기록하고 PHASE 16 완료 여부를 확정한다.

이번 승인 요청의 범위는 위 **Production Config 추가 + 지정 head의 main 병합 + 자동 운영 배포 확인 + 필요 시 직전 운영 복구**다. 기존 Preview와 별개로 운영 환경의 실제 브라우저 확인은 배포 후 수행한다. Preview를 그대로 production에 promote하는 절차로 대체하지 않는다.

## 복구 대상

현재 운영 기준은 `dpl_CA5xqJa7drXgTBqZt136qMcDQmL2` (main `a7e2c69`, READY)다. 승인 후 적용 직전에 이 값이 여전히 현재 운영인지 재확인한다.

- 캐릭터만 중지: Config를 `0`으로 바꾸고 같은 코드로 새 운영 배포를 만든다. 기존 대화/기록은 보존된다.
- 배포 전체 복구: 검증된 이전 운영 배포로 rollback한다. 사용자 기록 DB를 되돌리거나 삭제하지 않는다.
- 복구 뒤 로그인·기존 비서 화면을 확인한다. Vercel rollback 후 다음 배포의 자동 도메인 연결 상태도 확인한다.

현재 운영 설정/도메인/DB에는 이번 작업을 적용하지 않았다.
