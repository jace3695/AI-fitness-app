## 다음 구현 범위

1. 기존 `/assistant` 대화 영역에 검수한 공통 캐릭터 패널을 연결한다. 우선 작업 브랜치 Preview에서 확인 가능한 형태로 구성한다.
2. 일반 채팅과 무료 조언의 **최종 문장**을 기존 발화 계획과 함께 전달한다.
   조언은 저장용 설명 문구와 실제 `adviceSpokenText`를 혼동하지 않게 한다. 대화 이력·조언 동의·기록 변경 확인 흐름을 유지한다.
3. 새 답변/요청 시작, 취소, 화면 이동, 새로고침 시 이전 음성과 계획을 정리한다.
   이력 복원으로 자동 재생하지 않으며, 캐릭터 전환 중 같은 오디오/Controller를 유지한다.
4. 기존 메시지 읽기 버튼과 캐릭터 음성의 동시 재생을 방지한다. 일반 TTS 음성에 정렬이 없으면 임의 입 움직임을 붙이지 않는다.
   저장 표본과 일치하지 않는 새 문장은 현재 범위에서 글 전용이다. 임의 새 문장 립싱크는 별도 TTS·정렬 기능이다.
5. 실제 대화 화면 연결에 따라 달라진 흐름만 검증한다. 새로고침, 다른 답변 도착, 오류 안내, 작은 화면,
   기존 이력/저장 기능 보존을 확인한다. 이미 확인한 원본 외형·두 구간 청취·10분 사용을 처음부터 반복하지 않는다.
6. 변경 커밋·Preview 결과·최종 제공 기능·제한·복구 대상을 갖춘 운영 후보를 준비한다.
   현재까지의 Preview push 승인은 포괄 운영 승인이 아니다. 구체적인 후보를 검증한 뒤 최종 운영 적용 승인 단계로 간다.

## 유지할 검증 범위

- 기존 한국어·사용자 선택 일본어 음성 유지. 이번 ‘확인 완료’는 바로 앞의 한국어 두 구간 검토를 뜻한다.
- 자동 정렬 원본은 보존하고 사용자 수용 결과를 별도로 기록한다. 전문가 수동 경계 인증으로 바꾸지 않는다.
- 새 TTS/유료 호출/정렬 공급자 호출 없음. 개인정보·기록 조회/쓰기는 이번 준비 작업에 수행하지 않았다.
- 기존 자동 브라우저 환경 문제와 클라우드 인증 통신 오류의 해결 여부는 아직 새로 확인하지 않았다.
  새 실제 화면 검증을 실행하기 전에 사용할 수 있는 브라우저 경로를 확인하고, 차단되면 정확한 미검증 범위를 남긴다.
- 운영 승인 전의 기준 배포는 위 main/production이다. 나중에 적용할 때 현재 운영 대상과 후보를 다시 확인한다.
- 기존 dirty 파일 `docs/yeoni-phase9/Yeoni_Human_Speech_Preview.html`은 이번 작업에 포함하지 않는다.
