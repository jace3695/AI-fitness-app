# PHASE 14/15 — 기기·성능 검증

2026-10-04: PHASE 13 답변 연결 PoC 사용자 확인 완료. 전체 12/16(1~4·6~13). 이 문서는 후속 검증 준비이며 기기·성능 단계 통과 기록이 아니다.

## 재사용할 기준

- 기존 한국어 `ko-KR-Chirp3-HD-Zephyr`, 사용자 선택 일본어 `gemini-3.8-flash-tts/Zephyr`, 기존 음소 타임라인과 고양이/인간 원본을 유지한다.
- 기술 음성 검토본 `Yeoni_Reply_Character_Preview.html`은 두 음성이 내장된 저장 표본이다. 파일 식별자는 `../yeoni-phase13/delivery.json`에 있다. 기기에서 실제 스크립트·오디오 실행이 가능한지 먼저 확인한다. iPhone 파일 미리보기에서 열린 것만으로 Safari 웹앱 실행을 통과 처리하지 않는다.
- 배포된 `/assistant/character-check`는 실제 AI 답변 검수용이다. 임의의 새 답변은 글로만 표시되므로 해당 화면으로 저장 표본 오디오 검수를 대신하지 않는다. `?mode=device`에서 기존 음성 2개를 선택하는 기기 검수 모드를 추가했다. 같은 Preview 분기 제한·기존 로그인 레이아웃을 유지하며 새 AI/TTS를 요청하지 않는다.
- PHASE 13에서 통과한 데스크톱 검사와 새 기기 검증을 분리하고, 기존 검사를 처음부터 반복하지 않는다. 새 AI·TTS 생성은 필요하지 않다.

| 순서 | 확인할 동작 | 통과 기준 | 현재 상태 |

| 2 | 저장 한국어/일본어 표본을 직접 재생 | 자동 재생 없음, 선택한 파일 재생, 입 모양과 음성이 자연스럽게 연결 | 미검수 |
| 3 | 재생 중 고양이/인간형 전환 | 음성이 중복·재시작되지 않고 진행 시각 유지 | 미검수 |
| 4 | 일시정지·끝·다시 재생 | 멈춤/끝에는 입이 닫히고 명시적 조작으로만 재개 | 미검수 |
| 5 | 다른 앱으로 전환·화면 잠금·복귀 | 복귀 시 자동 발화 없음, 이전 몸짓 재실행 없음 | 미검수 |
| 6 | 움직임 줄이기·스크롤로 화면 밖 이동 | 불필요한 움직임이 멈추고 복귀 정책 유지 | 미검수 |

처음에는 1~4의 짧은 확인부터 진행하고, 통과 후 5~8로 이어간다. 한 번에 전체 검수를 사용자에게 요구하지 않는다.

## 결과를 기록할 때

- 기기 모델, iOS/Safari 버전, 확인한 파일 또는 배포 버전, 사용한 외형/언어, 출력 장치, 실제 확인 시각을 기록한다.
- 화면 녹화로 보이는 상태, 사용자가 청취한 자연스러움, 개발자 측 시간·루프 측정을 구분한다. 정지 화면으로 소리·발열·프레임 유지율을 통과 처리하지 않는다.
- 문제가 있으면 해당 전환만 재현·보완하고 영향을 받는 검증만 반복한다. 음성/정렬/원본 변경을 기본 해결책으로 삼지 않는다.
- PHASE 5의 상세 음소 경계와 표본 밖 발음 검토, PHASE 16 운영 적용 승인은 별도로 남긴다.

## 2026-10-04 후속 구현

- 기존 경로에 `?mode=device`를 붙이면 `DeviceCheck`를 표시한다. 선택 → 움직임 켜기 → 답변 듣기 순서이며 한국어/일본어 선택은 저장 문장과 기존 파일만 공통 `ReplyCharacterPanel`에 전달한다.
- 원래 AI 답변 검수 화면에 기기 검수 링크를 추가했다. 쿼리가 없으면 기존 기능을 유지한다.
- 실제 음성 파일·정렬·외형·플레이어·인증 레이아웃은 수정하지 않았다. 음성 해시와 서버 빌드 추적에 두 파일 포함을 확인했다.
- 새 변경의 타입·대상 린트·프로덕션 빌드 통과. 이전 Turbopack 캐시 손상은 캐시를 별도 임시 폴더로 옮겨 해결했다.
- **새 브라우저 검증은 미통과/차단 상태**다. 기존 실행 파일이 잘려 Chromium 시작이 실패했고, 표준 Playwright 설치 주소가 ZIP 대신 `Site Unavailable` HTML을 반환했다. 실행한 검사가 성공한 것으로 집계하지 않는다. 인증 우회나 대체 네트워크 경로를 사용하지 않았다.
- `scripts/yeoni-reply/check-device.mjs`는 실제 컴포넌트·앱 CSS로 음성 해시, 선택/전환/정지/새로고침, 320·390·844px 레이아웃을 확인하도록 준비했다. 실제 로그인/물리 iPhone 검증과는 별도다.
- 상세 결과는 `evidence/verification.json`, 빌드 출력은 `evidence/build.txt`다. 전체 완료는 계속 **12/16(75%)**, iPhone·성능 통과 판정은 보류한다.

### iPhone 첫 확인

1. Preview의 `/assistant/character-check?mode=device`를 Safari로 열고 필요하면 기존 계정으로 로그인한다.
2. `한국어 음성 선택` → 필요하면 `움직임 켜기` → `답변 듣기`, 이어서 일본어도 같은 방법으로 확인한다.
3. 재생 중 `인간형`/`고양이형` 전환, `일시정지` 후 입 닫힘, 가로 전환 시 버튼 잘림만 먼저 확인한다.

처음 결과를 받은 뒤 잠금·복귀·출력 지연·발열 검증으로 넘어간다. 이전 인간형 답변 유지·새로고침 확인을 다시 요구하지 않는다.
