# 다음 실제 음성 검증 범위

제안 문장: `こんにちは。今日は、ゆっくり一歩ずつ進みましょう。`

- 언어/음성: ja-JP / ja-JP-Chirp3-HD-Zephyr, MP3, 기본 정상 속도.
- 새 생성 범위: 이 정확한 문장 1회만. 실패 시 자동 재시도·다른 문장·다른 음성 생성 없음.
- 목적: 모음, 양순음, 비음, 촉음, 장음 및 쉼이 포함된 짧은 실제 발화 검토. 한 문장으로 모든 일본어 발음을 검증했다고 보고하지 않는다.
- 요청 전 기존 TTS 연결의 사용 가능 여부와 일회성 허용 범위를 확인한다. 현재 일본어 API 요청·비밀 키 조회·과금은 수행하지 않았다.
- 확보한 MP3와 실제 보낸 UTF-8 문장을 고정하고 해시 기록. 기존 한국어 파일은 보존.
- 발음 변환 뒤 해당 MP3에 대한 정렬을 측정한다. 정렬 도구가 없거나 신뢰할 수 없으면 미검증으로 남기며 균등 문자 분할로 대체하지 않는다.
- 실측 라벨은 prepare-timeline.mjs로 가져오고, 두 브라우저·두 외형에서 정상 속도와 경계 구간을 검토한다.
- 사용자의 실제 청취·자연스러움 확인 후 해당 범위의 완료 여부를 갱신한다.

별도 확인이 필요한 근거: AGENTS.md가 참조하는 docs/yeoni-character-architecture.md의 ‘5단계 검증과 완료 조건’ 2항은 기존 1회 생성 승인을 새 문장의 포괄 승인으로 해석하지 않도록 명시한다. PHASE 11 확인은 새 일본어 TTS 생성 횟수 승인이 아니다.
