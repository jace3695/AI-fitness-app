# 자기계발 완료 명령 — 2026-09-16

6단계의 자기계발 완료 명령을 확인·실행 이력·되돌리기에 연결했다. 확인 없이 목표 시간을 실제 수행 시간으로 저장하던 기존 경로를 교체했다. 자기계발 전체 또는 6단계 전체 완료를 뜻하지 않는다.

## 지원 범위

| 명령 예시 | 저장할 내용 |
|---|---|
| `오늘 타자 연습 완료했어` | 오늘 해당 루틴의 완료 사실. 실제 시간은 미기록 |
| `오늘 손글씨 15분 완료했어` | 오늘 해당 루틴 완료와 직접 말한 실제 15분 |
| `오늘 자기계발 독서 20분 완료로 기록해줘` | 사용 중인 이름이 정확히 `독서`인 루틴의 오늘 완료와 실제 20분 |

- 연이 대화·빠른 명령 → 한국 시간 날짜·루틴·완료 내용 확인 → 확인하고 저장 → 공통 실행 이력의 자기계발 탭에서 재조회·되돌리기.
- 루틴의 정확한 이름을 먼저 찾는다. 타자·손글씨·개발 별칭에 해당하는 루틴이 여러 개면 임의로 고르지 않고 정확한 이름을 요청한다. 비활성 루틴과 기존에 보류한 그림 연습은 제외한다.
- 실제 시간은 직접 입력한 정수 1~1,440분만 받는다. 시간을 생략하면 목표 시간을 실제 시간으로 채우지 않으며, 기록·달력·실행 이력에 `시간 미기록`으로 표시한다. 기존 숫자 필드에는 0과 `actualMinutesRecorded:false` 표식을 함께 저장한다.
- 타자 속도·정확도, 손글씨 평가, 시작·종료 시각, 메모를 추정하지 않는다. 목표 시간은 계획 정보로만 남긴다.
- 오늘의 루틴 하나만 지원한다. 과거·미래, 질문·조건·부정·일부 완료, 찾을 수 없거나 애매한 대상은 저장하지 않는다. 사용자 정의 루틴은 `자기계발`과 정확한 이름을 함께 말한다.
- 같은 날짜·루틴에 완료·일부·중단 기록이 하나라도 있으면 기존 기록을 보호하기 위해 새 명령을 저장하지 않는다. 상세 기록 수정은 자기계발 화면에서 진행한다.

## 보존·복구

- 로그인한 본인의 RLS와 invoker 함수로 완료 세션과 실행 이력을 같은 트랜잭션에서 저장한다. 이력 저장이 실패하면 세션도 롤백한다.
- 확인했던 루틴의 이름·목표·요일·주간 횟수·사용 여부·갱신 시각과 초기화 표식을 비교한다. 루틴 변경, 다른 확인 요청의 선행 저장, 초기화가 있으면 오래된 요청을 거절한다.
- 초기화와 같은 잠금 순서를 적용한다. 원래 없던 앱 상태 행을 생성하지 않으며 다른 루틴·날짜·기존 세션은 보존한다.
- 확인 유효기간은 15분이고 한국 날짜가 바뀌면 다시 확인한다. 동일 요청은 중복 저장하지 않으며, 저장 응답이 유실돼도 같은 탭의 복구 요청으로 결과를 다시 받는다. 이미 저장한 요청은 만료 뒤에도 기존 결과만 반환하며 되돌린 요청을 다시 실행하지 않는다.
- 되돌리기는 이 명령이 만든 세션의 전체 내용이 그대로이고 같은 날짜·루틴에 추가 기록이 없을 때만 수행한다. 직접 편집·추가한 기록, 다른 날짜·루틴, 삭제되어 연결이 끊어진 루틴 기록을 덮어쓰지 않는다.
- 자기계발 또는 비서 초기화 시 실행 이력을 지우고 대기 요청을 무효화한다. 계정 삭제는 외래키 cascade로 처리하며 Auth 내부 역할에 앱 테이블 권한을 추가하지 않는다.
