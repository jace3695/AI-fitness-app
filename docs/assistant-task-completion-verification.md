## 범위

`우유 사기 할 일 완료해줘`, `할 일 우유 사기 완료해줘`처럼 정확한 제목의 미완료 항목 하나를 먼저 확인한 뒤 완료한다. 제목이 중복되거나 일치하지 않으면 자동으로 고르지 않는다. 기존 즉시 완료·반복 일정 생성 경로를 확인·실행 이력·되돌리기로 연결했다.

- 확인 화면에 제목, 기존 상태, 마감, 우선순위, 반복과 다음 일정 생성 여부를 표시한다.
- 매일/매주/매월의 다음 일정은 기존 마감일(없으면 한국 시간의 완료일)을 기준으로 생성한다. 월말은 다음 달의 마지막 날짜로 맞춘다.
- 완료·다음 일정 1건·이력은 하나의 트랜잭션이다. 같은 요청 재시도는 기존 결과만 반환한다. 만료·초기화·다른 계정·변경된 원본·이미 존재하는 다음 일정은 차단한다.
- 되돌리기는 부모와 이 명령이 만든 다음 일정의 전체 행이 일치할 때만 가능하다. 다음 일정 수정·완료·삭제·후속 일정 생성 시 보호한다. 부모의 원래 상태·완료 시각·갱신 시각을 복구해 앞선 추가 명령도 역순으로 되돌릴 수 있다.
- 기존 추가/수정 명령과 수동 할 일 화면의 흐름은 유지한다. 새 명령은 무료이며 AI/TTS를 자동 호출하지 않는다.
