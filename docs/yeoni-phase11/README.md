# PHASE 11 — 외형 전환 중 발화 연속성

2026-10-01 22:17 KST 사용자가 입 전환 보완 미리보기를 확인하고 다음 단계 진행을 요청했다. 고양이형↔인간형을 바꿔도 하나의 음성·재생 위치·Controller·동작 시간이 이어지도록 구현했다. 기술 PoC는 **10/16(1~4·6~11)**이다.

## 미리보기

[Yeoni_Appearance_Switch_Preview.html](Yeoni_Appearance_Switch_Preview.html)을 다운로드하여 Edge/Chrome에서 연다. ChatGPT의 파일 보기에서 소스 글씨가 보이면 HTML을 다운로드한 뒤 브라우저로 열어야 한다.

1. **저장된 연이 음성 불러오기 → 재생**을 누른다.
2. 말하는 도중 **고양이형 / 인간형**을 번갈아 누른다.
3. 선택적으로 **표정과 몸짓도 이어서 확인하기**에서 기쁜 표정·인사를 선택하고 외형을 바꾼다.

기존 승인 이미지와 39자 Zephyr MP3를 포함한 독립 HTML이다. 서버·로그인·새 음성 생성·외부 요청 없이 동작한다. 초기 선택은 고양이형이며 외형 선택을 영구 저장하는 기능은 이번 범위에 없다.

## 변경 내용

- `appearance-renderer.ts`: 새 외형을 별도 Canvas에서 준비한다. 첫 프레임을 그릴 수 있을 때 가시 화면을 교체하고 이전 자원을 해제한다. 준비 중 또는 실패하면 현재 외형을 유지한다. 빠른 재선택은 마지막 요청만 적용하며 실패한 선택은 다시 불러올 수 있다.
- `appearance-stage.ts`: 단일 공통 호스트와 Controller를 생애 전체에 유지한다. 준비된 외형의 재그리기는 기존 동작 시각과 최신 오디오 시각을 사용한다. 음성 로드·재생·탐색을 호출하지 않는다.
- `character-stage.ts`: 기존 시간과 정책을 유지하는 `redraw()`를 추가했다. 기존 외형 마운트 경로는 유지한다.
- `SwitchableCharacterStage.tsx` / `appearance-stage.module.css`: 외형 선택·준비·실패 안내와 한 개의 가시 Canvas. 초기 대체 그림도 원래 정사각형 비율을 유지한다.
- `SpeechLab.tsx`: 미리보기별 제목을 받는 선택적 속성만 추가했다. 음성 로딩·검증 로직은 변경하지 않았다.
- `scripts/yeoni-appearance/`: 새 미리보기·독립 HTML 내보내기·실제 브라우저 검사·오류/경합/프레임 비교 프로브.

Ubuntu 24.04의 기존 Chromium 실행 파일과 **사용자 영역 라이브러리를 사용하는 WebKit WPE 실행기**를 재사용했다. 시스템 패키지를 설치하지 않았다.

재생 중 교체가 추가 `loadstart/emptied/play/pause/seeking` 이벤트를 발생시키지 않는지 확인했다. 실제 Canvas의 입 모양을 기록한 오디오 시각의 예상 값과 비교했다. 정지·끝·되감기·0.5배속·감정·진행 중 몸짓·로딩 실패/복구·동작 줄이기·화면 밖·숨김/복귀·해제/재진입·320/390/1280px·새로고침을 검사했다. 호스트는 루프 1개·관찰자 3개를 유지하며 해제 후 모두 0이다.

비동기 경합 프로브는 마지막 요청 우선, 현재 외형으로 취소, 로딩 실패, 첫 렌더 실패, 초기 생성 실패 후 재시도, 준비 전 해제, 동기 완료 생성자 등 7개 하위 사례를 각 엔진에서 검사한다. 동일 프레임 비교는 승인된 기존 렌더러와 새 전환 표면의 차이를 검사하며, 과거 원본 A안 비교를 재실행하지 않았다.

코드 검사 **703/703**, lint·타입 검사·빌드 통과. 전체 브라우저 검사는 **32/32**다. [최종 verification.json](evidence/verification.json), [코드 검사 기록](evidence/code-checks.json), [Chromium](evidence/chromium/results.json), [WebKit](evidence/webkit/results.json)에 근거를 보관했다.

## 기존 결과 보존과 남은 범위

기존 이미지·음성·영상·독립 HTML·검증 JSON·문서 **329개**가 기반 커밋과 일치한다. [보존 해시](evidence/preserved-assets.json)에 기록했다. 기존 61개 검사나 원본 비교를 반복하지 않았고 기존 결과물을 덮어쓰지 않았다.

이전 입 전환 보완의 사용자 확인은 완료로 기록했다. 이번 외형 전환 미리보기의 사용자 확인, 미검토 자동 정렬 경계·표본에 없는 음소, 물리 iPhone/Bluetooth/발열 검증은 남아 있다. 데스크톱 WebKit을 물리 iPhone 검증으로 간주하지 않는다. 한국어 정렬의 자동 후보 상태를 임의로 검토 완료로 바꾸지 않았다.

현재 개발 브랜치와 Draft PR #207에만 반영한다. 기존 원본/영상 CI의 불필요한 재생성을 피하기 위해 검증 완료 커밋에 `[skip ci]`를 사용한다. 운영 병합·배포는 수행하지 않는다.
