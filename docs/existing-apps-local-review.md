# 기존 비서·가계부·캐릭터 로컬 회귀

기준 커밋은 `d58558255f7e9ceb273b254b874b601af826a050`이다. 앞서 보존한 일본어/성장 후보 10개 파일은 그대로 유지했다. 이번 작업은 로컬 변경이며 커밋·push·배포·외부 업로드하지 않았다.

## 확인한 오류와 수정

### 비서 집계 범위

- 기존 28일 집계는 체성분 수치, 음식별 영양, 수면, 자세를 분석하지 않는다. 일본어의 현재 오답/과정 복습 목록에는 직접 저장한 회화 예문이나 그림·필기·타이핑 기록이 들어가지 않는다. 실제 집계에 맞게 이 제외 범위를 요약 메모에 명시했다.
- 가계부 통화 설정을 읽지 않고 모든 금액에 원화 단위를 붙이던 오류를 수정했다. 기존 소유자 조건으로 `budget_user_settings.currency`를 읽고 KRW/USD/JPY를 환산 없이 표시한다. 미지원 설정이나 조회 오류는 완전한 분석처럼 표시하지 않는다.
- 가계부 화면의 월별 계산은 충전카드 충전을 지출에서 제외하지만 비서 집계는 포함하고 있었다. 최소 조회 필드에 기존 `transaction_type`을 추가해 충전을 제외했다. 미래·기간 밖 기록 제외, 전체 건수 대조, 소유자 조건, 동의·설정 확인과 무료 호출 보호는 유지한다.
- 자료 출처와 서울 기준 최근 28일 기간, 현재 시점의 복습 항목 수, 기록 없음과 조회 실패, 예시 자료를 합성 화면에서 구분했다. 새 분석 분야나 금융 연결을 추가하지 않았다.

### 캐릭터 미디어 제어

수정 전 합성 이벤트 검사 3개가 실패해 다음 문제를 재현했다.

- `play()` 대기 중 정지/pagehide 후 늦은 `playing` 이벤트가 재생 상태를 되살렸다.
- 재생 준비 중 빠른 연속 클릭이 중복 `play()` 요청을 보냈다.
- 실제 미디어는 재생 중인데 과거의 `pause`/`ended` 이벤트만 늦게 도착하면 현재 상태를 덮었다.

현재 재생 의도와 요청 번호, 준비 중 여부를 추적하고 실제 미디어 상태에 맞는 이벤트만 반영한다. 컴포넌트 해제 뒤 늦게 끝난 재생 Promise도 중단한다. 음원·음소 정렬·Controller·외형 자산은 수정하지 않았다. 음소거 검사는 합성 media의 `muted` 상태 전환과 같은 재생 시계 유지 확인이며 실제 청취 결과가 아니다.

### 가계부

화면 코드에서는 수정이 필요한 오류를 발견하지 않았다. 실제 `CategoryEditor`와 `MonthlyCheck`를 합성 RPC/계정 어댑터로 실행하여 확인 취소, 반복 제출, 응답 유실 후 같은 요청 재확인, 되돌리기, 다른 화면 수정과의 충돌, 10월 말→11월 초, 계정별 화면 분리를 확인했다.

별도로 기존 PGlite 메모리 DB 검사에서 실제 마이그레이션 SQL의 중복 요청·충돌 롤백·되돌리기·타 소유자 거절을 실행했다. 이는 로컬 합성 SQL 검증이며 호스팅 Auth/PostgREST/DB/RLS나 실제 계정 저장 검증이 아니다. 실제 DB 스키마를 변경하지 않았다.

## 검증 기록

- 전체 기본 단위 900개 + 별도 AI 예산 제어 26개 = **926개 통과**, 실패·건너뜀 0. 이전 920개에 이번 비서 2개/미디어 이벤트 4개가 추가됐다.
- 새 합성 UI 확인 16개 통과. 비서 4개, 가계부 6개, 캐릭터 5개, 320px 표시 1개이며 외부 요청 시도·페이지 오류는 0건이다.
- 타입 검사·전체 lint·최종 프로덕션 빌드 통과.
- 기존 일본어 16개, 성장 기본 26개, 그림 D71–80 21개, 체성분 점검 25개, 체성분 채팅 18개 재실행 통과.
- 기존 인바디 날짜·저장·운동 목록 51개 재실행 통과. 새 검사 16개와 기존 157개를 합쳐 **합성 UI 확인 173개 통과**다. 별도 운동 시범 검사는 활성 27종·비활성 초안 3종과 정지/해제 정책을 통과했다.
- 최종 통합 실행의 13개 작업 모두 종료 코드 0. 런타임 수정 후 남은 실패는 없다.
- 로그: `scripts/browser-qa/.generated/existing-apps-final/`. 새 UI 상세: `scripts/browser-qa/.generated/existing-apps/result.json`. 320px 화면: 같은 폴더의 `advice-320.png`.
- 이전 검사 산출물은 최종 실행 전에 `existing-apps-final/previous/`에 복사했다. 이전 통합 후보의 manifest와 파일 복사본도 수정하지 않았다.

검사 도구 최초 구성에서 합성 RPC 어댑터의 닫는 괄호가 빠져 번들링이 실패했으며 이를 고친 후 UI 검사를 실행했다. 이 도구 오류를 앱 오류나 UI 통과로 계산하지 않는다.

## 다음 배포 후보 구성

보존한 일본어 런타임 3개와 이번 오류 수정 런타임 3개를 기능 후보로 묶을 수 있다. 성장 관련 파일은 검증 전용이다. 기존 개발 PR 전체, 다른 운동 증거 폴더, 새 서비스·보안·DB 변경을 포함하지 않는다. 배포하지 않았으며 최종 실제 계정/기기 검증 범위는 위 표처럼 남아 있다.
