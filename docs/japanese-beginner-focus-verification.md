# 일본어 입문·집중 학습 개선 검증 기록

검토일: 2026-09-06. 대상 브랜치: `feat/japanese-beginner-focus`.

## 현재 판정

로컬 구현과 자동 검증을 진행했다. **실제 브라우저에서 새 UI를 조작하는 검증은 미완료이며, 운영 배포 승인 근거로 사용할 수 없다.** GitHub 업로드·PR·프리뷰 생성·병합·운영 배포는 이번 변경에 대해 실행하지 않았다.

## 구현 범위

- 홈에서 ‘글자를 처음 배워요 / 조금 읽을 수 있어요’를 선택한다. 이미 학습 기록이나 진행 중 초안이 있으면 이어하기를 우선한다.
- `/language/start`: 히라가나 46글자를 10묶음으로 나눈다. 첫 묶음은 あいうえお이며, 한 글자씩 듣고 고른다. 기본 묶음별 진도를 저장한다. 가타카나와 기존 따라 쓰기는 전체 가나 페이지에서 이용한다.
- `/language/learn`: 표현 하나 → 문장 원리 → 대화 → 선택적 말하기 → 한 문제씩 확인. 한글·읽기·뜻 도움은 조절할 수 있다.
- 5/10/20분 설정에 따라 확인 문제는 3/5/8개다. 5분에는 말하기 단계를 생략하고 10/20분은 설정에 따라 1/3회 말하기를 제시한다. 제한시간이나 강제 타이머는 아니다.
- 캐릭터 ‘연이’의 짧은 안내, 큰 일본어 글자, 한 화면의 주요 행동, 충분한 버튼 높이, 저자극 청록색을 사용한다. 설명은 작성된 문구로, 실시간 AI 답변이나 유료 생성 호출이 아니다.
- 처음 고른 결과와 다시 맞힌 결과를 분리한다. ‘해본 수업’은 숙달 판정이 아니다. 힌트를 볼 수 있어 점수도 무도움 실력 점수로 표시하지 않는다.
- 아직 틀린 과정 문제는 즉시 복습, 재도전으로 맞힌 문제는 다음 날 복습으로 남긴다. 복습 화면은 먼저 정답을 숨기고 한 문제씩 풀게 한다. 힌트나 재도움이 필요하면 간격을 짧게 유지한다.
- 수업별 초안을 기존 동기화 키 안에 보존한다. 시작 시의 분량과 문제 방식, 첫 선택, 재도전, 위치를 복원하며 소리·녹음은 자동 재개하지 않는다.
- 같은 저장을 재시도해도 오답 횟수를 중복 증가시키지 않는다. 다른 수업의 초안이나 새로 열린 세션은 이전 세션 완료로 삭제하지 않는다.
- 초기 계정 준비·동기화 뒤 학습 화면을 연다. 네트워크 요청 도중 들어온 로컬 입력을 재조회해서 오래된 스냅샷 적용으로 덮어쓰지 않도록 보완했다. 기존 DB 테이블·RLS·인증 방식은 변경하지 않았다.
- 음성 요청·재생은 취소할 수 있고 화면 이동 및 백그라운드에서 중단한다. 녹음은 이 화면의 메모리에만 두며 전송하지 않는다. 일본어 음성이 없는 실패를 성공처럼 숨기지 않는다.

## 자료 품질

| 항목 | 변경 전 | 변경 후 | 의미 |
|---|---:|---:|---|
| 고유 단어 | 1,111 | 1,111 | 숫자·단위 467개를 별도 필터로 분리 |
| 고유 문장 | 1,445 | 1,186 | 기계적으로 붙인 중복·부적절한 질문 확장 제거 |
| 문법 | 40 | 40 | 난이도와 상황 설명 구분 |
| 문법 예문 | 120 | 88 | 무조건 ‘か’를 붙인 예문 대신 서로 다른 상황 예문 |
| 통합 수업 / 확인 문제 | 60 / 480 | 60 / 480 | 기존 수업 ID와 문제 원본 인덱스 유지 |

동사·형용사의 예문과 품사를 명시하고, 숫자·단위의 문맥과 불규칙 읽기를 보정했다. 장음과 일부 조사 발음 보조를 정리했다. 확인한 잘못된 표제어 `入口券`은 `入場券`으로 바로잡았다. 저장해 둔 단어·문장 스냅샷은 강제로 수정하거나 삭제하지 않았다.

자료실 첫 화면의 기초·일반 자료는 단어 52개, 문장 19개다. 전체 자료는 필터로 접근 가능하다. 단계는 앱 자체 추천 학습 순서이며 JLPT·CEFR 인증 등급이 아니다. 일부 확장 명사 예문은 공통 문형을 사용한다. 전체 자료를 일본어 전문 교사가 개별 감수했다는 의미는 아니다.

문법 원칙을 확인한 1차 자료: [국제교류기금 『이로도리』 문법 노트](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf), [『이로도리』 소개](https://www.irodori.jpf.go.jp/about.html). 특히 조사 は/を/へ의 읽기와 형용사 종류를 참고했다. 해당 교재의 이미지나 본문을 앱에 복제하지 않았다.

## 프리뷰에서 반드시 할 실사용 검증

이번 변경에 대한 외부 업로드·배포 승인 및 로그인된 테스트 계정이 필요하다. 비밀번호를 채팅이나 코드로 받거나 인증 게이트를 우회하지 않는다. 허가된 테스트 계정에서만 기록 생성·삭제를 한다.

1. 320/375px 모바일, iPad, 데스크톱 및 확대 화면에서 가로 넘침·버튼 잘림·글자 대비·키보드 포커스를 확인한다.
2. 신규 사용자: 시간 5분 → 처음 배워요 → あいうえお → 일부 오답 → 재선택 → 묶음 저장 → 인사말 수업으로 이동한다.
3. 기존 사용자: 저장 단어·문장·수업 점수·선호 설정이 유지되고 불필요한 입문 강요 없이 이어갈 수 있는지 확인한다.
4. 5/10/20분, 입문/읽기 모드, 말하기 포함/제외의 실제 문제 수와 입력 UI를 확인한다.
5. 문제 중간 뒤로 이동·새로고침·다른 수업 방문 후 복원한다. 첫 오답 점수와 현재 재도전 결과가 유지되는지 확인한다.
6. 모든 오답·일부 재정답·모두 정답의 완료 안내와 오늘/다음 날 복습을 확인한다. 복습 힌트·재도전·건너뛰기·저장 실패를 확인한다.
7. 일본어 TTS 성공, API 실패 시 기기 음성, 일본어 음성이 없는 기기, 재생 중 페이지 이동/취소를 확인한다. 실제 발음과 속도도 듣고 확인한다.
8. 마이크 허용/거절, 녹음 재생, 화면 이동/백그라운드 중단, 카메라·마이크 불필요 요청이 없는지 확인한다.
9. 저장 → 클라우드 동기화 → 재로그인/다른 기기 재조회로 실제 보존을 확인한다. 오프라인·재연결·여러 탭 경합도 확인한다. 현재 단위 테스트를 이 검증의 대체로 취급하지 않는다.
10. 운동·체중관리·자기계발 자동 연동과 일본어 자유 학습의 기존 동작, 콘솔 오류·서버 오류를 회귀 확인한다.

통합 수업의 활동 기록과 기존 5개 자유 학습 루틴 체크는 별도 구조를 유지했다. 루틴 체크를 수업 시작만으로 임의 완료 처리하지 않는다. 이 구분도 실제 홈·자기계발 화면에서 확인해야 한다.

프리뷰 검증에서 중요한 실패가 있으면 병합하지 않는다. 통과 후에만 승인된 병합·운영 배포를 진행하고 운영 화면을 재확인한다. 초등학생/왕초보의 실제 사용성은 대표 사용자 관찰이 추가로 필요하며, 현재 테스트만으로 학습 효과를 보장하지 않는다.
