# 5번 가계부 개선 구현·검증

기준: 2026-09-14 무료 우선 통합 실행 순서의 5번(F05). 1번의 Zephyr 계정 무료 조건은 확인 대기이고, 2번 무료 Gemini 일상 조언은 이전 Preview 검증 완료 상태다. 3번 음성 및 4번 ChatGPT 분석방을 완료로 표시하지 않는다.

## 구현한 범위

- 상세 내역의 필터 결과에서 지출 1~100건을 선택하고 분류 변경을 확인한다. 저장 전 선택 당시의 서버 행 전체를 비교하고 하나라도 바뀌거나 삭제되면 전부 중단한다.
- 사용자가 선택한 경우 같은 장소의 분류를 기억한다. 공백·대소문자만 정리하며, 지점명·일부 단어가 비슷한 가게를 합치지 않는다. 다음 입력의 확인 화면에만 제안하며 자동 저장하지 않는다. 수입·저축에는 지출 분류를 적용하지 않는다.
- 분류와 기억 설정은 하나의 DB 트랜잭션으로 저장한다. 응답 유실 후 같은 요청을 새로고침 뒤에도 확인할 수 있다. 같은 요청의 중복 실행·다른 내용 재사용을 막는다.
- 최근 20개 변경의 날짜·건수·변경 전후 분류를 조회하고 되돌린다. 이후 달라진 기록이나 분류 기억을 덮어쓰지 않는다. 삭제한 거래를 분류 되돌리기로 재생성하지 않는다. 이미 되돌린 요청의 재전송도 다시 적용하지 않는다.
- 분류 기억을 따로 지울 수 있다. 원래 지출의 분류는 유지한다. 전체 가계부 초기화는 변경 이력도 지우며, 분류 규칙은 예산과 같은 설정으로 유지한다.
- 기존 지출·수입·저축 삭제 직후의 원본 그대로 복원을 유지한다. 기존 혼합 항목 저장의 중복 방지 계약도 유지한다.
- 지출 조회가 현재 월에 제한되던 문제를 수정했다. 지출·수입·저축 모두 소유자 필터와 안정된 순서로 500건씩 조회하고, 전체 건수 대조 및 10,000건 상한으로 잘린 결과를 전체로 계산하지 않는다.
- 선택한 달의 중복 후보(날짜·장소·금액·결제수단·거래 종류 일치), 고정 항목의 기록 확인 여부, 구독 금액 변화 후보, 하루 예산 참고치를 표시한다. 자동 삭제나 미납·정확한 사용 가능 금액의 단정은 하지 않는다.
- 하루 참고치는 이번 달에만 계산한다. 월 예산에서 이번 달 기록과 지난달 1건인 고정 항목의 미기록 예상액을 빼고 오늘을 포함한 남은 날짜로 나눈다. 충전카드 충전은 중복 지출 계산에서 제외한다. 월별 행동은 지난달의 같은 날짜 범위와 비교하고 근거 금액을 표시한다.

- 보안 진단에서 새 항목은 없었다. 기존 유출 비밀번호 보호 경고는 이번 작업과 별개이며 계정 설정을 변경하지 않았다. [Supabase 안내](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).
- 유료 AI·새 요금제·충전·새 유료 서버를 사용하지 않는다. 원본 사용자 거래로 저장·분류 변경 테스트를 하지 않는다. 운영 앱 병합·배포와 실제 iPhone 최종 검증은 남아 있다.
