## 발견한 문제와 수정

1. **키워드 없는 후속 질문**: 체성분 문맥이 제거된 채 일반 서버 경로로 갈 수 있었다.
   이제 체성분 대화 뒤 모호한 후속 질문은 로컬 안내만 반환한다.
   “오늘 할 일 보여줘” 같은 정확한 기존 일반 조회 명령은 통과하며, 자유로운 다른 주제는
   사용자가 “기존 일반 대화로 돌아가기”를 눌러 기존 경로로 전환한다.
   전환 시 작성 중 입력은 지워 실수로 보호 대상 후속 질문을 보내지 않는다.
   이 전환은 별도 외부 AI 조언 동의나 기록 전송 범위를 변경하지 않는다.
2. **복원한 이전 대화**: 로컬 보호 표시가 없는 DB 대화가 새 서버 문맥·음성 대상이 될 수 있었다.
   복원한 대화는 모두 읽기 전용으로 표시하고 후속 문맥·음성·실행 링크에서 제외한다.
   체성분 대화가 포함되면 로컬 후속 질문 보호도 켠다.
3. **계정 전환 중 늦은 응답/조회**: 기존 비동기 응답이 새 계정 화면에 남을 수 있었다.
   인증 소유자·요청 세대·요청 순서를 확인하고 오래된 응답을 버린다.
   계정 전환 시 이전 대화·작성 입력·조언·음성 상태를 비운다.
4. **네트워크 실패**: 오류 내용을 후속 문맥이나 음성으로 전달하지 않는다.
   이전 대화 조회 실패는 명시적 안내를 표시하며 이전 계정 내용을 복원하지 않는다.
5. 일반 경로가 예상 밖 체성분 답변을 반환해도 그 답변은 음성·재전송 대상에서 빼고
   로컬 후속 질문 보호를 켠다. 새 의료 규칙이나 외부 AI 호출은 추가하지 않았다.
