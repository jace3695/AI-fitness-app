# 4단계 — ChatGPT 분석방 연결 조건

2026-09-15 최초 조건 검토 후, 전용 MCP/OAuth 연결과 조언 조회 화면을 구현했다. **실제 Jace ChatGPT 계정 연결과 모델 분석은 아직 미완료다.** 최신 구현·검증·설치 절차는 [연결 검증 문서](chatgpt-connection-verification.md)를 따른다. 이 문서는 추가 비용 0원의 확인서가 아니다.

## 확인한 방식

ChatGPT 웹은 플러그인이 제공하는 원격 MCP 도구를 사용할 수 있다. 데스크톱/CLI의 로컬 MCP 설정 파일을 웹 분석방이 그대로 읽는 방식은 아니다. 작업 공간의 도구 허용 설정도 적용된다. [OpenAI 연결 문서](https://learn.chatgpt.com/docs/extend/mcp).

개인 기록 조회·조언 저장 도구에는 사용자 인증이 필요하다. 공식 지침은 OAuth 2.1, 요청마다 토큰 확인, 인증/리소스 메타데이터와 PKCE를 안내한다. 따라서 연이 로그인과 연결 권한을 구분하고, 인증된 본인 자료만 조회·저장하는 전용 경로를 구현해야 한다. [OpenAI 플러그인 인증 문서](https://developers.openai.com/plugins/build/auth).

현재 저장소에는 Preview 전용 `/mcp`와 OAuth·기록 요약·조언 저장 경로가 추가되었다. 이 대화에서 개발용 Supabase·GitHub 도구를 사용할 수 있다는 사실을 연이 앱의 사용자별 분석 연결이 완성된 것으로 취급하지 않는다.

## 작은 검증의 제안 범위

아래 범위를 구현했으며, 실제 ChatGPT 계정 연결까지 통과한 뒤 4단계 완료로 표시한다.

| 도구 | 허용할 동작 | 저장 원칙 |
|---|---|---|
| 본인 기록 요약 조회 | 사용자가 고른 기간·영역의 요약 조회 | 원본 수정 없음, 조회 시점/누락 구분 |
| 조언 저장 | 사용자가 요청한 분석 결과를 연이에 저장 | 요청 ID로 중복 방지, 분석한 요약 버전 연결 |
| 저장한 조언 조회 | 새로고침 후 같은 조언 재조회 | 다른 사용자의 조언 접근 차단 |

연결 서버는 별도 유료 LLM API를 호출하지 않는 설계로 시작한다. 기존 ChatGPT 계정의 연결 기능·사용 한도와 기존 Vercel/Supabase 범위 안에서의 운영 조건은 실제 계정에서 확인해야 한다. 새 요금제·과금 프로젝트·자동 충전은 이 검증의 전제에 넣지 않는다.

원본 가계부·운동 계획을 수정하는 기능은 조언 저장과 분리한다. 원본 변경은 6단계의 사용자 확인·이력·되돌리기 경로를 갖춘 후 연결한다. 24시간 자동 감시나 앱 변경 즉시 분석을 이번 요청형 검증의 완료 조건으로 포함하지 않는다.

## 이어서 할 일

1. 구현한 인증·세 동작의 격리 브라우저 검증과 Preview 준비를 마친다. 단위·DB 검증은 통과했다.
2. 실제 연결 주소와 허용 권한을 준비한 뒤, Jace 계정에서 연결 기능 사용 가능 여부와 로그인 승인을 확인한다.
3. ChatGPT에서 명시적으로 분석을 요청하고, 연이의 저장된 조언을 다시 조회한다. 성공 전에는 4단계 완료로 표시하지 않는다.

지금 무료 자체 기능 개발을 계속하기 위해 사용자가 새 API 키를 발급하거나 요금제를 변경할 필요는 없다.
