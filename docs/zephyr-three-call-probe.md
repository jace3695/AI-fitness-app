# Zephyr 실제 사용량 검증 준비 — 2026-09-15

사용자는 청구 보고서에 아직 사용량이 보이지 않아 **앱에서 음성 검증을 몇 번 실행**하도록 요청했다. 이번 요청은 일반 음성 기능의 상시 활성화나 무료 한도 검증 완료를 의미하지 않는다.

## 요청 범위와 준비한 코드

- `fix/app-wide-reliability`의 Vercel Preview에서만 `/assistant/voice-check`와 `/api/tts/probe` 사용 가능. 운영 환경과 다른 브랜치는 404.
- 현재 로그인 사용자 인증을 앱 서버와 Edge Function에서 각각 확인한다. 키는 기존 `GOOGLE_TTS_API_KEY`를 서버에서만 사용하며 화면에는 설정 여부만 표시한다.
- 미리 지정한 계정의 승인 요청 세 개만 사용. DB 슬롯 번호는 1~3으로 제한하며, 승인 기간은 최대 24시간이다. 앱과 Edge에서는 승인 생성·기간 연장·삭제를 지원하지 않는다.
- 고정 문장 61자, 총 최대 183자. `ko-KR-Chirp3-HD-Zephyr`, MP3, 요청당 Google 시도 1회. 접수 후 실패·응답 유실에도 동일 요청 번호 재사용 불가. 화면에서 오류가 나면 추가 생성을 멈춘다.
- 음성 생성 성공과 받은 음성의 재생 완료를 따로 표시한다. 재생 버튼은 받은 오디오만 사용한다.
- 월별 무료 승인과 원장, `FREE_MODE=true`, 일반 음성 기능은 변경하지 않는다. 실제 청구액을 0원으로 가정하지 않는다.

고정 문장:

> 안녕하세요. 저는 연이예요. 지금은 구글 제퍼 목소리로 음성 테스트를 하고 있어요. 오늘도 차근차근 함께해요.

[Google TTS 요금표](https://cloud.google.com/text-to-speech/pricing)의 Chirp3-HD 초과 단가 USD 30/100만 문자를 적용하면 세 번 모두 과금되는 경우 TTS 비용은 USD 0.00549다. 이는 실제 청구 결과가 아니다.

## 현재 적용 상태

- 새 제한 통합 검사 9개, TypeScript, 변경 파일 ESLint 통과. 실제 Google 대신 합성 응답으로 권한·한도·동시 중복·실패를 검증했다.
- 공유 Supabase에 새 테이블/함수/RLS·내부 service role 권한을 추가하는 `zephyr_three_call_probe` 마이그레이션은 **자동 승인 검토에서 거절**됐다. 이유는 음성 검증 요청만으로 추가 공유 DB·접근 권한 변경까지 승인되지는 않았다는 판단이다.
- 따라서 호스팅 마이그레이션과 새 Edge 배포, 승인 슬롯 생성은 진행하지 않았다. 새 승인 기능이 없어도 Preview의 상태 조회는 키 설정 여부를 보여주며, 음성 생성은 허용하지 않는다.
- 실제 Google 호출·재생은 아직 수행하지 않았다. 테스트 전 계정 확인은 완료했다. 실제 키 설정 확인·최종 배포·CI 결과는 [PR #189](https://github.com/jace3695/AI-fitness-app/pull/189)의 최신 작업 기록에 남긴다.

## 필요한 다음 조치

공유 Supabase 프로젝트에 검증 전용 테이블 하나와 내부 전용 함수 두 개를 추가하는 변경의 명시적 승인이 필요하다. 승인되면 검증된 마이그레이션 → JWT 필수 Edge 배포 → 해당 계정의 3개 요청만 최대 24시간 승인 → Preview에서 하나씩 생성·재생 → 호출 횟수/문자 수/HTTP 응답 기록 순서로 진행한다. 기존 개인 기록이나 월별 무료 승인은 수정하지 않는다.

키가 없는 것으로 확인되면 `GOOGLE_TTS_API_KEY`를 Vercel Preview, 해당 브랜치의 Value 칸에 설정해야 한다. 키 원문을 대화에 보내지 않는다. 키가 속한 프로젝트/결제 계정과 실제 청구 결과는 별도로 대조해야 한다.
