# 연이 한국어·일본어 음성: 실제 파일의 음향 분석

2026-10-05 / 사용자 요청: 직접 청취가 불가능한 환경에서 분석·평가할 방법 확인.

## 결론

**음향 수치 분석은 가능하며 기존 네 파일에 대해 실행했다. 현재 일본어가 기존 한국어보다 크게 낮은 목소리라는 근거는 없었다.** 대표 음높이(F0 중앙값)는 기존 한국어 222Hz, 현재 일본어 219Hz다. 두 파일의 음높이 중앙값은 비슷하지만, 이를 같은 음색이나 같은 화자로 판정한 결과로 해석하면 안 된다.

현재 일본어의 주파수 분포와 주기성 관련 지표에는 차이가 있다. 그러나 문장·발음·언어·음성 길이와 MP3/WAV 형식도 다르므로, 이 차이가 어린 남성처럼 들리는 원인이라고 확정할 수 없다. 초기 수치 분석 시점에는 직접 청취 또는 오디오 이해 AI를 통한 청감 평가를 실시하지 않았다. 이후 승인된 Gemini 비교 1회의 결과와 한계는 아래 후속 평가에 기록했다. 여성/남성·나이·동일 화자 분류기를 실행하지 않았다.

## 분석 대상

| 파일 | 기록된 생성 조건 | 길이 | 현재 선택 |
|---|---|---:|---|
| 기존 한국어 | Cloud TTS / ko-KR-Chirp3-HD-Zephyr | 5.376초 | 예 |
| 기존 일본어 | Cloud TTS / ja-JP-Chirp3-HD-Zephyr | 4.056초 | 아니요 |
| 받은 한국어 후보 | Gemini 3.8 Flash TTS / Zephyr 후보 | 5.720초 | 아니요 |
| 받은 일본어 후보 | Gemini 3.8 Flash TTS / Zephyr 후보 | 5.080초 | 예 |

일본어 후보의 실제 생성 모델·음성 선택은 생성 당시 일본어 화면으로 독립 확인하지 못했다. 후보 조건은 기존 비교 계획과 수령 기록이다. 기존 일본어는 이미 비교한 파일이며 새 후보가 아니다. 최신 첨부 한국어/일본어 WAV를 다시 받아 저장소 파일과 각각 SHA-256 일치를 확인한 후 분석했다. 모든 원본은 변경하지 않았다.

한국어 두 파일의 예정 문장은 서로 같고, 일본어 두 파일의 예정 문장도 서로 같다. 언어 사이에는 문장과 음소 구성이 다르다. 한 조건당 한 개의 짧은 발화이므로 모델과 언어의 영향을 인과적으로 분리할 수 없다.

## 음높이 결과

대표 음높이는 유성으로 검출한 구간의 F0 중앙값이다. 범위는 전체 최저/최고가 아니라 10~90 백분위수다. 프레임은 서로 겹치며 독립된 실험 표본이 아니다.

| 파일 | 대표 음높이 | 주된 음높이 범위 | 다른 계산 방식의 중앙값 |
|---|---:|---:|---:|
| 기존 한국어 | 222Hz | 164~293Hz | 225Hz |
| 기존 일본어 | 241Hz | 169~301Hz | 240Hz |
| 받은 한국어 후보 | 207Hz | 152~281Hz | 206Hz |
| 현재 일본어 후보 | 219Hz | 160~316Hz | 215Hz |

- 현재 조합의 중앙값 차이: 일본어가 약 2.8Hz(1.3%) 낮다. 이 작은 중앙값 차이만으로 남성처럼 들리는 이유를 설명할 수 없다.
- 현재 일본어 후보는 한국어 후보보다 중앙값이 높다. 따라서 후보 파일들이 모두 일본어에서 더 낮아졌다고 할 수 없다.
- 기존 일본어는 기존 한국어보다 중앙값이 높다. 이것만으로 기존 일본어가 더 적합하다고 다시 선정하지 않는다.
- 현재 일본어는 기존 한국어보다 이 샘플에서 10~90 백분위 음높이 범위가 넓다. 문장과 발음의 영향이 있어 일반적인 언어 특성으로 확장하지 않는다.

## 음색 관련 보조 수치

| 파일 | 유성 구간 스펙트럼 중심 중앙값 | 유성 구간 HNR 중앙값 |
|---|---:|---:|
| 기존 한국어 | 940Hz | 12.48dB |
| 기존 일본어 | 949Hz | 13.05dB |
| 받은 한국어 후보 | 859Hz | 10.60dB |
| 현재 일본어 후보 | 1,072Hz | 11.12dB |

스펙트럼 중심은 분석한 주파수 대역에서 진폭 분포의 중심이다. HNR은 주기성 성분과 잡음성 성분의 비율 지표다. 두 수치는 음색과 관련된 일부 특성을 설명하지만, 화자의 고유 음색이나 성별을 직접 측정하는 지표가 아니다. 같은 사람도 발음하는 모음에 따라 HNR이 달라질 수 있다. 서로 다른 문장 전체를 요약한 이 수치로 ‘여성 확률’, ‘화자 일치율’, ‘음색 유사도 %’를 만들지 않았다.

## 계산 방법 및 확인

- 도구: praat-parselmouth 0.4.7 / 내장 Praat 6.1.38, NumPy, SciPy, FFmpeg.
- MP3/PCM WAV를 원래 24kHz 단일 채널로 디코딩했다. 속도·피치·음량 보정 필터는 적용하지 않았다.
- 주 계산: Praat raw autocorrelation, 10ms 간격, 60~600Hz, very_accurate=True, voicing_threshold=0.45.
- 교차 확인: 같은 조건의 raw cross-correlation. 양 방식에서 모두 유성으로 검출된 프레임의 97.3~98.5%가 1반음 이내였다. 두 방식의 일치는 정답률이나 성별 판단 신뢰도가 아니다.
- 탐색 범위를 50~800Hz로 바꾼 민감도 확인에서도 네 파일의 중앙값 순서는 같았고 기존 한국어/현재 일본어가 비슷하다는 결론이 유지됐다.
- 현재 Praat 문서는 말소리 분석에서 filtered autocorrelation을 선호한다. 이번에 설치 가능한 Parselmouth 내장 버전은 이전 raw 방식이며 버전·교차 확인·탐색 범위 결과를 모두 기록했다.
- 스펙트럼: 40ms Hann 창, 10ms 간격, FFT 2048, 100~8000Hz, 유성 구간만 선택, 사전 강조 없음. HNR은 cross-correlation 방식으로 계산했다.
- 최신 첨부 원본 두 개와 저장소 WAV 해시 일치 확인. 모든 네 원본의 해시는 분석 전후 일치했다.
- 새 TTS 생성 0회, 외부 음성 업로드 0회, 앱 코드·배포 변경 없음.

## 더 할 수 있는 평가

오디오 입력을 지원하는 AI에는 파일 자체를 전달하여 발성의 밝기·숨소리·공명·억양, 같은 캐릭터처럼 들리는 정도를 비교하도록 요청할 수 있다. 이는 현재 Work의 직접 청취 기능과는 별개의 분석 경로다. Google은 Gemini의 오디오 설명·질의응답 기능을 공식 제공한다. 이러한 정성 평가는 보조 의견이며 동일 화자 인증이나 성별의 확정 판정으로 취급하지 않는다. 초기 수치 분석 후, 사용자 승인으로 이 경로를 1회 실행했다.

다음 청감 비교에서는 파일명과 Zephyr/여성 등의 사전 정보를 숨긴 A/B 비교로 유도 편향을 줄이고, 기존 한국어를 고정 기준으로 사용한다. 동일성의 합격 기준은 사용자가 원하는 ‘한국어 연이가 일본어를 말하는 것처럼 들리는가’다. 음높이가 비슷하다는 이유만으로 통과시키지 않는다.

## 후속 오디오 이해 AI 비교: 2026-10-05

사용자가 로그인 및 저작권 동의를 승인한 뒤, Google AI Studio의 Gemini 3.8 Flash에 기존 한국어(A.mp3)·현재 일본어(B.wav)만 첨부하고 텍스트 평가를 1회 요청했다. 원본 파일의 바이트는 변경하지 않았다. 새 TTS 생성 0회, 추가 재시도 0회다. UI에 유료 API 키 미선택이 표시되었고 웹 검색 연결은 꺼져 있었다. Google Drive 저장 권한 요청은 취소했다.

| 항목 | Gemini가 반환한 정성 평가 |
|---|---|
| 기존 한국어 A | 성숙하고 차분한 여성적 인상 |
| 현재 일본어 B | 어리고 발랄한 여성적 인상 |
| 같은 캐릭터처럼 들리는 정도 | 차이 큼 |

모델은 시작 단어를 A ‘안녕하세요’, B ‘こんにちは’로 각각 반환했다. 이는 파일 내용 처리의 일부 근거지만, 음색 평가의 정확성이나 전체 문장 인식의 검증은 아니다. Codex가 직접 청취했다는 뜻도 아니다.

**응답에는 실측과 맞지 않는 설명이 있다.** 모델은 B의 기본 피치가 A보다 확연히 높고 문장 전체의 기준선도 상당히 높다고 주장했지만, 기존 측정 F0 중앙값은 A 222Hz, B 219Hz로 비슷하다. 다른 계산 방식도 A 225Hz, B 215Hz다. B의 상위 음높이 범위가 더 높은 부분과 전체 기준선이 훨씬 높다는 주장은 구분해야 한다. 따라서 모델의 피치 설명을 검증된 사실로 채택하지 않는다.

비강·두성 공명, 짧은 성도, 포먼트에 관한 설명도 측정 없이 제시한 추정이다. 실제 신체 특성이나 검증된 원인이 아니다. 이 응답만으로 피치를 낮추거나 포먼트 필터를 적용하는 것은 근거가 부족하다. 한 모델의 여성적 인상 평가가 사용자의 ‘어린 남성처럼 들린다’는 인상을 틀렸다고 판정하지도 않는다.

현재 결론은 **일본어의 캐릭터 인상이 사용자 기준에 맞는지 여전히 검토가 필요하다**는 것이다. 기존 한국어를 유지하고, 일본어의 말투·발성 스타일을 맞추는 통제된 비교가 다음 검토 방향이다. 이 방향 자체가 효과 검증이나 새 생성의 승인은 아니다. 짧은 단일 샘플, 언어·문장·코덱 차이 때문에 원인과 해결책은 아직 확정할 수 없다.

- 응답 원문 텍스트의 별도 파일 전달은 동기화 실패로 제공하지 못했다. 주요 평가와 실측 대조는 위 기록과 화면에 보존했다.

## 재현 및 원자료

- 분석 코드: `scripts/yeoni-voice/analyze-acoustics.py`
- 설정·해시·소수점 원자료: `measurements.json`
- 시간별 F0: `pitch-traces.json`
- 실행: `python scripts/yeoni-voice/analyze-acoustics.py --originals-dir <최신 첨부 원본 디렉터리> --output-dir docs/yeoni-voice-comparison/acoustics-20261005`
- 의존성은 앱 의존성에 추가하지 않았다. 실행 환경에 numpy, scipy, praat-parselmouth와 ffmpeg가 필요하다.
