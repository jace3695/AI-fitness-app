## 사용자 흐름 및 안전 범위

신규5개는 장비별 선택 화면에서 `새 동작`으로 표시한다. 안내를 펼치면 장비, 부위, 난이도, 시작 자세, 순서, 호흡, 실수, 중단 조건, 대체 선택과 원문 링크를 볼 수 있다. 직접 추가해야 루틴에 들어가고 원본 ID와 출처가 재시작 후에도 연결된다.

선택용 카탈로그와 맞춤 추천을 화면에서 분리했다. WORKOUT_GROUPS 및 자동 추천/통증 판단 로직은 변경하지 않았다. 새 동작은 기본 루틴에 삽입되지 않는다. 기존 전역 안전/허리·통증 규칙과 슬라이딩보드·힙브릿지 제외를 유지한다. 대체 선택은 동등 자극을 보장하지 않으며 부위가 다르면 명시했다.

1kg 아령도 사용자에게 무거울 수 있다고 표시한다. 케틀벨·바벨 조립 무게, 밴드 단계별 저항, 안전 스윙 가능성은 추정하지 않는다. 스윙·AB 롤아웃은 추가하지 않는다. 밴드 외회전은 제조사 지침에 맞는 고정 장치가 없으면 선택하지 않도록 안내하며 임의 문손잡이 고정을 권하지 않는다. 장비 범주 선택은 고정점 소유/안전 확인을 뜻하지 않는다.

## 검증

- 전체 단위 테스트: 744/744 통과 (`full-suite-expanded.log`). 새 검사는 정의/출처/필수 안내 완결성, 30개 고유 ID, 자동 그룹 편입 없음, 5개 각각의 JSON 저장·복원, 기존 AB 준비만 유지, 미검증 장비 범주 없음 등을 확인한다.
- 실제 React 브라우저: 19개 검사 통과 (`result-expanded.json`). 추가 검사는 5개 모두 안내 펼치기→출처/카탈로그 표시→선택→새로고침 후 source ID 유지다. 이전 18개 날짜/도해/화면 회귀도 포함한다.
- 실제 렌더 검토: 신규 밴드 외회전의 전체 안내 화면 `expanded-band-guide.png`를 직접 확인했다. 기존 벽 푸시업 시작·굽힘·복귀 화면도 앞선 검토에서 확인했다. SVG 코드·제어 테스트 통과와 임상/전문가 자세 정확성 검증은 별개이며 후자는 미실행이다. 추가 사람형 애니메이션은 만들지 않았다.
- 첫 타입 검사에서 선택적 이름과 literal boolean 타입 오류를 발견하고 고쳤다. 최종 타입/lint/빌드 결과와 독립 리뷰는 후속 기록을 따른다.
- 브라우저는 기존 합성 OCR/로컬 저장 테스트 호스트다. 실제 인증/클라우드 왕복, 실제 개인 건강데이터 OCR, 실물 기기 검증을 대신하지 않는다.

push·병합·배포 없음. 유료 AI·새 서비스·보안·백업·Vercel 이미지·원본 개인 파일·비밀정보에 변경 없음.

## 독립 리뷰

별도 읽기 전용 리뷰 에이전트가 main 이후의 날짜 저장·목록·도해와 이번 신규 카탈로그 변경을 검토했다. 공개 출처 3개와 실제 도해 PNG도 직접 열었다. 관련 단위 10개를 직접 실행해 통과했다. 리뷰에서 P2 1건: 가져오기 체중 0.01이 반올림 후 0kg로 저장되는 회귀를 재현했다. 반올림 결과에도 유한수/양수 검증을 추가하고 0.01, 0.04 및 반올림 오버플로를 거절하면서 원기록을 유지하는 회귀 검사를 추가했다. 나머지 범위에서는 확정 결함을 발견하지 못했다.

재검토 결과 P2 해소 확인. 리뷰 에이전트가 bodyImport.test.ts 5/5를 직접 재실행했다. 최종 전체 단위 **745/745**, 타입 검사, 변경 파일 ESLint, 최종 운영 빌드 통과 (`full-suite-expanded-final.log`, `build-expanded-final.log`). 브라우저 19개는 카탈로그 완성 후 통과했으며 이후 체중 반올림 수정은 단위 회귀·타입·빌드로 검증했다. 현재 알려진 미해결 결함 없음. 인증/클라우드 왕복·실물 기기·전문가 자세 검증은 미실행 상태를 유지한다.
