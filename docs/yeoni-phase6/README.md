# PHASE 6 — 고양이 감정·몸짓 연동 PoC

2026-09-30. 사용자 요청으로 PHASE 5 청취 확인을 귀가 후로 보류하고 개발을 병행했다.
이전 음성 검증을 완료로 바꾸지 않으며, 새 음성 생성·계정/DB 변경·운영 반영은 없다.

## 확인 방법

[소리 없이 시작하는 미리보기](Yeoni_Emotion_Gesture_Preview.html)를 내려받아 브라우저에서 연다.
열두 표정을 골라 정지 상태로 비교하고, **움직임 켜기 → 몸짓 버튼**을 누른다.
몸짓은 한 번 끝나면 돌아오며 새 버튼을 누르면 교체된다. ‘기본으로’는 표정과 몸짓을 초기화한다.
아래 ‘기존 음성과 함께 보기’를 펼치면 같은 39자 MP3를 불러올 수 있다. 기본은 음소거이며
‘소리 켜기’를 직접 눌러야 들린다. 사용자가 음성 파일을 만들 필요는 없다.

## 구현 범위

| 구분 | 구현 |
| --- | --- |
| 표정 12종 | 기본·미소·기쁨·뿌듯함·응원·걱정·놀람·생각 중·진지함·아쉬움·졸림·위로 |
| 일회성 몸짓 4종 | 끄덕임·갸웃·꾸벅 인사·가벼운 응원(몸 들어 올리기) |
| 전환 | 눈·시선·입의 닫힌 곡선·고개·꼬리 태도, 감정 240ms 전환 |
| 충돌 방지 | 최신 몸짓 하나만 실행, 립싱크 우선, 숨김/동작 줄이기/비활성/화면 해제에서 취소 |
| 공통 구조 | Controller는 정규화된 프레임만 생성, Canvas에서 자산 좌표·각도를 적용 |

기존 자산의 눈을 반투명으로 겹치면 잔상이 생겨 불투명 눈 도형으로 보완했다.
이미지 파일을 변경하거나 원래 고양이에 없는 신체를 추가하지 않았다.
**독립 귀·앞발 동작은 분리 자산이 필요해 이번 PoC에 포함하지 않는다.** ‘인사’는 고개 숙임이다.
감정은 미리보기에서 수동 선택하며 실제 AI 응답의 감정 판단은 PHASE 13 항목이다.

## 검증과 진행 상태

- 로컬 단위 690개·린트·타입 검사·Next.js 빌드 통과.
- Chromium: 기존 기본 동작 16개·립싱크 25개와 새 감정/몸짓 10개 시나리오 검증.
- 12가지 표정 정지 비교, 네 동작의 종료·중간 교체, 동작 줄이기, 배경 전환,
  MP3를 재생하면서 표정 변경, 화면 제거/복귀 10회, 모바일·어두운 배경 포함.
- 실제 청취와 물리 iPhone/잠금/Bluetooth는 미검증. 합성 visibility 이벤트와 데스크톱 WebKit은 실기기 검증이 아니다.
- 최종 CI와 오프라인 파일 검증 결과는 후속 증거 기록에 남긴다.

현재 완료 확정은 **1~4단계**, **5단계 사용자 청취 보류**, **6단계 구현·검증 진행 중**이다.
이번 PoC 검증 후 다음 개발 항목은 **PHASE 7 인간형 A안 캐릭터 자산 제작**이다.
그림 실사용 보류 및 별도 분석 SQL 방 후속 완료 미확인 상태는 그대로 유지한다.
