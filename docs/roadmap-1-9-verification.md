# 1~9단계 연속 작업 — 2026-09-18

사용자는 1~9단계를 이어서 진행하도록 요청했다. 기존 기능을 다시 만드는 대신 남은 자체 기능을 구현하고 외부 조건과 실제 검증을 분리한다. Preview·허가된 테스트 계정만 사용하며 실제 iPhone 및 운영 병합은 마지막에 유지한다.

## 이번 변경

- 운동 상세 명령: 오늘의 피로도(1~5), 전체 난이도, 마지막 세트 RPE(1~10), 통증 부위, 일부 완료·중단을 한 항목씩 확인 후 저장한다. 기존 세트·유산소·다른 날짜 보존, 원자적 실행 이력, 같은 요청 재확인, 조건부 되돌리기를 기존 공통 이력에 연결했다. 통증 부위는 통증 있음도 표시하고 일부·중단은 완료 표시를 해제한다. 확인 화면에 함께 표시한다.
- 운동 기록 근거: 어제까지 28일을 두 14일로 비교하며 수행 상태·세트·피로·RPE·통증과 바로 다음 날짜의 컨디션을 표시한다. 미기록은 실패·휴식·무증상이 아니다. 일부 완료를 브리핑의 전체 완료로 표시하던 오류도 수정했다.
- 식단·운동 시각 근거에 당일 저장 단백질과 운동 후 식사 응답을 추가했다. 마지막 식사 시각을 단백질 섭취 시각으로 간주하지 않는다.
- 아침·저녁 요청형 브리핑: 할 일·예산·운동·식단·일본어·자기계발과 다음 행동, 조회 실패 영역을 구분한다. 채팅 브리핑도 실패하지 않은 영역의 결과를 보여준다. Work 예약 작업의 진행 상태를 앱 브리핑으로 대체하지 않는다.
- 기억 관리: 소유자 조회·추가·수정·삭제, 변경 전후 확인, 이전 내용과 일치할 때만 수정·삭제, 응답 유실 뒤 조회만 재시도. 원본 일정·기록에는 쓰지 않는다.
- 일본어: 기초·업무·여행 선택과 복습일·힌트·누적 오답에 따른 우선 문제, 도면 치수·공차 및 측정·품질 수업 2개(전체 62개). 예문은 직접 작성했다. 용어 확인 자료: [KEYENCE 일본어 공차 설명](https://www.keyence.co.jp/ss/products/measure-sys/gd-and-t/basic/about.jsp). 실제 검사 기준을 지정하는 자료가 아니다.
- 타자: 최종 입력에서 다른 글자 수, 같은 문장의 최근/이전 14일 가중 정확도·타수. 삭제·수정한 오타나 키 입력 이력은 측정하지 않는다. 한 연습의 고정 ID로 응답 유실을 복구하며 새 ID로 중복 저장하지 않는다.
- 손글씨: 남은 획 수·접촉 시간·화면 사용 범위, 실제 변화를 감지한 펜 압력만 표시한다. 목표 시간을 실제 수행 시간으로 쓰던 오류를 수정했다. 그림과 지표의 되돌리기를 함께 처리하며 빈 화면 저장을 막는다. 비공개 이미지·자료·세션은 고정 식별자로 재확인한다. 글씨 품질 점수는 만들지 않는다.
- 자기계발의 기존 중단 이유·요일·시각·운동일 비교와 목표 검토를 유지하며, 기록이 없다는 이유로 실제 미수행을 단정하던 코칭 문구를 정정했다.

## 검증 체크포인트

- 단위/DB 599/599, 동기화 27/27, TypeScript·lint 통과.
- 로컬 기본 Turbopack 빌드는 작업 환경의 외부 node_modules 심볼릭 링크를 거부했다. 지원되는 `--webpack` 로컬 빌드 통과. CI는 기존 기본 Turbopack 빌드를 사용한다.
- 새 SQL의 형식 오류를 로컬 PGlite에서 수정했고, 저장·재시도·되돌리기·충돌·원자성·계정 분리 검사 6개가 통과했다. 수업 수 기준도 60→62로 갱신했다. 초기 실패를 최종 통과로 숨기지 않는다.
- `assistant_workout_feedback_commands` 적용 전후 테스트 계정 29개 테이블의 행 수와 전체 행 해시가 동일했다. 함수는 SECURITY INVOKER, 빈 search_path, anon 실행 불가, authenticated 실행 허용이다. 데이터 변환은 없다.
- 실제 Preview 저장·복구: 실행 후 갱신 예정.
- 전체 브라우저 결과: 실행 후 갱신 예정. 새 7개 시나리오를 Chromium·작은 WebKit에 추가했다. Storage도 격리 컨테이너에서 실제로 실행하고 사용자 삭제 전 합성 파일을 제거·재조회한다. 더 많은 사례와 Storage 초기화를 위해 전체 작업 상한만 30→40분으로 변경했다. 개별 90초 제한·재시도 0·1 worker·원본 비교는 유지했다.
