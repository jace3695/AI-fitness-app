## 2026-09-14 연이 목소리 선택 확정

사용자 요청: “응 구글 Zephyr 유지 해줘”. 연이의 한국어 조언을 읽는 목소리는 Google Cloud Text-to-Speech의 `ko-KR-Chirp3-HD-Zephyr`로 유지한다. 분석·조언을 만드는 모델과 음성 제공 서비스를 분리하며, 분석 모델을 바꾸더라도 연이의 목소리는 바꾸지 않는다.

### 연결 조건을 확인할 때 지킬 범위

- Google Cloud TTS의 무료 문자수와 결제 조건은 위 Zephyr 결정 절을 따른다. 무료 한도 중단은 알림만으로 대체하지 않고 실제 요청 전 차단으로 검증한다.
- Gemini 무료 등급은 지원 모델·한도가 정해져 있고 일부 무료 사용 자료가 제품 개선에 사용될 수 있다. 개인 식별정보를 제외한 필요한 요약으로 시작하며 실제 전달 범위를 확인한다. [공식 Gemini 요금·데이터 처리 안내](https://ai.google.dev/gemini-api/docs/pricing).
- ChatGPT는 원격 MCP 기반 도구를 연결할 수 있지만, 이것이 연이 전용 연결의 구현 완료나 앱에서 호출하는 무제한 무료 API를 뜻하지 않는다. 요청형 조회·분석·조언 저장부터 검증한다. 지속적인 자동 감시·앱 변경 즉시 분석·정기 실행은 별도 지원 여부와 사용량 검증 대상이다. [ChatGPT 연결 안내](https://learn.chatgpt.com/docs/extend/mcp).
- 분석방에서 조언을 저장하는 것과 원본 가계부·운동 계획 등을 바꾸는 것은 구분한다. 원본 변경은 통합 명령의 확인·이력·되돌리기 흐름으로 처리한다.
