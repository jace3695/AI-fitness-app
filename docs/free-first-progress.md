# AI 연이 무료 우선 개선 진행 기록

기준: 원본 「AI 연이 앱 개선 로드맵」과 사용자 요청 “비용이 드는 작업은 제외하고, 나중에 진행할 수 있게 정리”.

이 문서는 원본 로드맵 전체 완료를 뜻하지 않습니다. 과거 P1/P2 완료 표시는 당시 선택한 작업 묶음의 완료였습니다. 이번 변경도 아래 범위를 구현하고, 검증 결과와 운영 반영을 따로 기록합니다.

## 이번 구현 범위

| 구분 | 구현한 동작 | 남은 범위 |
|---|---|---|
| F00 무료 실행 정책 | 공통 AI 라우터와 한국어·일본어 서버 음성을 사용량 예약·외부 요청 전에 차단. 기존 키·환경변수로 다시 켤 수 없음. 이전 비용은 조회만 가능 | 운영 적용은 마지막 iPhone 검증 이후 |
| F03 복습 개인화 | 문제별 첫 응답 시간·힌트·실제 풀이 방식 저장, 정답도 복습 편입, 1/3/7/14/30일 간격, 관찰한 문제의 방식별 숙련도 | 실제 필기·발음 품질 평가, 장기간의 학습 효과 검증 |

| F06 기록 기반 운동 점검 | 최근 1회·7일·이번 달·28일과 이전 28일을 저장 수치로 계산. 미응답을 정상으로 추정하지 않음. 기존 무료 계획 제안·결정 이력 유지 | 통증 부위·대체 운동·RPE·다음 날 회복의 더 세밀한 연결 |
| 가계부 무료 대체 | 기존 규칙 질의 유지, 추가 AI 분석 경로는 수입·지출·저축·예산을 계산해 반환 | F05의 분류 규칙·수정 이력·일괄 편집 |

복습 시간은 현재 문제 화면에서 보낸 시간이며 숨겨진 탭 시간은 제외합니다. 재접속 이전 시간까지 누적한 총 학습 시간이 아닙니다. 선택 12초·듣기 25초·입력 30초보다 오래 걸린 정답은 오답 처리하지 않고 현재 간격을 유지합니다. 힌트 없이 연속 3회 이상 정답이고 간격이 7일 이상인 관찰 문제만 “안정”으로 표시합니다. 발음·필기 품질이나 전체 일본어 실력을 판정하지 않습니다.

식단 불러오기는 해당 끼니의 단백질·밥·점심 보충 단백질만 입력칸에 반영합니다. 저장은 기존 “오늘 식단 저장”으로 명시적으로 실행합니다. 소화·야식·운동 후 식사의 미응답은 정상·아니요로 바꾸지 않습니다. 평균은 해당 수치가 저장된 날만 계산하며 저장된 0은 포함합니다.

## 검증

- 로컬 단위/DB 검사 271개, 격리 저장 VM 검사 25개, lint와 TypeScript 통과.
- 로컬 Turbopack 빌드는 공유 node_modules가 프로젝트 루트 밖을 가리키는 환경 제한으로 실패했습니다. 저장소 설정을 우회하지 않고 독립 GitHub/Vercel 빌드에서 확인합니다.
- 유료 AI 키가 존재하고 재활성화 환경변수가 설정된 합성 환경에서도 모든 공통 유료 기능·두 서버 TTS·기존 분석 API의 공급자 요청과 비용 예약이 0회인지 검사.
- 복습 반복 저장·재시도에서 성취를 부풀리지 않음, 불러오기에서 다른 끼니·시간·원본을 변경하지 않음, 미래·이전 기간·미응답을 잘못 합산하지 않음 검사.
- Chromium/WebKit 실브라우저에 무료 회화, 식단 미리보기·취소·저장·재조회, 루틴 중단 이유·무료 코칭 저장, 힌트 사용 복습·간격 저장 사례 추가. 로그인·실제 격리 Auth/PostgREST/Postgres·320px 화면으로 검사하며 결과는 실행 완료 후 아래에 추가.
- 기존 무료 사진 분석의 전용 키·무료 확인·단일 요청·한도 중단 정책 유지. 이번 작업에서 실제 Google 사진 판독을 반복 호출하지 않음. 이전 실제 판독 결과는 `free-diet-photo-hosted-verification.md` 참고.
- 호스팅 DB 구조 변경, 대표 개인 계정 기록 변경, 운영 병합은 이번 범위에 포함하지 않음.

보류 항목 때문에 무료 개선 완료를 기다리지 않습니다. 예산 여유가 생겨도 자동 재개하지 않으며, 과거 월 10,000원 보호 설정을 현재의 유료 작업 승인으로 취급하지 않습니다. 유료 기능은 별도의 승인과 코드 변경·검증이 있어야 재개됩니다.
