# AI 연이 자기계발 — 처음부터 배우는 캐릭터 그림

AI 비서 9 개발방 전달용 학습·기능 명세 v1.0

- 작성일: 2026-09-21
- 대상: 그림을 거의 그려본 적이 없고, 보고도 시작 위치와 순서를 모르는 성인 초보자. 초등학생도 이해할 수 있는 설명을 사용한다.
- 요청 범위: 기존 연이앱의 자기계발 영역에 단계형 그림 학습을 통합한다.
- 이 문서의 상태: 9단계·80개 기본 수업의 교육 설계 및 구현 요구사항. 앱 코드·DB·배포 상태를 확인하거나 변경한 결과 보고서가 아니다.
- 초기 사용자 상태: 1단계 첫 병아리 트레이싱을 안내받았으나, 그린 결과나 숙련도는 아직 확인되지 않았다. 최초 진도는 D01 시작 전으로 둔다.
- 준비된 것: 학습 원칙, 80개 과제, 도움 조절·진급·복습 규칙, 첫 수업의 실제 안내 문구, 콘텐츠 및 검증 요구사항.
- 개발에서 완성할 것: 각 과제에 맞는 검수된 예제 그림·순서 그림, 학습 화면, 저장·복원, 필요한 이미지 피드백 연결, 실제 기기 검증. 제목 80개를 표시하는 것만으로 구현 완료 처리하지 않는다.

## 1. 목표와 수업 원칙

목표는 캐릭터를 관찰하고, 큰 형태와 비율을 이해하며, 참고 그림을 보거나 간단한 기억을 활용해 그린 뒤, 표정·포즈를 바꾸고 자신의 게임·앱용 캐릭터를 설계하는 것이다. 모든 사람이 같은 기간에 같은 결과를 얻는다는 약속이나 ‘80일이면 전문가’ 같은 문구를 사용하지 않는다.

1. 한 수업은 기본 10~20분이다. 바쁜 날에는 같은 목표의 5분 축소 과제를 제공한다. 긴 작품은 여러 수업으로 나눈다.
2. 한 번에 핵심 하나만 가르친다. 모양·비율·표정·선의 깔끔함을 동시에 평가하지 않는다.
3. 모든 수업은 실제 캐릭터 또는 그 캐릭터의 일부를 그리면서 진행한다.
4. 선·원·사각형 반복을 필수 선행 단계로 두지 않는다. 막힌 부분이 확인되면 2~5분 이내로 필요한 선을 몇 번만 그린 뒤 캐릭터로 돌아온다.
5. 원본과 같은 정도로 매끈한 선, 좌우의 완벽한 대칭, 정해진 속도를 요구하지 않는다. 연필을 떼고 여러 번 나누어 그려도 된다.
6. 설명은 ‘어디에서 시작 → 어느 방향으로 움직임 → 어디에서 멈춤 → 왜 그렇게 하는지’를 보여준다. ‘보고 그리세요’만 제시하지 않는다.
7. 전문 용어는 처음 등장할 때 쉬운 말과 그림으로 설명한다. 타원은 ‘길쭉하거나 납작한 동그라미’, 비율은 ‘부분끼리의 크기 관계’, 실루엣은 ‘속의 세부를 지운 바깥 모양’처럼 안내한다.
8. 왼쪽·오른쪽은 기본적으로 화면을 보는 사람 기준이다. 캐릭터 자신의 왼손을 뜻하는 경우 별도로 표시한다.
9. 피드백은 관찰된 장점, 가장 중요한 수정 1개를 기본으로 한다. 필요할 때만 최대 3개까지 제시한다. 성격·재능·노력을 그림만 보고 추측하지 않는다.
10. 비교 대상은 사용자의 이전 그림이다. 남의 그림과 순위를 매기거나 ‘곰손 점수’를 표시하지 않는다.
11. 쉬어간 날에 진도나 숙련도를 깎지 않는다. 연속 출석을 강요하지 않는다.
12. 종이·연필과 iPad·Apple Pencil을 모두 지원한다. 작은 동작이 불편한 사용자는 확대된 예제와 길게 이어 그리지 않아도 되는 순서로 시작한다.

## 2. 전체 과정

| 단계 | 수업 | 배우는 내용 | 대표 결과물 | 다음 단계에 필요한 확인 |
|---|---|---|---|---|
| 1. 캐릭터 트레이싱 | D01~D08, 8개 | 큰 선의 방향·시작 위치를 보며 따라가기 | 병아리·콩 캐릭터·동물 얼굴 | 큰 부분부터 시작할 위치를 고르고, 어려운 선을 나눠서라도 끝까지 시도한다. |
| 2. 도형화 트레이싱 | D09~D16, 8개 | 제공된 밑그림으로 큰 덩어리와 붙는 위치 이해 | 머리·몸·귀가 구분된 밑그림 | 큰 덩어리와 연결 위치를 2~3개 짚을 수 있다. |
| 3. 원본을 보며 모작 | D17~D28, 12개 | 겹쳐진 도움을 줄이며 옆의 원본을 보고 옮기기 | 같은 크기·작은 크기의 모작 | 큰 모양부터 그리고, 원본과 달라진 크기 관계 하나를 찾아 수정한다. |
| 4. 기억해서 다시 그리기 | D29~D34, 6개 | 큰 특징을 기억하고 원본과 비교해 보완 | 간단한 캐릭터 기억 그림 | 큰 특징 2개를 떠올려 그려보고, 비교 후 보완할 부분을 찾는다. |
| 5. 간단한 변형 | D35~D42, 8개 | 한 요소만 바꾸고 나머지는 유지 | 표정·귀·몸·팔 방향의 변형 | 바꾼 요소와 유지한 특징을 구분한다. |
| 6. 스스로 도형화 | D43~D52, 10개 | 도움 없이 큰 덩어리를 찾고 다시 조립 | 새 캐릭터의 구조 밑그림 | 처음 보는 쉬운 캐릭터도 덩어리와 앞뒤 관계로 설명한다. |
| 7. 쉬운 크로키 | D53~D60, 8개 | 몸의 방향·기울기·팔다리 흐름을 간단히 기록 | 막대인간·도형 자세 | 세부 없이도 참고 자세의 방향을 나타낸다. |
| 8. 포즈와 표정 | D61~D70, 10개 | 같은 캐릭터를 다른 감정·자세로 유지 | 표정 모음·인사·앉기·걷기 | 특징을 유지하면서 자세나 감정 하나를 전달한다. |
| 9. 오리지널 제작 | D71~D80, 10개 | 용도·특징 결정부터 작은 캐릭터 묶음까지 | 기본형·표정 3종·포즈 3종·소개 카드 | 자신의 선택 이유와 유지할 특징을 설명하고 같은 캐릭터를 다시 그린다. |

2단계는 선생님이 표시해 둔 도형을 따라 읽는 과정이고, 6단계는 사용자가 스스로 어떤 도형으로 나눌지 선택하는 과정이다. 5단계의 포즈 변형은 팔 하나의 방향 정도로 한정하며, 전신 포즈 구성은 7~8단계에 배치한다.

‘수업 80개’는 미리 준비할 기본 콘텐츠 수다. 반복·복습·작품 분할에 따라 실제 연습 횟수는 달라진다. 종료 후에는 11장의 확장 과정을 이용한다.

## 3. 수업 한 개의 공통 구성

학습 화면은 현재 행동 하나를 크게 보여준다. 아래 항목을 한꺼번에 펼치지 않는다.

1. **오늘 할 일:** ‘병아리의 큰 몸 선을 따라가요’처럼 한 문장.
2. **잠깐 보기:** 완성 예제 한 장과 오늘 볼 특징 한 곳. 30초~1분은 참고일 뿐 제한 시간이 아니다.
3. **순서 보기:** 3~6개의 짧은 단계. 각 단계에는 이전까지의 선, 이번에 그릴 선, 시작 위치, 방향 표시를 구분한다. 자동 재생 없이 한 장씩 넘길 수 있어야 한다.
4. **직접 그리기:** 앱 안에 그리기 또는 종이에 그린 뒤 사진 남기기. 참조 보기·다시 보기·확대가 가능하다.
5. **막혔을 때:** ‘더 쉽게’는 같은 목표의 축소 과제, ‘그림 바꾸기’는 같은 난이도의 다른 검수 예제를 연다.
6. **짧은 확인:** 오늘의 목표에 대한 질문 최대 2개. ‘해봤어요 / 도움을 받았어요 / 아직 어려워요’로 답한다.
7. **마무리:** 오늘 배운 내용 / 잘된 부분 / 먼저 고칠 부분 1~3개 / 필요한 보조 연습 / 다음 연습 / 현재 학습 단계. 직접 확인할 근거가 없는 칭찬이나 판정은 만들지 않는다.

5분 축소 과제도 학습 시도로 기록한다. 단, 해당 수업의 전체 목표 확인이나 단계 진급과는 구분한다.

## 4. 도움을 줄이는 순서와 진급 규칙

### 도움 수준

- H3 함께 따라가기: 원본 전체 + 시작점 + 이번 선의 방향 + 한 동작씩 보기.
- H2 큰 모양 도움: 전체 외곽을 따라 그리기보다, 큰 덩어리·크기 틀·연결 위치를 표시한다.
- H1 시작점 도움: 위·아래·양옆의 기준 위치 또는 머리 위치만 표시한다. 세부 선은 주지 않는다.
- H0 스스로 그리기: 옆의 원본이나 과제 설명을 보고 그린다. 기억 과제는 처음에는 원본을 가리되 언제든 다시 볼 수 있다.

3단계에서는 H3→H2→H1→H0를 한 번에 바꾸지 않는다. H3는 부분 보충용으로 돌아갈 수 있다. 도움을 사용했다고 이미 완료한 다른 학습 기록을 지우지 않는다.

### 수업 상태와 숙련도는 별개

- 수업 상태: 시작 전 / 진행 중 / 시도 완료.
- 목표 확인: 아직 확인 전 / 도움을 받아 확인 / 스스로 확인.
- 확인 근거: 사용자 자기확인 / 이미지 피드백 / 두 가지 모두. 자기확인을 AI 채점 결과처럼 표시하지 않는다.
- 예제의 선을 따라 그린 정확도나 일치 픽셀 비율로 그림 실력을 판정하지 않는다.

### 다음 추천을 고르는 기본 규칙

1. ‘너무 어려워요’가 들어오면 오늘 목표를 유지하면서 더 단순한 예제 또는 그 캐릭터의 일부로 줄인다. 다음 단계를 자동 추천하지 않는다.
2. 목표를 아직 확인하지 못했으면 같은 기술의 다른 예제로 한 번 더 해보게 한다. 같은 그림을 계속 강제하지 않는다.
3. 도움이 있으면 가능하다면 다음 연습에서는 도움을 한 종류만 줄인다.
4. 서로 다른 예제의 별도 시도에서 목표를 확인하면, 해당 단계의 마무리 과제를 추천한다. 연습 횟수만으로 진급하지 않는다.
5. 단계 마무리에서는 위 전체 과정표의 관찰 가능한 기준을 확인한다. 필요하면 대표 과제 두 번으로 나누며 하루에 몰아 하지 않아도 된다.
6. 현재 목표의 확인 근거가 부족하면 ‘한 번 더 살펴보기’를 제안한다. 무기한 잠금하지 않고 사용자가 다음 단계 맛보기를 선택할 수 있게 한다. 맛보기는 이전 단계의 숙련도 확인으로 기록하지 않는다.
7. 한 단계가 끝났을 때 선택지: 다음 단계 / 같은 수준의 다른 그림 / 익숙한 그림으로 쉬어가기.

두 예제에서 확인하는 규칙은 앱의 추천 정책이며 보편적인 교육학적 합격 기준을 뜻하지 않는다. 실제 사용자의 어려움에 맞춰 조절 가능한 설정값으로 둔다.

## 5. 80개 기본 수업 — 실제 과제

아래 ‘순서’는 앱에 넣을 수업 원고다. 각 행동과 일치하는 시각 예제가 필요하다. 개발 중에는 문장만 배치하고 시각 예제가 없는 수업을 완료로 처리하지 않는다. ‘확인’은 아름다움 점수가 아니라 오늘 배운 행동을 확인하는 질문이다.

### 1단계: 캐릭터 트레이싱 — 8개

**D01. 첫 병아리 한 장**
- 핵심: 큰 바깥 선의 방향을 보며 따라간다.
- 예제: 머리·몸이 합쳐진 둥근 달걀, 눈 점 2개, 작은 세모 부리, 안쪽 날개 곡선 2개, 짧은 다리선 2개. 털·무늬·그림자 없음.
- 순서: 꼭대기를 찾는다 → 꼭대기에서 왼쪽을 지나 맨 아래 가운데까지 따라간다 → 다시 꼭대기에서 오른쪽을 지나 아래로 연결한다 → 눈과 부리 → 날개와 다리. 긴 선은 원하는 곳에서 끊어 그려도 된다.
- 확인: 큰 선을 어디서 시작했는지 짚을 수 있나요?
- 더 쉽게: 왼쪽 몸 선과 눈 2개만 그린다. 나머지는 다음 시도에 이어간다.

**D02. 콩 캐릭터 한 장**
- 핵심: 휘어지는 방향이 바뀌는 곳을 본다.
- 예제: 한쪽이 살짝 들어간 콩 모양에 점 눈과 짧은 입만 있다.
- 순서: 튀어나온 배와 들어간 허리를 손가락으로 짚는다 → 위에서 배 쪽으로 크게 돌아간다 → 아래에서 허리 쪽을 지나 닫는다 → 눈과 입을 따라간다.
- 확인: 바깥으로 나온 부분과 안으로 들어간 부분을 구분했나요?
- 더 쉽게: 허리가 덜 들어간 넓은 콩 예제로 바꾼다.

**D03. 동그란 곰 얼굴**
- 핵심: 큰 얼굴과 작은 귀의 연결 위치를 본다.
- 예제: 둥근 얼굴, 위쪽 양옆의 반원 귀, 눈 점, 작은 코. 안쪽 귀 장식 없음.
- 순서: 얼굴의 큰 둥근 선부터 따라간다 → 왼쪽 귀가 시작하고 끝나는 곳을 짚고 잇는다 → 오른쪽 귀 → 눈과 코.
- 확인: 귀가 얼굴의 어느 높이에 붙는지 찾았나요?
- 더 쉽게: 얼굴과 귀 하나만 따라간다.

**D04. 토끼 얼굴**
- 핵심: 긴 부분과 짧은 부분을 구별한다.
- 예제: 둥근 얼굴 위에 긴 귀 2개, 점 눈과 짧은 입.
- 순서: 얼굴 외곽을 따라간다 → 귀 밑에서 시작해 꼭대기를 돌아 밑으로 내려온다 → 다른 귀 → 눈과 입.
- 확인: 얼굴보다 길쭉한 귀 모양을 눈으로 따라갔나요?
- 더 쉽게: 한쪽 귀만 그리거나 귀가 짧은 예제를 선택한다.

**D05. 둥근 모서리 로봇 얼굴**
- 핵심: 곧은 부분과 둥글게 도는 모서리를 구별한다.
- 예제: 모서리가 둥근 네모 머리, 점 눈, 짧은 가로 입. 나사·안테나 없음.
- 순서: 위쪽 가로선을 따라간다 → 모서리에서 천천히 돌아 옆으로 내려온다 → 같은 방식으로 밑과 반대편을 잇는다 → 눈과 입.
- 확인: 모서리에서 선의 방향이 바뀌는 것을 확인했나요?
- 더 쉽게: 얼굴 윗부분과 양쪽 모서리만 그린다.

**D06. 작은 펭귄**
- 핵심: 바깥 선과 몸 안의 선을 구별한다.
- 예제: 긴 달걀 몸, 안쪽의 단순한 배 타원, 얼굴. 발가락 없음.
- 순서: 몸 바깥을 먼저 따라간다 → 연필을 떼고 안쪽 배로 옮긴다 → 배 선을 따라간다 → 얼굴을 넣는다.
- 확인: 몸 바깥과 배 안쪽을 구별해서 그렸나요?
- 더 쉽게: 배 무늬를 빼고 몸과 눈만 따라간다.

**D07. 같은 기술, 다른 얼굴**
- 핵심: 새 예제에서도 큰 모양부터 시작한다.
- 예제: 둥근 고양이 얼굴에 작은 삼각 귀 2개와 눈·입. 수염 없음.
- 순서: 큰 얼굴 선을 찾는다 → 얼굴부터 따라간다 → 귀의 선을 하나씩 따라간다 → 눈과 입을 넣는다.
- 확인: 눈보다 큰 얼굴에서 먼저 시작했나요?
- 더 쉽게: 순서 화면에 시작점을 다시 표시한다.

**D08. 트레이싱 마무리**
- 핵심: 익힌 순서를 새 그림에 적용한다.
- 예제: D01~D07과 같은 복잡도의 검수된 다른 콩 캐릭터 또는 동물 얼굴.
- 순서: 가장 큰 부분을 짚는다 → 내가 정한 시작 위치에서 따라간다 → 작은 부분을 추가한다 → 원본을 숨기고 어려웠던 선 하나를 고른다.
- 확인: 시작 위치를 골랐나요? 어려운 선을 나누어 그리는 방법을 사용했나요?
- 더 쉽게: D01의 확대 예제에서 큰 몸만 완성한다. 평가 실패 표시를 하지 않는다.

### 2단계: 도형화 트레이싱 — 8개

**D09. 병아리 속 큰 달걀 찾기**
- 핵심: 세부를 빼고 큰 덩어리 하나를 본다.
- 순서: 예제에서 눈·부리를 잠시 숨긴다 → 제공된 큰 달걀 밑그림을 따라간다 → 원본을 켜서 같은 자리에 있는지 본다 → 눈만 넣어 캐릭터로 만든다.
- 확인: 작은 장식 없이도 몸의 큰 모양을 짚었나요?

**D10. 곰의 얼굴과 귀 덩어리**

- 더 쉽게: 얼굴과 귀 하나만 표시한다.

**D11. 토끼 귀를 긴 타원으로 보기**
- 핵심: 길쭉한 부분을 길쭉한 덩어리로 나타낸다.
- 순서: 얼굴의 둥근 밑그림 → 왼쪽 귀의 긴 타원 → 오른쪽 귀의 긴 타원 → 겹친 부분과 실제 보이는 외곽을 번갈아 본다.
- 확인: 귀를 얼굴과 다른 길쭉한 모양으로 표시했나요?
- 더 쉽게: 귀의 가운데 길을 한 번 짚고 제공된 타원을 따라간다.

**D12. 눈사람의 머리와 몸**
- 핵심: 위·아래 두 덩어리의 위치를 구분한다.
- 순서: 위쪽 작은 머리 원 → 아래쪽 큰 몸 원 → 두 원이 만나는 곳을 짚는다 → 눈 점과 간단한 팔을 더한다.
- 확인: 머리와 몸이 어디서 만나는지 찾았나요?
- 더 쉽게: 이미 그려진 몸 위에 머리만 따라간다.

**D13. 곰 인형의 머리·몸통**
- 핵심: 덩어리끼리의 크기를 비교한다.
- 순서: 제공된 큰 머리 원을 따라간다 → 그 아래 짧은 몸 타원을 따라간다 → 머리 폭과 몸 폭을 눈으로 비교한다 → 완성 외곽을 겹쳐 본다.
- 확인: 이 예제에서 머리와 몸 중 더 넓은 쪽을 골랐나요?
- 더 쉽게: 두 덩어리의 양옆 끝 표시를 함께 켠다.

**D14. 곰 인형의 팔이 붙는 곳**
- 핵심: 팔이 몸 어디에서 시작하는지 본다.
- 순서: 머리·몸 밑그림을 따라간다 → 몸 양옆의 팔 시작점 2개를 짚는다 → 짧은 팔 타원을 따라간다 → 실제 외곽을 켜서 비교한다.
- 확인: 팔이 머리가 아닌 몸 쪽에 연결되는 예제임을 확인했나요?
- 더 쉽게: 몸과 한쪽 팔만 표시한다.

**D15. 로봇의 네모와 막대**
- 핵심: 캐릭터에 따라 다른 도형을 사용한다.
- 순서: 머리의 둥근 네모 → 몸의 더 작은 네모 → 팔·다리의 짧은 막대 → 겹친 선을 그대로 둔 채 완성 예제와 비교한다.
- 확인: 로봇을 큰 네모·작은 네모·막대로 구별했나요?
- 더 쉽게: 머리와 몸만 따라간다. 입체 박스는 아직 요구하지 않는다.

**D16. 도형 밑그림 마무리**
- 핵심: 큰 덩어리와 연결 위치를 설명한다.
- 순서: 처음 보는 단순한 동물의 제공 밑그림을 따른다 → 머리·몸을 짚는다 → 귀 또는 팔의 시작점을 짚는다 → 도형 위에 눈 2개만 넣는다.
- 확인: 큰 덩어리 2개와 작은 부분이 붙는 곳 하나를 말하거나 표시할 수 있나요?
- 더 쉽게: 부위 이름 선택지를 주고 해당 위치를 누르게 한다.

### 3단계: 원본을 보며 모작 — 12개

**D17. 빈 몸 안에 병아리 얼굴 넣기**
- 핵심: 옆의 그림에서 위치를 옮겨 본다.
- 순서: 왼쪽 완성 병아리와 오른쪽의 빈 몸을 본다 → 원본 눈의 높이를 짚는다 → 빈 몸의 비슷한 높이에 눈 2개를 넣는다 → 눈 사이보다 조금 아래에 부리를 넣는다.

**D18. 몸의 네 끝을 이어 병아리 만들기**
- 핵심: 전체 크기를 먼저 정한다.

- 핵심: 높이를 기준으로 폭을 잡는다.
- 순서: 위·아래 시작점 2개를 확인한다 → 원본의 폭을 보고 양옆 위치를 가볍게 찍는다 → 큰 몸을 잇는다 → 얼굴을 넣는다.
- 확인: 양옆 위치를 직접 선택해 봤나요?

**D20. 안내점 없이 병아리 모작**
- 핵심: 빈 공간에서 큰 형태부터 시작한다.
- 순서: 옆 원본을 본다 → 내 그림의 꼭대기와 바닥을 가볍게 표시한다 → 달걀 몸 → 눈·부리 → 날개·다리를 추가한다.
- 확인: 빈 공간에 큰 몸부터 그렸나요? 원본보다 넓거나 좁아진 부분 하나를 찾았나요?
- 더 쉽게: 날개·다리를 빼고 원본 옆에 D18의 네 점 도움을 넣는다.

**D21. 곰 얼굴의 크기 관계**
- 핵심: 귀를 얼굴보다 작게 배치한다.
- 순서: 얼굴의 큰 둥근 모양 → 귀가 붙을 위쪽 양옆 표시 → 작은 귀 2개 → 눈·코. 원본과 귀 크기만 비교한다.
- 확인: 큰 얼굴과 작은 귀의 크기 차이를 표현했나요?
- 더 쉽게: 큰 얼굴은 제공하고 귀만 직접 그린다.

**D22. 토끼의 귀 길이**
- 핵심: 긴 부분의 길이를 관찰한다.
- 순서: 얼굴을 먼저 그린다 → 원본에서 얼굴 높이와 귀 길이를 비교한다 → 귀 밑과 끝의 위치를 가볍게 찍는다 → 두 귀와 눈을 넣는다.
- 확인: ‘귀가 얼굴보다 얼마나 길게 보이는지’를 먼저 살펴봤나요?
- 더 쉽게: 한쪽 귀의 밑·끝 두 점을 제공한다.

**D23. 눈사람의 위아래 배치**
- 핵심: 두 덩어리의 상대 위치를 맞춘다.
- 순서: 머리 위치를 작게 표시한다 → 아래 몸의 공간을 남긴다 → 작은 머리와 큰 몸을 그린다 → 얼굴을 넣고 두 덩어리가 만나는 위치를 비교한다.
- 확인: 머리와 몸 사이의 위치를 원본과 비교했나요?
- 더 쉽게: 몸의 중심 위치를 한 점으로 표시한다.

**D24. 펭귄 몸 안의 여백**
- 핵심: 안쪽 모양과 바깥 선 사이의 간격을 본다.
- 순서: 큰 몸 외곽 → 배 타원의 꼭대기·바닥 표시 → 안쪽 배 모양 → 얼굴. 배와 몸 양옆 사이에 남은 공간을 비교한다.
- 확인: 배를 그리기 전에 주변에 남을 공간을 살펴봤나요?
- 더 쉽게: 배의 크기 틀만 연하게 제공한다.

**D25. 고양이 귀의 위치**
- 핵심: 작은 부분의 붙는 곳을 옮긴다.
- 순서: 얼굴의 큰 모양 → 양쪽 귀 밑의 시작·끝 위치 표시 → 세모 귀를 연결 → 눈·입. 귀의 모양보다 붙은 위치를 먼저 비교한다.
- 확인: 귀 밑의 위치를 정한 뒤 귀를 그렸나요?
- 더 쉽게: 귀 한쪽의 시작·끝 점을 제공한다.

**D26. 작은 크기로 다시 그리기**
- 핵심: 크기가 달라도 부분끼리의 관계를 유지한다.
- 순서: 익숙한 곰 얼굴 원본을 본다 → 원본보다 작은 자리 틀을 잡는다 → 큰 얼굴부터 넣는다 → 그에 맞춰 귀와 눈도 작게 넣는다.
- 확인: 얼굴만 줄이지 않고 귀도 함께 줄였나요?
- 더 쉽게: 축소한 원본을 옆에 함께 보여준다. 정확한 축척 계산은 하지 않는다.

**D27. 한 곳만 고쳐보기**
- 핵심: 원본과 비교해 중요한 차이 하나를 수정한다.
- 순서: D20~D26 중 내 그림과 해당 원본을 나란히 놓는다 → 전체 폭·귀 위치·눈 높이 중 차이가 큰 하나를 고른다 → 그 부분의 위치를 연하게 새로 표시한다 → 한 번만 수정한다.
- 확인: 수정할 한 곳을 고르고 이유를 말하거나 선택했나요?
- 더 쉽게: 가능한 차이 2개만 확대해서 제시한다. 나머지는 수정하지 않는다.

**D28. 새로운 쉬운 캐릭터 모작**
- 핵심: 배운 모작 순서를 다른 예제에 적용한다.
- 예제: 처음 보는 둥근 햄스터 얼굴. 점 눈·작은 귀·짧은 입만 포함한다.
- 순서: 가장 큰 얼굴의 높이·폭 → 귀의 위치 → 눈·입 → 원본과 한 곳 비교.
- 확인: 큰 모양부터 시작했나요? 크기나 위치 차이를 하나 찾았나요?
- 더 쉽게: 얼굴의 네 끝을 표시하고, 귀와 눈 중 하나만 직접 옮긴다.

### 4단계: 기억해서 다시 그리기 — 6개

**D30. 곰 얼굴 기억하기**

**D31. 토끼 특징을 골라 기억하기**

- 순서: 귀 길이와 얼굴 모양 중 기억할 두 가지를 고른다 → 원본을 가린다 → 고른 특징부터 그린다 → 원본을 열어 선택한 두 특징만 비교한다.
- 확인: 세부 전체보다 중요한 특징을 골라 그렸나요?
- 더 쉽게: 특징 선택지를 그림으로 제공한다.

**D32. 기억이 안 나면 확인하고 이어가기**
- 핵심: 막힌 부분을 관찰로 보완한다.
- 순서: 익숙한 콩 캐릭터를 보고 가린다 → 기억나는 데까지 그린다 → 막힌 부분만 원본을 다시 본다 → 원본을 가리고 그 부분을 이어 그린다.
- 확인: 무엇을 다시 봐야 하는지 스스로 짚었나요?
- 더 쉽게: 가리기를 취소하고 모작으로 마무리한다. 실패로 기록하지 않는다.

**D33. 다음 연습에서 기억 꺼내기**
- 핵심: 이전에 익힌 큰 형태를 다시 떠올린다.
- 순서: 이전 수업에서 골랐던 캐릭터 이름을 본다 → 원본 없이 큰 몸과 특징 2개를 그린다 → 원본을 열어 한 곳을 보완한다.
- 확인: 기억한 부분과 다시 확인한 부분을 구별했나요?
- 더 쉽게: 해당 캐릭터의 작은 미리보기를 잠깐 보거나 처음부터 옆에 둔다.

**D34. 기억 그림 마무리**
- 핵심: 기억·비교·보완의 순서를 사용한다.
- 순서: 익숙한 캐릭터 하나를 고른다 → 주요 특징을 말하거나 선택한다 → 가리고 그린다 → 열어서 한 곳만 보완한다.
- 확인: 큰 특징 2개를 떠올렸나요? 다시 보고 보완할 곳을 하나 찾았나요?
- 더 쉽게: 원본을 가리는 대신 세부만 숨긴 큰 덩어리 힌트를 제공한다.

### 5단계: 간단한 형태·표정·포즈 변형 — 8개

**D35. 입 하나로 기분 바꾸기**
- 핵심: 한 부분만 바꿔 본다.
- 예제: 둥근 얼굴에 점 눈과 짧은 입을 가진 콩 캐릭터. 부리가 있는 병아리를 억지로 입 캐릭터로 바꾸지 않는다.
- 순서: 익숙한 얼굴을 한 번 그린다 → 눈과 얼굴은 그대로 둔다 → 입을 위로 휜 짧은 선으로 바꾼다 → 기본 예제와 비교한다.
- 확인: 얼굴·눈을 유지하면서 입만 바꿨나요?
- 더 쉽게: 얼굴과 눈이 있는 빈 템플릿에 입만 넣는다.

**D36. 눈을 감은 표정**
- 핵심: 눈 모양만 바꿔 본다.
- 순서: 기본 얼굴을 그린다 → 눈 점 대신 짧은 곡선 2개를 그린다 → 원래 눈 높이와 비교한다.
- 확인: 눈 위치를 크게 옮기지 않고 모양을 바꿨나요?
- 더 쉽게: 눈 위치를 연한 점으로 표시한다.

**D37. 토끼 귀 길이 바꾸기**
- 핵심: 길이 하나를 의도적으로 바꾼다.
- 순서: 토끼 얼굴을 그린다 → 원래 귀 밑 위치를 표시한다 → 그 자리에서 귀 끝만 더 높이 잡는다 → 긴 귀를 잇는다.
- 확인: 귀가 붙는 위치는 유지하고 길이를 바꿨나요?
- 더 쉽게: 원래 얼굴은 제공하고 귀 1개만 늘린다.

**D38. 몸을 조금 납작하게**
- 핵심: 높이와 폭 중 하나만 바꾼다.
- 순서: 콩 캐릭터의 폭은 원본과 비슷하게 잡는다 → 위·아래 간격을 조금 줄인다 → 새 몸 외곽 → 그 안에 얼굴을 넣는다.
- 확인: 무엇을 줄였고 무엇을 유지했는지 구분했나요?
- 더 쉽게: 원본과 납작한 예제를 나란히 보여주고 후자를 따라간다.

**D39. 머리를 조금 크게**
- 핵심: 머리·몸 크기 관계를 바꾼다.
- 순서: 곰 인형의 몸 위치를 유지한다 → 원본보다 큰 머리 자리 표시 → 귀와 얼굴 배치 → 원본과 느낌 비교.
- 확인: 몸은 두고 머리 크기를 바꾸었나요?
- 더 쉽게: 같은 몸 위에 크기가 다른 머리 틀 2개 중 하나를 선택한다.

**D40. 팔 하나 들어 인사하기**
- 핵심: 연결점을 유지한 채 방향을 바꾼다.
- 순서: 곰 인형의 머리와 몸을 그린다 → 한쪽 팔이 붙는 점을 찾는다 → 그 점에서 위쪽으로 짧은 타원 팔을 그린다 → 반대 팔은 기본 자세로 둔다.
- 확인: 팔 시작점은 유지하고 팔 끝의 방향을 바꿨나요?
- 더 쉽게: 몸과 팔 시작점이 있는 예제에 한쪽 팔만 넣는다.

**D41. 귀 하나 접기**
- 핵심: 큰 특징 하나를 바꿔도 같은 캐릭터임을 유지한다.
- 순서: 기본 토끼의 얼굴과 한쪽 귀를 그린다 → 다른 귀의 중간 위치를 짚는다 → 접힌 예제의 위·아래 두 덩어리를 보고 귀 하나를 접어 그린다.
- 확인: 바꾼 귀 외에 얼굴·반대 귀를 유지했나요?
- 더 쉽게: 접힌 귀의 연한 밑그림을 따라간다.

**D42. 내가 고른 한 가지 변형**
- 핵심: 변화와 유지 요소를 의식적으로 선택한다.
- 순서: 지금까지 그린 캐릭터를 고른다 → 입·눈·귀·몸 폭·팔 방향 중 하나를 고른다 → 나머지는 유지하며 바꾼다 → 무엇을 바꿨는지 말하거나 선택한다.
- 확인: 바꾼 것 1개와 그대로 둔 것 1개를 짚었나요?
- 더 쉽게: D35 또는 D40의 완성 비교 예제를 보고 같은 변화를 따라 한다.

### 6단계: 스스로 도형화 — 10개

**D43. 새 캐릭터에서 큰 덩어리 고르기**
- 핵심: 제공된 도형 없이 큰 형태를 찾는다.
- 예제: 머리·몸이 하나인 배 모양 새. 세부 무늬 없음.
- 순서: 완성 예제를 본다 → 가장 큰 덩어리를 손가락으로 둘러본다 → 원·타원·둥근 네모 중 가까운 모양을 고른다 → 그 덩어리를 원본 위에 그린다.
- 확인: 내가 선택한 도형이 어떤 큰 부분을 나타내는지 설명했나요?
- 더 쉽게: 타원과 둥근 네모 두 가지 겹침 예제 중 더 가까운 것을 선택한다.

**D44. 새 동물 얼굴을 세 덩어리로**
- 핵심: 얼굴과 귀를 스스로 분리한다.
- 순서: 새로운 햄스터 얼굴을 본다 → 큰 얼굴 덩어리 표시 → 귀 2개를 작은 덩어리로 표시 → 겹침을 숨기고 다시 켜서 관계를 본다.
- 확인: 얼굴과 귀를 구별할 수 있게 표시했나요?
- 더 쉽게: 귀 하나의 위치만 힌트로 제공한다.

**D45. 몸이 있는 캐릭터 나누기**
- 핵심: 머리·몸·팔다리를 스스로 구별한다.
- 예제: 손가락·발가락이 없는 단순 곰 인형.
- 순서: 머리와 몸의 큰 덩어리 2개 → 팔이 붙는 위치 → 짧은 팔·다리 덩어리. 눈·코는 생략한다.
- 확인: 얼굴 세부 없이도 각 부위의 위치를 나타냈나요?
- 더 쉽게: 머리·몸만 표시하고 팔다리는 다음에 이어간다.

**D46. 큰 도형을 옆에 다시 조립하기**
- 핵심: 원본 위의 분석을 빈 공간으로 옮긴다.
- 순서: D45에서 나눈 밑그림을 본다 → 옆 빈 공간에 머리 → 몸 → 팔·다리 순서로 배치한다 → 원본과 큰 덩어리의 위치만 비교한다.
- 확인: 분석한 덩어리를 다른 공간에 다시 놓았나요?
- 더 쉽게: 옆 공간에 머리의 크기 틀만 제공한다.

**D47. 무엇이 앞에 있을까**
- 핵심: 겹친 모양의 앞뒤 관계를 구별한다.
- 예제: 몸 앞에 작은 공을 든 곰 인형. 손은 작은 둥근 덩어리.
- 순서: 몸 덩어리를 그린다 → 몸 앞의 공을 그린다 → 공에 가려지는 몸 선을 짚는다 → 별도 완성 선에서 가려진 부분을 생략한다.
- 확인: 공 뒤에 가려지는 몸 선을 찾았나요?
- 더 쉽게: 예제에서 공과 몸만 두 색으로 구분한다.

**D48. 앞의 귀와 뒤의 귀**
- 핵심: 겹침 때문에 일부만 보이는 부위를 이해한다.
- 예제: 고개가 약간 돌아가 한쪽 귀가 조금 가려진 토끼.
- 순서: 머리 덩어리 → 앞쪽 귀 → 뒤쪽 귀의 보이는 부분 → 밑그림 전체와 완성 외곽을 번갈아 본다.
- 확인: 뒤쪽 귀가 없어지는 것이 아니라 일부 가려진 것임을 짚었나요?
- 더 쉽게: 두 귀가 겹치는 부분만 확대해 따라간다.

**D49. 둥근 얼굴의 방향 표시**
- 핵심: 얼굴이 향하는 쪽을 안내선으로 나타낸다.
- 순서: 정면 콩 얼굴과 살짝 돌아간 예제를 비교한다 → 둥근 얼굴 덩어리 → 얼굴 가운데를 지나는 휜 안내선을 예제처럼 넣는다 → 안내선 근처에 코 위치만 표시한다.
- 확인: 안내선이 얼굴 방향을 알려준다는 것을 확인했나요?
- 더 쉽게: 정면과 옆으로 휜 안내선 두 예제 중 하나를 골라 따라간다. 입체 원근 규칙 전체를 설명하지 않는다.

**D50. 돌아간 얼굴에 눈 놓기**
- 핵심: 얼굴 방향에 맞춰 눈 위치를 바꾼다.
- 순서: D49의 둥근 얼굴과 안내선 → 예제를 보며 가까운 눈 위치 → 반대쪽 눈 위치 → 원본과 얼굴이 향한 방향 비교.
- 확인: 정면 눈을 그대로 두지 않고 예제의 방향에 맞춰 위치를 바꿨나요?
- 더 쉽게: 두 눈 위치를 연한 점으로 제시한다.

**D51. 네모 로봇을 덩어리로 만들기**
- 핵심: 다른 형태의 캐릭터도 큰 덩어리로 조립한다.
- 순서: 새 로봇 예제를 본다 → 둥근 네모 머리 → 직사각 몸 → 짧은 팔다리 → 눈. 도형의 크기 관계 하나만 비교한다.
- 확인: 동물 캐릭터에서 쓰던 ‘큰 덩어리 먼저’ 순서를 로봇에도 적용했나요?
- 더 쉽게: 몸의 위치가 표시된 머리·몸 두 덩어리 과제로 줄인다.

**D52. 도형화 마무리**
- 핵심: 새 예제를 나누고 다시 조립한다.
- 순서: 처음 보는 단순 동물 1개를 고른다 → 원본 위에 큰 덩어리 2~4개를 표시한다 → 옆에 같은 덩어리를 다시 놓는다 → 대표 특징 1개만 더한다.
- 확인: 내가 고른 덩어리와 붙는 위치를 설명했나요? 겹친 곳이 있다면 앞쪽을 구분했나요?
- 더 쉽게: 도형 후보를 2가지씩 제공하고 조립 위치는 일부 표시한다.

### 7단계: 쉬운 크로키 — 8개

크로키는 여기서 ‘자세의 큰 방향을 간단하게 옮기는 연습’으로 설명한다. 초기에는 정해진 시간 안에 끝내지 않아도 된다. 막대인간은 배우는 표시 방법이지 완성 그림 점수의 기준이 아니다. 캐릭터·마네킹 자세 예제를 사용하고 인체 해부학·근육 묘사는 요구하지 않는다.

**D53. 서 있는 자세의 가운데 길**
- 핵심: 머리에서 몸을 지나 발까지 이어지는 방향을 찾는다.
- 순서: 편하게 서 있는 마네킹 예제를 본다 → 머리 자리 동그라미 → 몸 가운데의 긴 방향선 → 발이 놓이는 곳을 짧게 표시한다.
- 확인: 머리·몸·발이 놓인 큰 방향을 나타냈나요?
- 더 쉽게: 예제 위에 가운데 길만 따라간다.

**D54. 기울어진 자세**
- 핵심: 몸이 어느 쪽으로 기우는지 본다.
- 순서: 곧게 선 예제와 옆으로 기운 예제를 본다 → 기운 예제 머리 위치 → 몸의 기울어진 방향선 → 발 위치. 얼굴은 그리지 않는다.
- 확인: 기울어진 방향이 원본과 같은 쪽인가요?
- 더 쉽게: 몸의 방향선 2개 중 원본과 비슷한 쪽을 선택한 뒤 따라간다.

**D55. 한 팔을 든 자세**
- 핵심: 팔의 시작점과 끝 방향을 연결한다.
- 순서: 머리와 몸 방향선 → 팔이 붙는 양쪽 위치 → 올라간 팔 끝 위치 → 짧은 선으로 연결. 손가락은 생략한다.
- 확인: 어느 팔이 올라갔는지 선만으로 구별되나요?
- 더 쉽게: 몸은 제공하고 올라간 팔 한쪽만 그린다.

**D56. 앉은 자세**
- 핵심: 몸과 다리가 꺾이는 큰 방향을 본다.
- 순서: 옆에서 앉은 단순 마네킹의 머리 → 몸 방향 → 앞으로 나온 허벅지 방향 → 아래로 내려가는 다리 방향을 짧은 선으로 잇는다.
- 확인: 서 있는 자세와 다른 다리의 꺾임이 보이나요?
- 더 쉽게: 머리·몸이 있는 예제에서 다리의 두 선만 따라간다.

**D57. 두 손을 위로 든 자세**
- 핵심: 양팔이 향하는 방향을 비교한다.
- 순서: 머리·몸 가운데 길 → 양쪽 팔 시작점 → 양쪽 팔 끝 위치 → 시작점과 끝을 잇는다.
- 확인: 두 팔이 위로 향하는 것을 나타냈나요?
- 더 쉽게: 한쪽 팔을 제공하고 반대쪽만 넣는다.

**D58. 한 발 내디딘 자세**
- 핵심: 양다리가 다른 방향을 향하는 것을 본다.
- 순서: 옆모습의 쉬운 걷기 예제에서 머리·몸 → 앞쪽 발 위치 → 뒤쪽 발 위치 → 몸 아래에서 두 발로 각각 잇는다.
- 확인: 앞다리와 뒷다리의 방향을 구별했나요?
- 더 쉽게: 두 발 위치를 미리 표시한다. 자연스러운 보행의 세부는 아직 평가하지 않는다.

**D59. 막대 자세에 몸 덩어리 입히기**
- 핵심: 방향선을 유지하면서 단순 몸을 얹는다.
- 순서: D55 또는 D57의 막대 자세 → 몸 주위에 작은 타원 → 팔 선 주위에 짧은 덩어리 → 머리 원. 손·발 세부는 생략한다.
- 확인: 덩어리를 더한 뒤에도 처음의 팔 방향이 보이나요?
- 더 쉽게: 몸과 머리만 덧붙인다.

**D60. 쉬운 크로키 마무리**
- 핵심: 새 자세의 큰 방향을 선택해서 기록한다.
- 순서: 서기·기울기·팔 들기·앉기 중 검수된 새 예제 1개 → 머리·몸 방향 → 가장 중요한 팔 또는 다리 방향 → 원본과 방향만 비교한다.
- 확인: 자세에서 중요한 방향 1~2개를 표현했나요?
- 더 쉽게: 원본 위에 방향선을 먼저 따라간 뒤 옆 공간에 다시 그린다. 빠른 타이머는 사용하지 않는다.

### 8단계: 캐릭터 포즈와 표정 — 10개

**D61. 같은 캐릭터의 기준 특징**
- 핵심: 여러 번 그려도 유지할 특징을 정한다.
- 예제: 사용자에게 익숙한 둥근 곰 또는 콩 캐릭터 1개.
- 순서: 원본에서 머리·몸 비율, 귀 모양, 눈 간격 중 2개를 고른다 → 기준 그림을 한 번 그린다 → 고른 두 특징을 표시한다.
- 확인: 앞으로 유지할 특징 2개를 골랐나요?
- 더 쉽게: 후보 특징을 그림으로 표시하고 선택하게 한다.

**D62. 반가운 표정**
- 핵심: 기준 특징을 유지하며 감정을 바꾼다.
- 순서: 기준 얼굴 → 예제의 웃는 눈 또는 입 중 하나를 선택 → 선택한 부분만 바꾸기 → 기준 특징 2개 확인.
- 확인: 같은 캐릭터로 보일 특징을 유지했나요?
- 더 쉽게: D35 또는 D36의 표정 도움으로 돌아간다.

**D63. 놀란 표정**
- 핵심: 눈·입의 변화로 한 감정을 전달한다.
- 순서: 기준 얼굴 → 놀란 예제의 눈 또는 둥근 입 선택 → 크기와 위치를 보고 넣기 → 기준 얼굴과 비교. 두 부분을 동시에 바꾸기 어려우면 입만 바꾼다.
- 확인: 무엇을 바꿔 놀람을 표현했는지 짚었나요?
- 더 쉽게: 기본 얼굴 위에 입만 넣는다.

**D64. 풀이 죽은 표정**
- 핵심: 눈이나 입의 방향이 주는 느낌을 관찰한다.
- 순서: 기준 얼굴 → 처진 눈 또는 입 예제 선택 → 한 부분을 바꾸기 → 앞선 표정과 나란히 보고 차이를 설명한다.
- 확인: 반가운 표정과 어떤 선의 방향이 다른지 찾았나요?
- 더 쉽게: 표정 후보 2개를 따라 그린 뒤 더 원하는 쪽을 고른다.

**D65. 같은 얼굴의 표정 모음**
- 핵심: 표정을 바꿔도 캐릭터의 특징을 유지한다.
- 순서: D62~D64의 그림을 나란히 놓는다 → 기준 특징이 크게 달라진 한 그림을 고른다 → 그 부분 하나만 수정한다 → 표정 3종을 저장한다.

- 더 쉽게: 두 표정만 비교한다. 3장을 새로 그리게 하지 않는다.

**D66. 인사하는 캐릭터**
- 핵심: 쉬운 자세를 자신의 기준 캐릭터에 적용한다.

- 확인: 인사 방향과 기준 특징이 함께 보이나요?

**D67. 앉아 쉬는 캐릭터**

- 확인: 서 있는 모습과 다리 방향이 다르면서 같은 캐릭터의 특징이 남았나요?

**D68. 한 발 걷는 캐릭터**
- 핵심: 앞뒤로 갈라지는 다리 방향을 캐릭터에 적용한다.

- 확인: 두 다리의 방향을 구별할 수 있나요?
- 더 쉽게: 짧은 다리의 옆모습 예제와 발 위치 도움을 제공한다.

**D69. 감정이 있는 자세**
- 핵심: 자세 하나와 표정 하나를 같은 의도로 맞춘다.
- 순서: ‘반갑게 인사’ 또는 ‘앉아서 쉬기’ 중 선택 → D66 또는 D67의 몸 → 이미 배운 표정 한 가지 → 두 요소가 같은 상황을 나타내는지 본다.
- 확인: 이 그림이 어떤 상황인지 짧게 설명했나요?
- 더 쉽게: 기존 포즈 그림에 표정만 바꾼다.

**D70. 캐릭터 일관성 마무리**
- 핵심: 여러 자세에서도 기준 특징을 유지한다.
- 순서: 기준 그림과 D66~D69 중 두 그림을 고른다 → 유지한 특징 2개 비교 → 달라진 부분 하나 수정 → 작은 포즈 모음으로 저장한다.
- 확인: 다른 자세에서도 같은 캐릭터임을 알려주는 특징을 짚었나요?
- 더 쉽게: 기준 그림과 포즈 하나만 비교한다.

### 9단계: 오리지널 캐릭터 제작 — 10개

**D71. 누구를 위한 캐릭터인지 정하기**
- 핵심: 그릴 캐릭터의 역할을 정한다.
- 순서: ‘게임 길잡이 / 앱에서 반겨주는 친구 / 작은 모험가’ 중 고른다 → 성격 한 단어 선택 → 동물·식물·작은 물건 등 모티프 선택 → 작은 모양 낙서 하나를 그린다.
- 확인: 역할과 성격을 한 문장으로 설명했나요?
- 더 쉽게: 역할·성격·모티프를 각각 두 개의 선택지에서 고른다.

**D72. 큰 몸 모양 후보 두 개**
- 핵심: 큰 형태로 서로 다른 인상을 만든다.
- 순서: 선택한 모티프를 둥근 형태로 작게 그린다 → 두 번째는 길쭉한 형태로 그린다 → 세부를 빼고 원하는 느낌에 가까운 쪽을 고른다.
- 확인: 선택 이유를 ‘더 포근해 보여요’처럼 말하거나 고를 수 있나요?
- 더 쉽게: 제시된 둥근 틀·긴 틀 안에서 눈 위치만 넣어 비교한다.

**D73. 알아볼 특징 하나 만들기**
- 핵심: 복잡한 장식 없이 구별되는 특징을 만든다.
- 순서: D72에서 고른 몸 → 귀 한쪽·잎사귀 하나·독특한 꼬리 끝 중 적합한 후보 선택 → 한 특징만 추가 → 작은 크기로 봤을 때 보이는지 확인.
- 확인: 내 캐릭터의 대표 특징을 하나 짚었나요?
- 더 쉽게: 이미 배운 귀 길이 또는 머리 모양 변형을 사용한다.

**D74. 정면 기본형 완성**
- 핵심: 반복해서 그릴 수 있는 기본형을 만든다.
- 순서: 큰 머리·몸 → 연결 부위 → 대표 특징 → 눈·입 → 불필요하게 복잡한 선 하나를 줄인다. 형태를 정하는 데 집중한다.
- 확인: 다음에도 따라 그릴 기준 한 장이 생겼나요?
- 더 쉽게: 머리와 몸이 하나인 마스코트로 구성한다.

**D75. 내 캐릭터를 한 번 더 그리기**
- 핵심: 자신이 만든 규칙을 재현한다.
- 순서: D74를 옆에 둔다 → 같은 큰 덩어리로 시작한다 → 대표 특징 → 얼굴 → 처음 그림과 머리·몸 관계 하나를 비교한다.
- 확인: 자신의 원본을 보고 같은 특징을 다시 표현했나요?
- 더 쉽게: D74 위에 도형화를 한 뒤 옆에 옮긴다. 오리지널 제작에서도 참고 그림 사용을 허용한다.

**D76. 기본 색 두 가지 고르기**
- 핵심: 작은 색 선택으로 기본형을 정리한다.
- 순서: 기존 선화 복사본을 쓴다 → 넓은 부분의 주색 하나 → 특징을 구별할 보조색 하나 → 작게 보며 구별되는지 확인. 선화 원본은 보존한다.
- 확인: 큰 부분과 대표 특징이 구별되나요?
- 더 쉽게: 미리 검수된 두 색 조합 3개 중 하나를 고른다. 종이에서는 색연필이 없으면 연필의 연함·진함 두 가지로 대체한다.

**D77. 내 캐릭터의 첫 표정**
- 핵심: 기본형을 유지하면서 감정을 하나 만든다.
- 순서: D74 기본 얼굴 → 반가움 또는 놀람 중 선택 → 눈·입 중 필요한 부분만 바꿈 → 대표 특징 확인.
- 확인: 기본형과 같은 캐릭터로 보이는 특징이 남았나요?
- 더 쉽게: 얼굴 틀은 복사·트레이싱하고 표정 부분만 직접 넣는다.

**D78. 표정 세 장 묶기**
- 핵심: 같은 기본형을 일관된 표정 묶음으로 만든다.
- 순서: D74의 기본 표정과 D77을 모은다 → 부족한 감정 하나를 새로 그린다 → 세 장의 대표 특징 비교 → 한 곳만 수정한다.
- 확인: 기본·반가움·놀람 등 서로 다른 표정 3개가 있나요?
- 더 쉽게: 두 장부터 저장하고 세 번째는 다음 연습으로 나눈다.

**D79. 포즈 세 장 묶기**
- 핵심: 기본형에 배운 두 자세를 추가한다.
- 순서: D74의 기본 자세를 첫 장으로 쓴다 → 이번 연습에서 인사 자세 한 장을 그린다 → 다음 연습에서 앉기 또는 걷기 한 장을 그린다 → 대표 특징을 비교한다.
- 확인: 기본 자세와 다른 자세 2개에서 특징을 유지했나요?
- 더 쉽게: 기본형과 인사 자세 두 장부터 저장한다. D79는 처음부터 두 번의 10~20분 연습으로 나누어도 된다.

**D80. 첫 캐릭터 소개 카드**
- 핵심: 만든 캐릭터를 실제 사용 목적과 연결해 정리한다.
- 순서: 이름·역할·성격 입력 → 기본형·표정 3종·포즈 3종을 기존 그림에서 선택 → 대표 특징 2개 표시 → 게임·앱 화면용 작은 미리보기에서 확인 → 다음에 개선할 것 하나 선택.
- 확인: 캐릭터를 설명하고 다시 그릴 기준 자료가 있나요?
- 더 쉽게: 기본형 1장과 특징 2개만 먼저 카드에 담고 나머지는 이어서 완성한다.

D80은 입문 창작 프로젝트의 완성이다. 이후 다양한 각도·자연스러운 동작·빛과 그림자·복잡한 의상·제작용 리소스 정리는 별도 성장 과제로 이어간다. 인체 해부학·전문 애니메이션·모든 화풍을 이 80개만으로 익혔다고 표시하지 않는다.

## 6. D01에 그대로 사용할 초보자 안내 문구

### 준비

“오늘은 병아리의 큰 몸 선을 따라가 봐요. 예쁜 선을 만들려고 서두르지 않아도 돼요. 선이 휘어지는 방향 하나만 살펴볼게요.”

- 종이: 손바닥보다 약간 큰 예제를 인쇄하고 선이 비치는 종이를 얹는다. 종이가 움직이면 모서리를 고정한다. 인쇄가 어려우면 앱의 그리기 화면을 사용하거나 준비된 예제 파일을 이용할 방법을 안내한다. 종이 트레이싱 준비가 안 된 사용자를 바로 모작으로 넘기지 않는다.
- 앱 내 그리기: 연한 원본과 그 위의 사용자 선을 앱이 처음부터 분리한다. 사용자가 첫 수업 전에 레이어를 직접 설정할 필요가 없게 한다.
- 외부 iPad 그림 앱: 원본 불러오기 → 원본을 연하게 만들기 → 위에 새 레이어 추가 → 새 레이어에서 그리기. ‘레이어는 원본 위에 올리는 투명한 종이예요’라고 설명한다. 앱을 선택하면 그 앱에 맞는 버튼 안내를 제공하며 확인하지 않은 버튼 이름을 임의로 쓰지 않는다.

### 한 장씩 표시할 행동

1. “병아리 몸의 맨 위를 찾아보세요. 여기서 출발할 거예요.” 화면에는 시작점 하나만 표시한다.
2. “왼쪽으로 둥글게 내려가 볼게요. 한 번에 길게 그리기 어려우면 중간에서 연필을 떼어도 돼요.” 왼쪽 곡선만 강조한다.
3. “다시 맨 위로 가서 오른쪽으로 내려가요. 아래 가운데에서 앞의 선과 만나면 돼요.” 오른쪽 곡선만 강조한다.
4. “눈은 몸의 위쪽에 있어요. 원본의 눈 두 개 위에 작은 점을 넣어볼게요.” 정확한 원의 대칭은 요구하지 않는다.
5. “두 눈 사이보다 조금 아래의 작은 세모가 부리예요. 선 세 개를 하나씩 따라가요.”
6. “양옆의 굽은 선은 날개, 아래의 짧은 선은 다리예요. 하나씩 따라가고 오늘 그림을 마칠게요.” 어려우면 날개·다리는 다음 시도로 넘길 수 있다.

### 마무리 질문

- “몸 선을 어디서 시작했는지 짚어볼까요?”
- “몸·얼굴·날개 중 어디가 가장 어려웠나요?”

오늘의 진급 판단은 선의 매끈함이 아니다. 시작 위치를 이해하고 큰 형태를 따라가는 시도를 했는지 확인한다. 작품이 없는 상태에서는 ‘몸 비율이 좋아요’ 같은 평가를 만들지 않는다.

## 7. 막혔을 때의 분기와 보조 연습

기본은 캐릭터 과제 안에서 난이도를 줄이는 것이다. 아래 보조 연습은 사용자가 특정 어려움을 선택하거나 피드백 근거가 있을 때만 제안한다. 한 번에 하나, 2~5분 이내이며 더 짧게 끝나도 된다.

| 확인된 어려움 | 먼저 바꿀 도움 | 필요한 경우의 짧은 보조 | 돌아올 캐릭터 과제 |
|---|---|---|---|
| 어디서 시작할지 모르겠음 | 가장 큰 덩어리와 시작점 하나 표시 | 별도의 선 연습 없이 손가락으로 경로 한 번 짚기 | 해당 덩어리만 그리기 |
| 긴 곡선을 잇기 어려움 | 그림 확대, 곡선을 2~4구간으로 나누기 | 병아리 몸의 일부 곡선만 2~3번 | 같은 몸 외곽 이어 그리기 |
| 타원이 너무 낯설음 | 귀나 몸의 위·아래·양옆 점 표시 | 해당 귀 크기의 타원 2~3개 | 토끼 귀 하나 그리기 |
| 모서리에서 방향을 잃음 | 모서리만 확대, 방향 화살표 표시 | 로봇 머리 모서리 2~3개 | 로봇 얼굴의 한쪽 연결 |
| 부분이 자꾸 커짐 | 큰 몸을 먼저 두고 작은 부분 자리만 표시 | 도형 반복 대신 큰/작은 후보 두 개 비교 | 귀 또는 눈 하나 배치 |
| 얼굴 위치가 헷갈림 | 눈 높이와 얼굴 가운데의 짧은 도움선 | 별도 도형 연습 없이 점 2개 배치 | 실제 캐릭터 얼굴 완성 |
| 원본이 없으면 기억이 안 남 | 대표 특징 2개 글자·그림 힌트, 다시 보기 허용 | 외우기 시험 없이 특징을 짚거나 말하기 | 특징 2개만 그린 뒤 비교 |
| 포즈가 어려움 | 얼굴·손·발 세부를 숨기고 몸 방향만 표시 | 인체 연습 대신 현재 자세의 방향선 1~2번 | 막대 자세에 머리·몸만 얹기 |
| 지루하거나 하기 싫음 | 같은 기술의 다른 캐릭터 또는 좋아하는 기존 과제로 변경 | 보조 연습을 추가하지 않음 | 5분 축소 과제로 마무리 |

피드백 문구의 구조는 ‘그림에서 보이는 사실 → 그렇게 보이는 이유 → 지금 할 행동’이다.

예시: “이번 그림은 귀가 얼굴 옆 가운데에서 시작해서 원본보다 아래에 붙어 보여요. 다음 그림에서는 귀의 시작점 두 개만 얼굴 위쪽에 먼저 찍어볼게요.” 이것은 해당 차이가 실제로 관찰된 경우에만 사용한다.

반대로 “재능이 있어요”, “노력이 부족해요”, “열 번 더 그리면 해결돼요”처럼 근거가 없는 판단을 자동으로 넣지 않는다.

## 8. 연이앱에 필요한 학습 화면

기존 자기계발 메뉴 아래에 **그림 연습**을 배치한다. 정확한 기존 메뉴명·경로·저장 방식은 개발방에서 현재 코드를 확인한 뒤 정한다. 새 독립 앱이나 별도 로그인부터 만들지 않는다.

### 기본 흐름

1. 그림 연습 홈: 현재 단계, 오늘 할 과제 하나, ‘이어서 연습하기’ 큰 버튼. 사용자가 길게 내려야 시작할 수 없게 한다.
2. 수업 화면: 예제와 지금 그릴 한 행동. 원본·밑그림·사용자 선을 구분하고 현재 행동에 필요한 도움만 보인다.
3. 도움: 다시 보기 / 더 쉽게 / 같은 수준의 다른 그림 / 잠깐 쉬기.
4. 마무리: 간단한 자기확인, 그림 저장 또는 사진 남기기, 오늘의 정리.
5. 내 그림: 날짜·과제·단계별 보기, 같은 유형의 이전 그림과 나란히 비교, 기록 수정·삭제·내보내기.
6. 학습 지도: 9단계의 설명과 현재 위치. 수업 수를 실력 점수로 표현하지 않는다.

### 그리기 방식

- **앱 안에서 그리기:** 트레이싱 원본, 단계별 선, 사용자 선을 분리한다. 되돌리기·다시 실행·지우개·확대·원본 숨기기·이어 그리기를 기본 제공한다. 초반 도구는 소수만 노출한다.
- **종이에 그리기:** 똑같은 수업 설명과 인쇄 가능한 원본을 제공한다. 사진을 남기지 않아도 연습 시도·자기확인을 저장할 수 있다. 다만 그림을 보지 않은 평가는 제공하지 않는다.
- **외부 그림 앱:** 예제 저장과 결과 이미지 가져오기를 지원한다. 외부 앱의 상세 안내는 앱별로 검증된 안내만 제공한다.
- 손떨림 보정·도형 자동 완성을 사용하면 도움 사용 사실을 기록할 수 있다. 이를 쓰지 않았다고 보상하거나, 사용했다고 실패 처리하지 않는다.
- Apple Pencil의 손바닥 오입력, 화면 스크롤과 그리기 충돌, 회전 후 좌표 어긋남은 실제 지원 기기에서 검증한다. 브라우저의 지원 범위를 확인하지 않고 완전한 손바닥 감지를 약속하지 않는다.
- 휴대폰에서는 예제 확인·사진 제출·기록 열람을 우선 편하게 만든다. 작은 화면에 모든 캔버스 도구와 설명을 한꺼번에 넣지 않는다.
- 초기 설정은 종이/앱 내 그리기/외부 그림 앱, 5분/10분/20분 정도만 묻는다. 복잡한 진단 설문으로 시작을 막지 않는다.

## 9. 매번 앱을 업데이트하지 않아도 이어지는 구조

### 처음부터 포함할 것

- D01~D80의 목표·원고·시각 예제·더 쉬운 버전·목표 확인 질문.
- 이 문서의 복습·도움 조절·진급 규칙.
- 11장의 지속 연습 과제 4종.
- 관련된 이전 수업으로 돌아가는 연결 관계.
- 예제 변경은 같은 목표와 난이도로 검수된 대체 예제만 사용한다. 캐릭터 이름·표정·포즈를 무작위로 섞어 과제를 자동 생성하지 않는다.

### 앱 기능과 수업 내용을 분리

수업을 매번 화면 코드에 직접 쓰지 않고, 앱이 읽는 독립적인 콘텐츠 팩으로 관리한다. 최초 80개 팩은 실제 필요한 자료와 함께 배포한다. 이후 코드 변경 없이 콘텐츠 팩을 추가하려면 원격 콘텐츠 공급과 버전 선택·검증 기능이 처음부터 있어야 한다. 단지 파일을 나눠 놓은 것만으로 배포가 필요 없어지는 것은 아니다.

| 변경의 종류 | 처리 방식 | 사용자 관점 |
|---|---|---|
| 오늘 과제·복습·도움 수준 선택 | 검수된 규칙과 현재 진도에서 계산 | 연습 후 자동으로 다음 추천이 바뀜 |
| 같은 수준의 예제 변경 | 이미 포함된 검수 예제 선택 | 업데이트 없이 다른 그림 연습 |
| 기존 틀 안의 새 수업·새 예제 추가 | 새 콘텐츠 팩 제작·검수·게시 | 콘텐츠가 추가되어 이어서 학습 |
| 새로운 도구·새로운 화면·오류 수정 | 앱 코드 수정·검증·배포 | 필요할 때 앱 기능 업데이트 |

‘업데이트가 필요 없다’는 말은 현재 설계된 학습 흐름을 매 수업마다 개발하지 않아도 된다는 뜻이다. 새로운 교육 콘텐츠 자체의 제작·검수까지 없어지는 것은 아니다.

### 최소 콘텐츠 항목

| 항목 | 역할 |
|---|---|
| 고정 수업 ID·단계 ID·콘텐츠 버전 | 설명이 바뀌어도 과거 기록과 연결 |
| 제목·핵심 목표·쉬운 설명·권장 시간 | 수업 시작 화면 |
| 선행 목표·권장 도움 수준 | 무리한 난이도 상승 방지 |
| 예제 ID·같은 목표의 대체 예제 ID | 실제 그림과 원고 일치 |
| 단계별 행동·해당 이미지·시작 위치 | 무엇을 어디서 그릴지 안내 |
| 더 쉬운 과제·5분 과제·선택 보조 연습 | 어려움·시간에 맞춘 조절 |
| 확인 질문·그림에서 볼 기준 | 오늘 목표의 확인 |
| 다음 후보·복습 후보 | 규칙에 따른 추천 |
| 예제 제작 출처·이용 조건·검수 상태 | 앱에서 사용할 자료 관리 |

콘텐츠에서 실행 코드를 받아 실행하지 않는다. 수업 데이터와 이미지의 필수 항목, 이미지 접근 가능 여부, 단계 순서, 선행 수업 연결을 게시 전에 검증한다.

### 업데이트 중 기록 보존

- 학습 시도는 당시 수업 ID·예제 ID·콘텐츠 버전을 함께 남긴다.
- 이미 시작한 수업은 가능한 한 당시 버전으로 마친다. 새 버전이 나왔다고 작성 중인 그림을 갈아끼우지 않는다.
- 게시 실패·잘못된 새 팩·네트워크 실패 시 마지막으로 검증된 팩을 유지한다.
- 수업 순서 변경이나 이미지 교체 때문에 완료한 수업·그림·자기확인이 사라지지 않게 한다.
- 저장 실패를 저장 완료로 표시하지 않고, 로컬의 미전송 그림과 동기화 상태를 보존한다.
- 같은 그림이 저장 재시도 때 중복 생성되지 않도록 시도 식별자를 사용한다. 다른 시도의 새 그림은 별도 작품으로 남긴다.

## 10. AI 선생님의 역할과 피드백

### AI 없이도 반드시 되는 것

수업 열기, 순서 보기, 트레이싱과 모작, 그림·사진 저장, 자기확인, 복습 선택, 다음 과제 추천, 이전 그림 비교, 80개 과정 완료. 사전 작성한 설명과 명시적 규칙으로 동작한다.

### 이미지 피드백을 사용할 때

- 기존 연이의 이미지 분석 지원 여부·사용량 조건·비용을 개발방에서 확인한다. 새 유료 서비스 연결을 기본 전제로 만들지 않는다.
- 이미지 분석은 사용자가 ‘그림 피드백 받기’를 선택했을 때 실행한다. 선을 그릴 때마다 요청하지 않는다.
- 입력은 해당 그림, 가능하면 원본 예제, 오늘 목표, 사용자 질문, 비교를 허용한 이전 그림으로 제한한다.
- 출력은 관찰한 사실, 근거 부위, 오늘 목표와 관련된 장점, 우선 수정 1개, 쉬운 다음 행동, 확인할 수 없는 부분을 구분한다.
- 원본이 없거나 사진이 어둡고 잘렸다면 비교 판정을 보류하고 필요한 부분만 다시 요청한다. 없는 원본을 보았다고 주장하지 않는다.
- 사용자가 ‘어렵다’고 답한 사실은 AI가 보기 좋다고 평가했더라도 다음 과제 선택에 반영한다.
- AI 피드백만으로 단계가 강제로 올라가거나, 사용자 자기확인이 덮어써지지 않게 한다.
- AI 실패·한도·네트워크 문제에도 기본 수업과 저장은 계속 사용할 수 있게 한다. 이때는 ‘그림 분석은 아직 받지 않았어요’라고 사실대로 표시하고 자기확인으로 진행한다.
- 원본 그림을 자동 보정하거나 대신 완성한 결과를 사용자의 실력 향상으로 기록하지 않는다. 수정 시범이 필요하면 사용자의 원본과 분리된 별도 시범으로 보여준다.

### 사용자에게 보여줄 마무리 예시 구조

- 오늘 배운 내용: 오늘의 목표를 한 문장으로 설명.
- 잘된 부분: 관찰 근거가 있으면 구체적으로 설명. 자기확인만 있다면 ‘스스로 시작 위치를 찾았다고 체크했어요’처럼 근거를 밝힘.
- 가장 먼저 고칠 부분: 기본 1개, 최대 3개. 근거가 없으면 ‘그림을 확인한 뒤 정할게요’.
- 필요한 보조 연습: 없으면 ‘오늘은 필요 없어요’. 무조건 채워 넣지 않음.
- 다음 연습: 다음 과제와 그 과제를 고른 이유.
- 현재 학습 단계: 단계명 + 도움 사용 정도. 숫자 실력 점수 없음.

## 11. 80개 이후에도 이어지는 지속 연습

새로운 낯선 기술을 자동으로 가르쳤다고 간주하지 않는다. 이미 배운 기술을 자신의 캐릭터와 새로운 상황에 적용하는 네 가지 프로젝트를 처음부터 제공한다. 한 프로젝트는 10~20분 연습 네 번 정도로 나눠 쓸 수 있으며 완료 기한은 없다.

| 프로젝트 | 1회 | 2회 | 3회 | 4회 | 확인 기준 |
|---|---|---|---|---|---|
| C01. 오늘의 기분 친구 | 기분 하나 선택, 기준 얼굴 확인 | 해당 표정 한 장 | 같은 캐릭터의 다른 표정 한 장 | 두 장의 특징 비교·한 곳 수정 | 감정은 달라도 대표 특징 유지 |
| C02. 작은 하루 포즈 | 이미 배운 인사·앉기·걷기 중 상황 선택 | 방향선으로 자세 잡기 | 큰 덩어리와 특징 추가 | 표정 추가·기준형과 비교 | 방향과 캐릭터 특징 함께 전달 |
| C03. 친구 캐릭터 만들기 | 기존 캐릭터와 다른 역할 하나 선택 | 큰 몸 모양 하나 변경 | 구별되는 특징 하나 설계 | 두 캐릭터를 나란히 정리 | 구별점과 공통점을 설명 |
| C04. 게임·앱용 작은 묶음 | 쓰일 화면·역할 선택 | 기본형을 작은 표시 크기로 확인 | 필요한 표정 또는 포즈 하나 추가 | 기본형·변형·이름 카드 정리 | 작게 보아도 중요한 특징 확인 가능 |

같은 프로젝트를 다시 할 때는 상황·모티프·유지할 특징·바꿀 요소 중 하나만 바꾼다. 새로운 각도나 자세가 필요한데 아직 배우지 않았다면 임의로 과제를 던지지 않고 배운 자세로 제한하거나 관련 수업을 추천한다.

한 곳에서 반복해서 막히면 C01~C04를 무작정 반복하지 않고 D35~D70의 해당 기술로 돌아간다. 새 학습 분야를 확장할 때는 검수한 콘텐츠 팩으로 추가한다.

## 12. 예제 그림과 순서 그림 제작 요구사항

이 문서에는 80개 과제의 예제 사양이 있으며, 모든 시각 자료가 이미 제작된 상태는 아니다. 개발방은 예제 제작 현황을 따로 관리해야 한다.

1. 처음에는 단순한 선화, 선명한 대비, 충분한 빈 공간, 큰 표시 크기를 사용한다. 복잡한 채색 완성작을 첫 트레이싱 예제로 쓰지 않는다.
2. 기본 캐릭터는 병아리·콩·곰 얼굴·토끼 얼굴·둥근 네모 로봇·펭귄·고양이 얼굴·눈사람·곰 인형·햄스터·배 모양 새 등 수업에 맞춘 자체 예제를 준비한다.
3. 같은 캐릭터의 최종 그림, 큰 도형 밑그림, 부분 단계 그림은 같은 모양·위치·비율을 공유해야 한다. 매 단계마다 독립적으로 그림을 생성하여 캐릭터가 달라지게 하지 않는다.
4. 원본, 도형, 안내점, 강조선은 분리된 자료로 관리한다. 시작점·방향·순서는 정확한 교육 표시이므로 검증 가능한 좌표·선 자료로 붙인다.
5. 도형을 조립하는 순서와 보이는 외곽선을 정리하는 순서가 다른 경우 두 목적을 설명한다. 도형 밑그림의 겹친 선을 ‘잘못된 선’으로 채점하지 않는다.
6. 각 단계 그림은 직전 상태에서 이번 행동만 추가되도록 한다. 첫 컷부터 완성된 선이 표시되거나 중간 단계가 건너뛰지 않게 확인한다.
7. 초기 병아리는 머리·몸이 합쳐진 모양이어야 한다. 도형 분석 화면에서 별도 머리와 목을 억지로 만들지 않는다.
8. 한 번의 연습에 캐릭터를 하나씩 제공한다. 선택 화면은 추천 예제 하나와 다른 선택 소수만 보여준다.
9. 대체 예제는 목표·부위·복잡도가 맞아야 한다. ‘입 모양 바꾸기’에 부리만 있는 새를 자동 배정하는 등의 잘못된 조합을 막는다.
10. 예제 파일의 제작 출처와 사용 조건을 기록한다. 외부 작품을 학습팩이나 최종 캐릭터 자산으로 사용할 때는 해당 이용 조건을 확인한다.
11. 시범은 사람이 따라갈 수 있는 속도로 한 단계씩 멈출 수 있어야 한다. 멋진 자동 완성 애니메이션만 보여주는 방식은 충분하지 않다.
12. 공개 준비 상태는 수업 단위로 ‘원고 준비 / 예제 준비 / 설명·그림 일치 확인 / 기기 확인’으로 관리한다. 잠긴 빈 카드로 수업 수를 부풀리지 않는다.

## 13. 복습과 추천의 구체적인 예

아래 간격은 최초 제품 정책이다. 사용자가 부담을 느끼면 바꾸고, 완료 횟수로 실력을 추정하지 않는다.

- 새 목표의 시도 2~3개 뒤에 이전 목표를 다른 예제로 한 번 다시 사용한다. 예: D21의 곰 얼굴 다음에 이미 배운 병아리 모작을 짧게 선택할 수 있게 한다.
- 해당 목표의 사용이 오래 뜸하면 다음 새 수업 앞에 짧은 복습을 제안한다. 결석 일수 때문에 강제로 처음으로 돌리지 않는다.
- 선택한 캐릭터가 같은 이유로 지루하다면 같은 목표의 검수된 다른 예제로 바꾼다. 도움 줄이기처럼 같은 캐릭터를 유지할 학습 이유가 있으면 그 이유를 설명하고 변경 선택도 제공한다.
- D18에서 네 점을 잇는 것이 어려움 → 점은 유지하고 몸을 두 반쪽으로 나누어 따라가기 → 다른 둥근 캐릭터로 한 번 확인 → D19를 추천.
- D27에서 귀가 커진 차이를 스스로 찾음 → 귀의 시작점·끝점만 잡는 변형 과제 → D28의 새 얼굴에서 다시 확인.
- D40에서 팔 방향은 바꾸지만 시작점이 이동함 → 같은 몸에 팔 시작점만 표시한 쉬운 과제 → 팔의 끝 방향만 바꾸어 보기.
- D68에서 걷기가 어려움 → D58 방향선으로 돌아가 앞·뒤 다리 구별 → D59 덩어리 얹기 → 다시 D68.

추천 이유는 사용자에게 한 줄로 표시한다. 예: ‘귀 위치를 한 번 더 익히면 옆에 두고 그리기가 편해져요.’

## 14. 기록과 기존 앱 통합

개발방은 현재 프로젝트의 계정·저장·동기화 방식을 확인한 뒤 기능을 추가한다. 기존 기록을 초기화하거나 현재 저장 구조를 이유 없이 교체하지 않는다.

최소 기록 항목:

- 계정별 학습 단계·현재 수업·선호 도구·권장 시간.
- 시도 식별자·수업 ID·예제 ID·콘텐츠 버전·실제 저장 시각.
- 진행 중 그림 또는 종이 사진, 축소 미리보기, 이어 그릴 수 있는 편집 정보(앱 내 그리기인 경우).
- 사용한 도움, 자기확인 결과, 어려웠던 항목, 피드백 내용과 확인 근거.
- 다음 추천과 그 이유, 사용자가 직접 고른 다른 과제.

그림 파일과 진도 저장은 함께 성공 상태를 관리한다. 그림 저장에 실패했는데 수업 전체가 정상 저장된 것처럼 안내하지 않는다. 저장 중에는 이탈 후에도 복구 가능하게 하고, 중복 요청을 안전하게 처리한다.

기존 계정 권한을 지키고 다른 계정의 작품·진도·피드백을 볼 수 없게 한다. 초기화 기능이 있다면 그림 영역의 범위와 결과를 명확히 보여주고 기존 운동·식단·언어·가계부 기록과 분리한다.

이 요청에서 매일 알림이나 예약을 자동 등록하지 않는다. 앱 내에 알림 설정을 둘 수는 있으나 사용자가 켜는 선택 기능으로 둔다.

### 필요한 검증

교육·콘텐츠:

- 수업 80개가 고유 ID로 존재하고, 9단계의 개수 합계가 맞는지 확인.
- 각 수업에 목표 1개, 실제 행동 순서, 맞는 예제, 쉬운 과제, 확인 질문이 있는지 확인.
- 모든 단계 그림을 실제로 열어 원고의 행동과 그림이 일치하는지 확인. 파일이 존재한다는 검사만으로 대신하지 않는다.
- 시작점과 선 방향이 실제 예제와 맞는지, 숨은 선과 최종 외곽이 혼동되지 않는지 확인.
- 수업 제목만 남은 카드·준비 중 예제·잘못된 대체 조합이 없는지 확인.

학습 흐름:

- ‘너무 어려워요’ → 쉬운 과제, ‘도움 있으면 가능’ → 도움을 한 종류만 줄이는 과제, 확인 근거 부족 → 복습/맛보기 선택이 나오는지.
- 횟수·출석만으로 자동 진급하지 않는지, 도움 사용·쉬어감 때문에 기록이 삭제되지 않는지.
- AI 분석이 없을 때 사용자 그림의 품질을 판정했다고 표시하지 않는지.
- D01→D80의 정상 진행과 D18·D40·D68에서 되돌아오는 경로를 확인.

그리기·저장:

- iPad/Apple Pencil과 지원 브라우저에서 선 끊김, 손바닥 오입력, 확대·회전 후 좌표, 스크롤 충돌을 확인. 실제로 확인하지 못한 항목은 미검증으로 보고.
- 새로고침·탭 전환·화면 잠금 뒤 작성 중 그림과 현재 행동을 복구하는지.
- 종이 사진 저장, 사진 없이 자기확인, 실패 후 재시도, 오프라인 중 보존과 재연결 처리를 확인.
- 새 수업 팩으로 바뀌어도 이전 그림·진도·버전 연결이 유지되는지.
- 계정 간 데이터 분리와 기존 다른 메뉴의 저장·탐색 기능을 확인.

최종 보고에는 구현 완료·미완료, 준비된 수업 수와 검수된 예제 수, 실제 기기 확인 범위, AI 피드백의 지원/미지원, 남은 문제, 확인 링크를 포함한다. 앱 반영 완료와 교육 효과의 장기 검증을 구분한다.

## 16. 교육 설계 참고와 적용 범위

큰 형태를 관찰하고 단순한 모양으로 정리한 뒤 필요한 세부를 더하는 접근은 Proko의 [7 Ways Simple Shapes Can Improve Your Drawings](https://www.proko.com/course-lesson/7-ways-simple-shapes-can-improve-your-drawings)에서 다루는 형태 단순화·결합 설명을 참고했다.

그림 학습을 손의 움직임과 관찰·이해가 함께 필요한 과정으로 설명하고, 과정이 지나치게 부담스럽거나 지루해지면 연습 방식을 조절한다는 관점은 Proko의 [Learning How to Draw](https://www.proko.com/course-lesson/learning-how-to-draw)를 참고했다.

이 문서의 9단계·80개 수업, 하루 10~20분, 도움 수준 H0~H3, 확인·복습 정책은 사용자가 제시한 제약에 맞춘 독자적인 교육·제품 설계안이다. 참고 강좌의 공식 과정이나 효과가 검증된 표준 시험으로 소개하지 않는다. 외부 강좌의 유료 수강은 이 앱의 전제 조건이 아니다.

## 17. AI 비서 9에 전달할 핵심 요청

연이앱 자기계발에 ‘그림 연습’을 추가해 주세요. 첨부한 AI_Yeoni_Drawing_Curriculum_v1.0.md를 교육·기능 기준으로 사용해 주세요.

저는 그림을 거의 그려본 적이 없고, 보고도 어디서 시작할지 모르는 완전 초보입니다. 병아리 트레이싱부터 시작해 도형화, 모작, 기억 그림, 간단한 변형, 쉬운 크로키, 포즈·표정, 오리지널 캐릭터 제작으로 이어지게 해 주세요.
