## 이번 추가 검증과 한계

`tests/e2e/drawing-templates.spec.ts`는 공개 CI에 개인 교재를 보내지 않기 위해 합성 PNG 150개로 **실제 배포 코드의 ZIP 디코더와 저장 함수**를 브라우저에서 실행한다. 격리된 Auth/Storage에 실제 요청을 보내고, 여섯 번째 읽기 실패 후 재등록·150개 재조회·타 계정 차단을 확인한다. 실제 UI에서는 잘못된 ZIP 거절과 잘못된 원본 해시 안내를 확인한다. 이것을 사용자 원본 150개의 운영 UI 등록 완료로 보고하지 않는다. 이 검사는 PR #195의 Actions 35723965061에서 Chromium·WebKit 모두 통과했다.

- 사용자 원본 ZIP의 운영 계정 등록/열기: 아직 사용자 계정에서 수행하지 않음.
- 실제 iPhone/Pencil, 회전/잠금/복귀, 종이 사진 촬영, 원격 팩 교체: 별도 확인 필요.
- 이미지 AI 품질 분석: 비활성. 기본 수업·추천은 AI 호출 없이 작동하며 자기확인을 그림 분석 결과로 표현하지 않는다.

## 이번 시각 검수

검수 그림은 `docs/drawing/stage-one/`에 있다. 각 단계의 실제 설명과 시작점·화살표·누적 선을 같은 패널에 렌더링해 82패널 모두 눈으로 대조했다. 출발점 좌표·선 누락·대체 예제 ID·이전 팩 스냅샷 보존은 자동 검사로 별도 확인한다.

- D02: 오른쪽 볼록한 배, 왼쪽 들어간 허리. 대체 예제는 얕은 허리.
- D03: 둥근 얼굴을 먼저, 귀는 위쪽 양옆. 제공 템플릿의 곰 구성을 얼굴 수업으로 단순화.
- D04: 얼굴 뒤에 붙는 긴 귀. 짧은 귀 대체 예제. 제공 토끼 자료의 연결 위치 참고.
- D05: 가로선 → 오른쪽 모서리 → 밑 → 왼쪽. 모서리 반경이 다른 두 예제.
- D06: 바깥 몸을 먼저 닫고 연필을 떼어 안쪽 배로 이동. 배는 타원으로 검수·수정.
- D07: 제공 고양이 자료의 얼굴·삼각 귀 참고. 수염·몸·꼬리는 제외.
- D08: 새 콩 두 예제로 시작 위치 선택, 선 나누기, 원본 숨기기와 메모를 연습. 도형의 시작점은 강제 위치가 아닌 시범 예시.

원본 교재 ZIP/PNG는 공개 코드·검수 이미지에 포함하지 않는다. 원본 참고 보관함과 새로 제작한 단계 시범의 출처를 구분한다.
