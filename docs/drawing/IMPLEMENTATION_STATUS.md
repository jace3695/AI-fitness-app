## 로컬 작성 기능

- 자기계발 메뉴 연결, 현재 과제/시작 버튼, 수업별 준비 상태.
- 벡터 시범의 시작점·현재 선·이전 선 분리, 수동 단계 전환.
- Canvas 선/지우개, 되돌리기/다시 실행, 확대, Pencil만 입력 옵션.
- 원본 숨기기, 종이/외부 앱 안내, 사진 압축, SVG 예제·PNG 그림·편집 JSON 내보내기.
- 계정별 IndexedDB 미전송 그림 보관. 서버 그림/사진/수업 스냅샷/자기확인을 한 행에 원자 저장.
- UUID 재시도, 응답 유실 뒤 정확한 본문 재조회, revision 조건부 수정, 계정별 RLS.
- 앨범, 비교, 삭제, 이전 그림 연결 UI, 원본 복사 후 색칠할 기반.
- 자기확인과 시도 완료 분리. 어려움 우선·짧은 시도 구분·도움 한 단계 줄이기·대체 예제 추천.
- 실행 코드 없는 학습팩 스키마, 원격 HTTPS 공급 URL, 크기 제한, 마지막 정상 팩 복구, 시도별 당시 콘텐츠 보존.

이 목록은 코드 작성 범위다. 실사용 검증 완료를 뜻하지 않는다.

## 검사

- D01 누적 선·단일 몸/머리, 원고 80개/9단계, 잘못된 팩 거절, 완료 횟수로 숙련 추정 금지, 어려움 우선: 단위 검사 통과.
- PGlite 실제 SQL 적용: 비로그인 차단, 소유자 조회, 타인 읽기/수정/삭제 차단, 중복 UUID, 오래된 revision, 스냅샷 보존, 누락 문서 거절 통과.
- TypeScript 통과, 변경 파일 ESLint 통과, Next production build 통과. 신규 단위·DB 검사 7개 통과. 인증 E2E와 구분한다.
- `tests/e2e/drawing.spec.ts` 및 격리 DB seed 작성. 실제 실행 전이며 통과라고 보고하지 않는다.
- iPhone/Pencil 실기기, 회전/잠금/복귀, 저장 후 재조회, 오프라인 복구, 원격 팩 교체 실사용: 미검증.

## 진행이 막힌 지점

- GitHub fetch와 Supabase `select 1`이 HTTP 400 `Invalid MCP request metadata`를 반환한다. 원격 상태 확인, PR, 호스팅 DB 검사 불가.
- 브라우저가 로컬 Next 서버에 `net::ERR_BLOCKED_BY_CLIENT`를 반환한다. 인증 후 화면 검증 불가.
- 이 실행 환경에는 Docker가 없어 기존 격리 Supabase E2E stack 실행 불가. 권한/네트워크 우회하지 않았다.
- AGENTS.md는 실제 학습·저장 검증 없이 운영 병합·배포하지 말라고 명시한다.

## 구현 결정

기존 운동·식단·손글씨·타자 테이블/데이터는 변경하지 않는다. 새 owner-scoped `growth_drawing_attempts` 테이블은 현재 로컬 SQL 파일만 있으며 운영에 적용하지 않았다. 개인 교재 ZIP/이미지는 저장소에 넣지 않았다. 첫 시범은 직접 작성한 정확한 좌표 그림이다.

기존 식단 이미지 분석 코드에 `GEMINI_FREE_TIER_CONFIRMED`와 별도 무료 키 확인 경로가 있다. 이는 운영자의 확인 표시이며 실시간 과금 상태 증명이 아니다. 이번 세션에서 실제 키/과금/그림 분석 지원을 확인하지 못했으므로 선택 AI 피드백은 활성화하지 않았다.

확인 주소: 아직 새 배포 없음. 로컬 구현 경로 `/growth/drawing`를 운영 주소처럼 안내하지 않는다.


## 사용자 피드백 반영 — 같은 날 후속 수정

- 이전 병아리는 원본보다 길쭉하고 날개 곡선이 반대 방향이었다. 사용자 스크린샷의 넓은 몸, 또렷한 점 눈, 바깥으로 휜 날개에 맞춰 좌표 도해를 수정했다. 완성 이미지뿐 아니라 두 예제의 12개 단계도 다시 확인했다.
- 새 학습팩은 `1.0.0-draft.2`. 예제 ID를 변경해 이전 그림 스냅샷은 보존한다.
- 제공 ZIP의 150종을 5개 접촉 시트로 펼쳐 검토했다. 동물 10, 눈·코입 30, 표정 30, 포즈 50, 효과선 30.
- 실제 원본 150개에 파일 해시/이름/분류를 부여했다. 14개 원본을 44개 수업의 **보조 참고**로 연결했다. 44개 수업을 완성했다는 뜻이 아니다.
- ZIP을 그대로 받아 150개 원본 전부를 해시 확인한 뒤 기존 개인 Storage에 등록하는 코드와 수업별 원본 보기/전체 자료 둘러보기 UI를 추가했다. 실제 첨부 ZIP으로 150개/5,967,433바이트 해시 확인 통과. 사용자 계정에 업로드한 상태는 아니다.
- 자료 PNG·ZIP은 공개 저장소에 포함하지 않는다. 저장 경로는 로그인 계정/learning/drawing/...이며 기존 비공개 버킷의 소유자 정책을 사용한다.
- 메타몽·푸린·피카츄 공식 도감 링크 및 개인 연습용 관찰 안내를 추가했다. 인터넷 캐릭터의 단계별 시범은 아직 제작하지 않았고 완료 예제로 세지 않는다.
- 신규 ZIP 검사를 포함한 콘텐츠 검사 9개 통과, TypeScript·변경 파일 ESLint·production build 통과.
- **연결 재확인:** GitHub 조회와 Supabase `select 1`이 복구됐다. 위의 HTTP 400 기록은 이전 시점의 오류다. 실제 학습/저장 E2E는 아직 미완료이며 운영 배포하지 않는다.
