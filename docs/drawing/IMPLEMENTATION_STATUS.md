# 그림 연습 구현 상태 — 2026-09-22

전체 요청은 아직 완료하지 않았다. 첫 수업과 저장 기반부터 단계적으로 반영한다.

## 콘텐츠 수

| 항목 | 실제 상태 |
|---|---|
| 수업 원고 | 9단계 80개, 고유 ID·목표·순서·질문·쉬운 과제 |
| 단계 그림까지 검수 | D01 1수업 / 80개 (1.25%: 수업 완성 비율이며 전체 기능 진척률이 아님) |
| 시각 예제 | 병아리 2종, 6단계씩 총 12패널 |
| D02–D80 | 원고만 준비. 시각 예제·단계 그림 미완료, 실행 불가 |
| 지속 프로젝트 | C01–C04 원고 4개. 실제 연습 흐름 보완 필요 |
| 첨부 템플릿 | 150종 원본 목록·해시 확인. 원본 14개를 44개 수업의 보조 참고로 연결 |
| 만화 캐릭터 | 메타몽·푸린·피카츄 공식 참고 링크·시작 안내. 전용 단계 그림 미완료 |

150종의 목록 검토와 44개 수업의 참고 연결은 수업 완성 수에 포함하지 않는다.

## 구현된 첫 묶음

- 자기계발 메뉴, 현재 과제/시작 버튼, 준비된 수업만 실행.
- 시작점·현재 선·이전 선을 구분하는 수동 단계 시범.
- 그리기·지우개·실행 취소/복원·확대·Pencil만 입력 옵션.
- 원본 숨기기, 사진 압축·등록, SVG/PNG/편집 JSON 내보내기.
- 계정별 미전송 그림 보관, 서버 그림/사진/수업 스냅샷/자기확인 원자 저장.
- UUID 재시도, 응답 유실 시 정확한 본문 재조회, revision 조건부 수정, 계정별 RLS.
- 앨범·이어 그리기·비교·삭제 및 기존 작품 연결 기반.
- 완료와 자기확인 구분, 어려움 우선·짧은 과제·도움 줄이기·대체 예제 추천 기반.
- 코드 없는 콘텐츠 팩 형식, 원격 공급 URL·마지막 정상 팩 복구·당시 콘텐츠 보존.
- 원본 ZIP 등록: 전체 150개 해시 검사 후 업로드. 기존 파일을 덮어쓰지 않으며 **각 저장 결과를 다운로드·해시 확인한 뒤** 완료로 계산한다.
- 다시 접속한 보관함의 등록 개수 표시. 파일을 열 때도 해시를 확인한다.

## 이번 추가 검증과 한계

`tests/e2e/drawing-templates.spec.ts`는 공개 CI에 개인 교재를 보내지 않기 위해 합성 PNG 150개로 **실제 배포 코드의 ZIP 디코더와 저장 함수**를 브라우저에서 실행한다. 격리된 Auth/Storage에 실제 요청을 보내고, 여섯 번째 읽기 실패 후 재등록·150개 재조회·타 계정 차단을 확인한다. 실제 UI에서는 잘못된 ZIP 거절과 잘못된 원본 해시 안내를 확인한다. 이것을 사용자 원본 150개의 운영 UI 등록 완료로 보고하지 않는다. 이 추가 검사는 작성 후 실행 결과를 PR에 기록한다.

- 사용자 원본 ZIP의 운영 계정 등록/열기: 아직 사용자 계정에서 수행하지 않음.
- 실제 iPhone/Pencil, 회전/잠금/복귀, 종이 사진 촬영, 원격 팩 교체: 별도 확인 필요.
- 이미지 AI 품질 분석: 비활성. 기본 수업·추천은 AI 호출 없이 작동하며 자기확인을 그림 분석 결과로 표현하지 않는다.
