# 남은 시범의 해결 설계

> 14차 이후 최신 상태·종목별 차단은 `NEXT-SCOPE-REVIEW.md`와 `CATALOG-STATUS.md`를 우선한다. 원암 로우와 랫풀다운은 13·14차에서 구현·검증했다. 아래는 이전 설계 기록이다.

2026-10-20. 이 문서의 설계는 구현 완료나 전문가 승인을 뜻하지 않는다. 공통 목록·추천·페이지·저장 구조는 수정하지 않는다.

## 복합 루틴

- 기본 몸풀기 / 기본 정리운동: 카탈로그의 단계별 동작을 각기 별도 장면으로 분리하고 “다음 단계” 수동 전환을 사용한다. 모든 관절이 순간 이동하는 연속 루프 대신 준비/실행/복귀를 표시한다. 완료 기준은 전체 단계, 순서, 중단 안내의 일치다. 대안은 장면별 정지 도해이며 일부 단계만 만들고 루틴 전체 완료로 세지 않는다.
- 폼롤러 준비 / 회복: 사용 부위·직접 압박 제외 부위를 먼저 표로 대조한다. 롤러와 신체 접촉점을 부위별 고정하고 준비/회복의 실제 차이를 문서화한다. 차이가 확인되지 않으면 같은 자산을 재명명하지 않고 공통 도해 재사용임을 명시한다.

## 접촉점과 하중

- 덤벨 플로어프레스: 6차 구현. 하나의 3차원 관절 모델을 사선/옆면으로 동기화해 양팔과 바닥을 분리해 읽는다. 사선의 높이 확대를 명시한다. 입력 각도는 시각화 값이며 권장 운동 범위가 아니다.
- 지지 원암 덤벨 로우: 지지 손과 양발 좌표를 고정한 상태에서 고관절 경첩 자세를 만들고, 몸통/골반 회전 없이 팔꿈치와 덤벨 경로를 검증한다. 무릎 지지 변형으로 임의 전환하지 않는다.
- 덤벨 고블릿 스쿼트: 10차 구현 및 10a 발끝 방향 보정·격리 검사 완료, 통합 대기.  손-덤벨 접촉을 구속하고 하강 시 팔꿈치/무릎의 간섭을 별도로 검사한다. 맨몸 스쿼트의 새 이름으로 처리하지 않는다. 중량/몸통 안정성에 대한 의학적 판단은 제공하지 않는다.
- 사이드워크 / 몬스터워크: 11차 구현·격리 검사 완료, 통합 대기.  두 발의 입각/유각 순서를 분리한 상태 기계를 사용한다. 첫 종목은 옆 이동, 둘째는 전후 대각선 발자국을 평면 보조도에 표시한다. 발끌림·동시 공중 부양·발교차·밴드 관통이 없어야 한다.

## 회전·저항 방향

- 팔 붙인 밴드 외회전: 7차 구현·격리 검사 완료, 통합 대기. 정면으로 고정 상완을, 위에서 본 보조도로 전완의 회전을 표시한다. 3차원 전완 길이와 팔꿈치 90도, 고정 팔꿈치/몸통을 검사했다. 반대쪽 고정점과 장력 방향을 표시한다.
- 밴드 풀어파트: 8차 구현·격리 검사 완료, 통합 대기. 정면/윗면 동기화로 수평 벌림과 팔 길이 단축 착시를 구분한다. 손바닥 아래 방향의 변형이며 연구의 근활성 결과를 개인 처방으로 바꾸지 않았다.
- 팔로프 프레스: 9차 구현·격리 검사 완료, 통합 대기.  정면과 윗면에 측면 저항을 나타내며 손이 앞으로 나가도 몸통 방향이 일정한지 검사한다.
- 랫풀다운: 위 고정점·손·팔꿈치 경로를 분리하고 밴드가 머리/몸통을 관통하지 않도록 시점을 선택한다.
- 페이스풀: 얼굴 근처 전완·어깨 회전이 겹치지 않는 사선/윗면 보조도가 필요하다. 그립과 팔꿈치 경로가 읽히지 않으면 검증 차단으로 전환하고 정지 도해를 검토한다.
- 골반 기울이기 / 캣카우: 골반 각도와 척추 곡선을 별도로 표현한다. 몸통을 한 막대처럼 회전시키는 방법은 사용하지 않는다. 과장된 허리 가동을 유도하지 않게 작은 변화와 확대도 범례를 병행한다.

## 현재 검증 차단과 대안

| 종목 | 정확한 차단 이유 | 가능한 대안/해제 조건 |
|---|---|---|
| 데드버그 | 기존 통증 이력과 제한에 새 변형이 맞는지 판단할 근거 부족 | 현 주의사항 유지. 적합한 변형이 확인되기 전 시범 자동 활성화 안 함. 일반 도해는 별도 미연결 초안으로만 검토 |
| 무릎 사이드 플랭크 | 현재 카탈로그와 확인한 AAOS 변형의 위쪽 다리 자세가 다름 | 동일 변형의 1차 근거를 찾거나 부모가 변형을 명시적으로 확정한 후 접촉점 설계 |

검증 차단은 해당 운동을 모두 위험하다고 판정한 뜻이 아니다. 자료 범위·변형 일치 또는 개인 적합성을 지금 확인할 수 없다는 의미다. 전문가 검수·실기기 검증 미실시 상태는 모든 신규 도해에 유지한다.


## 범위 재확인 후 구현한 준비 자세

AB 슬라이더의 밀지 않는 준비 자세와 턱걸이의 발 보조 준비 자세는 기준 가이드에서 범위를 확인했다. 12차 정지 도해와 격리 검사를 완료했다. 롤아웃·완전 매달리기 시범은 없으며 애니메이션 수에 포함하지 않는다.
