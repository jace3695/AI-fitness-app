# 운동 시연 로컬 통합 상태

기본 움직임 시연 27종을 앱 디스패처에 연결했습니다. 디스패처 미연결 3종은 아래 상태를 유지합니다. **2026-10-26 현재 로컬 상태:** AB 슬라이더의 기존 정지 준비 도해, 데드버그와 폼롤러 회복의 명시적으로 여는 일반 동작 설명을 자세 가이드에 별도로 연결했습니다. AB에는 롤아웃이 없습니다. 데드버그는 두 변형을 비교하고, 폼롤러는 기존 7장면에 새로 정의한 외측 대퇴사두근 좌우 2장면을 더한 정보용 9장면입니다. 원 안내의 모호한 대상 조직을 확인하거나 개인 운동표·추천을 바꾼 것이 아닙니다. **기본 디스패처 27종·AB 정지 안내 1종·선택 열기 일반 설명 2종**을 구분합니다. 전문가 자세·개인 적합성 검수는 미실시이며 의료적 안전성을 보장하지 않습니다. 로컬 통합은 배포 완료를 의미하지 않습니다. 이번 세 항목 변경의 실제 브라우저 검증은 미실시입니다.
