# 14차: 서서 하는 롱밴드 랫풀다운

13차 다음 적용한다. 양발·몸통·고정점을 유지하며 양쪽 상완과 전완의 실제 3차원 길이가 변하지 않는 자체 도해다. 정면은 팔꿈치 하강을, 윗면은 밴드가 머리 앞을 지나는 경로를 표시한다.

서는 자세는 기존 앱 가이드의 “무릎을 살짝 굽힘”, “팔꿈치를 아래로 끌어내림” 범위를 따른다. [PureGym Lat exercises](https://www.puregym.com/exercises/back/lat-exercises/)의 수직 당김 원리를 참고하며 머신/막대 지지 변형과 동일한 설치라고 주장하지 않는다. 임의 막대·매듭·문 고정법은 안내하지 않는다.

새 파일은 `latPulldownMotion.ts`, `.test.ts`, `LatPulldownFigure.tsx`, `check-lat-pulldown-motion.cjs`. 독립 디스패처 ID 등록 외 공통 목록·페이지·추천·저장을 변경하지 않는다.

검사: 401프레임 팔 길이, 대칭, 지지점·몸통 고정, 밴드와 머리의 앞뒤 분리, 팔꿈치 하강과 밴드 길이 증가, 닫힌 주기. strict 타입·격리 Edge·320px·200% 글자·키보드·터치·느린 재생·모션 감소 검사 및 시작/당김 화면 검토 통과.

한계: 고정 장치 강도, 밴드 저항, 그립, 견갑골 상세 운동과 개인별 관절 부하는 모델링하지 않았다. 전문가 자세 검수·의학적 적합성 검토는 미실시이며 허리 질환 안전성을 보장하지 않는다. 앱 미통합이다.
