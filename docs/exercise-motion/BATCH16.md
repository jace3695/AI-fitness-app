# 16차: 분절 등선 캣카우

15차 이후 적용. 직접 작성한 8개 모식 분절의 길이를 일정하게 유지하면서 등선을 양 방향으로 굽힌다. 손·무릎·발 접촉과 팔·허벅지 길이, 머리와 어깨 사이 거리를 고정했다. 몸통 막대를 통째로 회전하거나 길이를 늘이는 방식이 아니다. 분절 개수는 실제 척추 해부 구조를 뜻하지 않는다.

기존 앱 가이드와 [Mayo Clinic Cat stretch](https://www.mayoclinic.org/healthy-lifestyle/adult-health/in-depth/back-pain/art-20546859)의 네발기기·등 둥글게/가슴 열기 원리를 참고했다. 자료의 반복·유지 시간이나 효과 주장은 옮기지 않았다. 외부 이미지·영상·모델을 사용하지 않는다.

한 주기는 중립→가슴 가볍게 열기→중립→등 둥글게→중립이다. 두 정지 자세 버튼과 중립 버튼을 제공한다. 확대도는 세로 변화 3배임을 표시하고 확대 크기를 따라 하지 말라고 안내한다.

401프레임 분절·사지 길이, 지지점, 반대 곡률, 중립 복귀와 정확한 자세 문구 검사 및 strict 타입·격리 Edge·320px·200% 글자·44px·키보드·터치·느린 재생·모션 감소 검사 통과. 시작/두 굽힘 화면 검토 완료. 실제 척추별 운동·관절 부하·전문가 자세 검수·의학적 적합성은 검증하지 않았다.

신규 파일: `catCowMotion.ts`, `.test.ts`, `CatCowFigure.tsx`, `check-cat-cow-motion.cjs`. 독립 디스패처만 연결하며 앱 본체·공통 목록·실제 기록은 변경하지 않는다.
