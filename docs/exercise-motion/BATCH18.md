# 18차: 작은 골반 기울이기

17차 이후 적용. 자체 골반 기호를 작게 회전시키고 발·머리·어깨·골반의 바닥 접촉을 보존한다. 골반 타원의 회전으로 외곽 높이가 달라져도 바닥 접촉을 유지하도록 중심 높이를 보정했다. 고관절 이동에 맞춰 다리 두 분절의 길이를 유지한다.

허리 표면선의 변화와 골반 기호의 회전을 구분한다. 표면선은 척추뼈나 고정 길이의 뼈 모형이 아니라고 표시한다. 확대도는 허리선 세로 변화 3배, 골반 크기 2배이며 운동 목표가 아니라고 안내한다. 골반을 바닥에서 드는 브리지·중립보다 크게 허리를 띄우는 단계는 포함하지 않는다.

[Cambridge University Hospitals NHS — Pelvic tilts](https://www.cuh.nhs.uk/patient-information/back-mobility-exercises/)의 뒤로 기울이는 원리와 기존 앱의 작은 말기·중립 복귀 범위를 대조했다. 외부 영상·이미지를 사용하거나 자료의 유지 시간·반복·효과를 처방으로 옮기지 않았다.
