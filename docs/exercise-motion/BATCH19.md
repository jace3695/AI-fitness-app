# 19차: 발 보조 턱걸이 준비 움직임

18차 이후 적용. 기존 `pullup-basic-posture`의 정지 도해를 주 디스패처에서 작은 준비 움직임으로 교체한다. AB 슬라이더는 계속 정지 도해이며 시연 완료로 세지 않는다. 기존 정지 컴포넌트는 직접 참조용으로 보존한다.

근거 범위는 읽기 전용 `57b3309426bdd845afae1e2014e10e4f39083b31:app/data/exerciseGuides.ts`의 양손 바 잡기·양발 바닥 보조·어깨를 귀에서 살짝 멀게 하기다. 완전 매달리기·턱걸이 반복·발을 떼는 장면은 없다. 소스 코드 경로를 사용자의 운동 안내 링크로 노출하지 않는다.

양손·상완·전완은 고정하고 작은 몸통 이동을 무릎 연동으로 표현한다. 머리·몸통 길이, 팔·다리 분절 길이, 양발 접촉을 보존한다. 어깨와 머리의 상대 거리가 변하며 실제 견갑골 운동이나 발 보조 하중을 계산했다고 주장하지 않는다. 모식 상대 변화 확대는 3배이며 따라 움직일 목표가 아니라고 표시한다.

401프레임 기하 검사, strict 타입·격리 Edge·320px·200% 글자·키보드·터치·모션 감소 검사 통과. 부동소수점 오차 때문에 길이의 완전 일치 비교가 한 번 실패해 다른 기하 검사와 같은 수치 허용오차로 수정 후 통과했다. AB 정지 분기도 별도 재검사했다.
