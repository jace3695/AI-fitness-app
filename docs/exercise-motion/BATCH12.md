# 12차: 정지 준비 자세 두 종목

11차 다음 `batch12-additions.patch`를 적용한다. 별도 `PreparationPoseDemo.tsx`와 `preparationPose.ts`가 AB 슬라이더 준비·턱걸이 기본 자세 ID만 받는다. 독립 시범 디스패처에서 먼저 분기하며 애니메이션 ID 목록에 등록하지 않는다. 공통 목록·페이지·추천·저장 구조는 변경하지 않는다.

범위 근거는 읽기 전용 기준 `57b3309426bdd845afae1e2014e10e4f39083b31`의 `exerciseGuides.ts`에 명시된 준비 자세다. AB 슬라이더는 밀지 않은 상태, 턱걸이는 양발을 바닥에 두고 지지하는 상태만 자체 벡터 좌표로 표현한다. 기존 가이드의 주차·시간·거리·반복 처방은 복제하지 않았다. 롤아웃·완전 매달리기·턱걸이 반복 동작으로 완료 처리하지 않는다.

두 SVG는 제목·설명을 제공하며 재생 버튼, 애니메이션 타이머, 외부 자산 요청이 없다. 모션 설정 변경에도 정지 상태를 유지한다. 바 설치 구조·허용 하중·지지력·정확한 관절 부하는 모델링하지 않으며 시각 비율을 설치 치수로 사용하면 안 된다. 전문가 자세 검수와 의료적 적합성 검토는 미실시다.

검사: 정확한 ID 선택, 바퀴와 무릎 접촉, 양손 바 접촉·양발 바닥 접촉 등 단위 테스트 3개. strict 타입, 격리 Edge, 320px 및 200% 글자에서 가로 넘침 없음, 접근 가능한 SVG, 재생 조작 없음, 모션 설정 변경 시 불변, 알 수 없는 ID의 빈 렌더를 확인했다. `batch12-evidence/after.json`과 스크린샷 참조.

누적 상태: 기준 배포 애니메이션 5종, 통합 대기 애니메이션 12종과 정지 준비 도해 2종. 총 30종 중 자산이 있는 19종, 미구현 11종. 19종은 전문가 검수 완료 수가 아니다.
