# 6~23차 시연 및 최종 상태 동기화 인계

2026-10-20. 요청 당시 남은 항목은 정확히 5개: 기본 정리운동, 폼롤러 준비, 폼롤러 회복, 데드버그, AB 슬라이더 준비 자세였다. 이번에 정리운동과 폼롤러 준비를 완성했고 회복은 부분 시범, 데드버그는 미연결 검토 초안으로 구별했다. AB는 정지 도해만 유지한다.

**카탈로그 30개 = 완성 움직임 시연 27개 + 회복 부분 시범 1개 + 데드버그 미연결 검토 초안 1개 + AB 정지 도해 1개.** 전문가 자세·개인 적합성 검수는 미실시다. 마지막 부모 보고의 앱 통합 10개 이후 실제 통합 상태는 새로 확인하지 않았으며 다른 작업공간의 앱 최종 검사를 대행하지 않았다.

권장 산출물은 `batch6-23-integration.patch`다. 문서·PNG를 제외한 app 독립 컴포넌트/라이브러리·테스트·scripts만 포함하며 최종 상태 생성기 동기화도 반영했다. 공통 운동 목록·페이지·추천·저장 구조는 변경하지 않는다.

새 임시 Git 디렉터리에 기준 커밋의 원본 바이트를 복원한 후 `git apply --check`, 실제 적용, 역적용 검사, 모든 app/scripts 파일의 대상 커밋 바이트 일치를 확인했다. **적용된 복사본에서 단위 검사 56개 통과.** 첫 검사에서 Windows 아카이브의 CRLF 변환을 확인해 원본 Git blob으로 재구성했다. 원본 코드 충돌이나 부모 앱 실패로 판정한 것이 아니다.

이 통합 패치는 **3~5차만 반영된 기준**에 사용한다. 이미 6차 이후 일부를 반영했다면 중복 적용하지 않고 아래 개별 차수와 기준/대상 해시를 대조해 남은 범위만 통합한다. 부모 작업공간에서 적용 검사가 실패하면 멈추고 해당 파일의 실제 차이를 병합해야 한다. 이 작업은 부모 작업공간에 적용하지 않았다.

데드버그의 별도 전역 금지 플래그를 이번에 확인했다는 뜻은 아니다. 기존 안내의 조건을 보존하고 이 구현에서 미연결 상태를 유지한다. 건강사진·진료기록·계정·비밀정보 접근 없이 필요한 변형 정의만 전달받으면 된다. 출처와 세부 한계는 `BATCH21.md`, `BATCH22.md`, `BATCH23.md`, `NEXT-SCOPE-REVIEW.md`에 기록했다.

## 범위와 제한

모든 자산은 자체 벡터 기하이며 외부 영상·모델·사진 복제, 구매나 추가 런타임 의존성은 없다. 관절·힘·압력·보조 하중·사용자 상태를 실제로 계산하지 않는다. 전문가 자세 검수와 의학적 적합성 검토는 미실시이며 허리 질환 안전성을 보장하지 않는다.

참조 저장소 수정·checkout, 앱 본체·실제 기록 변경, 다른 작업공간 검사 대행, push·배포·외부 업로드·DB 쓰기·유료 호출은 하지 않았다. 작업은 이 격리 저장소 안에서만 수행했다. 이 인계 문서와 현재 `CATALOG-STATUS.md`가 과거 차수 문서의 누적 수치보다 우선한다.
