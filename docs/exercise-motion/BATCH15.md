# 15차: 롱밴드 페이스풀

14차 뒤 적용. 자체 3차원 관절 모델로 손을 뒤로 당기면서 양옆으로 벌리고, 팔꿈치를 바깥으로 이동시킨다. 상완 38·전완 40의 모식 길이를 전 프레임 유지한다. 윗면은 벌림, 옆면은 얼굴 앞 공간을 보여 주며 양팔이 겹친다고 명시한다. 기존 풀어파트나 외회전 자산의 이름 변경이 아니다.

기준 앱 가이드의 얼굴 높이 고정점·팔꿈치 벌림 범위와 [PureGym Face Pulls](https://www.puregym.com/exercises/arms-and-shoulders/rear-delt-exercises/face-pulls/)의 양손 벌림·복귀 원리를 대조했다. 외부 영상·이미지·모델은 사용하지 않았다. 그립 회전과 견갑골 세부 움직임은 모델링하지 않으며 설치 치수·중량·횟수를 처방하지 않는다.

401프레임 팔 길이·좌우 대칭·지지점 고정·손 및 밴드의 얼굴 여유 공간 검사, strict 타입, 격리 Edge, 320px·200% 글자·키보드·터치·느린 재생·모션 감소 검사를 통과했다. 시작/당김 화면도 검토했다. 실제 밴드 저항·설치 강도·전문가 자세 검수·의학적 적합성은 검증하지 않았다.

새 파일: `facePullMotion.ts`, `.test.ts`, `FacePullFigure.tsx`, `check-face-pull-motion.cjs`. 독립 디스패처 외 공통 목록·페이지·저장 구조 변경 없음. 앱 미통합.
