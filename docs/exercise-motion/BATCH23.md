# 23차: 데드버그 미연결 검토 초안

`DeadBugReviewDemo.tsx`, `deadBugReviewMotion.ts`, `.test.ts`를 추가했다. **운동 카탈로그 또는 `ExerciseMotionDemo`에서 import·호출하지 않는다.** 검토 전용 표시 컴포넌트를 직접 열 때만 팔·반대 다리의 작은 움직임과 팔만 움직임의 두 변형을 비교할 수 있다. 둘 중 하나를 사용자에게 선택·추천·자동 전환하지 않으며 완료 시연 수에 포함하지 않는다.

기존 안내의 양팔 위·고관절/무릎 90도 준비, 반대 팔다리 교대, 허리가 뜨기 전 범위 제한을 대조했다. NASM 원리도 참고했다: https://www.nasm.org/resource-center/exercise-library/dead-bug . 출처의 끝 범위·효과·처방은 복제하지 않았다. 두 변형 모두 원본 벡터로 만들었으며 작은 범위는 표현상의 임의값이지 개인에게 허용된 각도가 아니다.

401프레임 검사에서 분절 길이, 고정된 머리·몸통·골반, 반대 팔다리 교대, 좌우 사이 중립 복귀, 팔만 변형에서 움직이지 않는 다리를 검증했다. 이 검사는 실제 사용자의 허리가 뜨지 않는다는 보장이 아니다. 정지 시작, 수동 탐색·재생, 모션 감소 등 공용 조작부를 사용한다. 별도 브라우저 진입점 옵션은 검사 하네스에만 추가했다.

## 외부 판단이 필요한 내용

기존 안내는 허리가 뜨기 전까지 움직이고 통증 시 팔만 움직이는 대안을 기술한다. 코드와 일반 자료만으로 현재 사용자에게 교차 동작·팔만 변형·다른 대안 중 무엇이 적합한지 정할 수 없다. 필요한 입력은 담당 전문가가 확인한 **허용 변형, 준비 자세 유지 가능 여부, 동작을 멈출 기준/허용 범위**다. 이 입력 없이 새 시범을 자동 활성화하거나 기존 제한을 삭제하지 않는다. 통증이 있는 상황에서 팔만 변형을 무조건 계속하라고 권하지 않는다.

추가 점검에서 `app/data`와 `app/lib`의 운동 관련 파일 안에 데드버그의 전역 금지 플래그를 새로 확인한 것은 아니다. 보류의 근거는 기존 안내의 통증·범위 조건과 개인 적용 판단의 부재다. 앞 문서의 “자동 활성화 차단”은 이 작업에서 미연결 상태를 유지한다는 의미이며, 별도의 전역 차단 기능을 구현하거나 검증했다는 뜻이 아니다.

## AB 슬라이더 준비 자세

12차 정지 준비 도해를 그대로 유지한다. 기존 안내의 초기 정지 유지와 이후 짧은 밀기는 서로 다른 진행 단계다. 현재 단계의 적합성을 판단할 입력 없이 롤아웃을 새로 넣지 않는다. 필요한 입력은 **정지 준비 유지인지 이동 단계까지 다룰지의 명시적 범위**, 전문가가 확인한 진행 허용 조건/범위, 실제 장비의 안정적 사용 조건이다. 제품 모델·바닥/미끄럼 조건·손잡이/바퀴 상태는 확인되지 않았으므로 그림만으로 장비 안전을 인증할 수 없다. 장식 움직임을 추가해 완성 시연으로 세지 않았다.
