# 운동 시연 독립 자산 검사 / 앱 라우팅 검사 분리

2026-10-26. 제품 컴포넌트·추천·강도·수행 처방·카탈로그는 변경하지 않았다. `ExerciseMotionDemo.tsx`의 미완료 3종 명시적 `null`도 그대로다. 이 작업은 기존 검수 하네스의 진입점 보정과 자동 회귀 검사만 다룬다.

## 문제와 보정

- `check-remaining-preparation.cjs`는 AB 정지 도해를 검사하면서 앱 디스패처를 사용해 빈 렌더에 도달했다. 이제 `PreparationPoseDemo.tsx`에 직접 진입한다. 정지 도해는 움직임 완료 수에 더하지 않는다.
- `check-roller-routine.cjs --recovery`도 디스패처에서 차단됐다. 이제 `RollerMotionDemo.tsx`에 `recovery: true`로 직접 진입한다. 7개 부위 그림과 2개 보류 단계의 부분 자산이며 루틴 전체 완료가 아니다.
- 독립 진입점에는 하네스의 `wall-pushup` 특례를 적용하지 않는다. 일반 검사에서는 기존 앱의 벽 푸시업 별도 분기를 유지한다.
- 직접 사용하는 `RollerMotionDemo`는 카탈로그 ID를 해석하지 않으므로 `show('unsupported')`를 언마운트로 취급하지 않는다. 명시적 `clear()`를 추가했고 브라우저 하네스는 재생 중 제거 후 RAF 정리를 검사하도록 했다. **그 브라우저 검사는 이번 작업에서 실행하지 않았다.**
- `check-final-motion-routing.cjs`는 독립 자산 검사가 아닌 기존 앱 라우팅 검사로 유지한다. 완료 상태는 **활성 27종 / 미연결 3종**, 증가 **0종**이다.

## 자동 검사 범위와 결과

`tests/motion-validation-paths.test.ts`의 5개 회귀 시나리오는 실제 검사 스크립트가 선택하는 설정을 캡처하고, 브라우저 번들과 동일한 직렬화된 `createControls`로 실제 컴포넌트를 합성한다. 서버 초기 마크업 검증이지 브라우저 검증이 아니다.

1. AB 직접 진입·접근성 표식·정지 도해·재생 조작 없음·알 수 없는 ID 빈 렌더.
2. 회복 `recovery=true`, 9단계 중 7개 SVG와 2개 명시적 보류 표식, 별도 `clear()` 계약.
3. 준비 모드는 디스패처를 유지하고 14단계 구성, 회복 ID는 빈 렌더.
4. 별도 라우팅의 27 활성 / 3 미연결. 실제 `ExerciseGuidePanel`도 합성해 `sourceExerciseId` 유무 각각 30종+미지원 ID에서 활성 시연 슬라이더 1개·미완료 SVG/슬라이더 없음·기존 수동 가이드/중단 안내 유지 검사. 벽 푸시업 별도 분기를 삭제하거나 중복하면 탐지한다.
5. 기존 데드버그 미연결 검토 진입점의 두 변형 보존.

검사 결과:

- 기존 준비·롤러·데드버그 기하/구성 단위 8개 + 새 회귀 5개 = **13/13 통과**, 실패·건너뜀 0. 이것은 이번 집중 실행 수이며 전체 저장소 테스트 수가 아니다.
- 변경 코드 ESLint, CJS 문법 검사 통과. 초기 테스트 헬퍼의 `module` 변수명 lint 오류를 수정한 뒤 재검사했다.
- 프로젝트 `tsc --noEmit --incremental false` 통과. 최종 Panel 시나리오까지 포함하는 집중 strict TypeScript 검사도 통과했다.
- AB/회복/앱 라우팅/데드버그 4모드의 기존 하네스 strict 타입 검사와 CSS·번들 생성, 생성 스크립트 문법 검사 통과. 브라우저는 기동하지 않았다.
- 운동 제품 소스 무변경 및 변경 대상 `git diff --check` 확인.

실행 증거는 `scripts/browser-qa/.generated/motion-validation-paths/`의 `focused-tests.log`, `final-static-checks.log`, `no-browser-harness-builds.json`이다. 생성물이 브라우저 통과 `after.json`으로 오인되지 않게 별도 이름을 사용했다. 과거 차수의 브라우저 증거를 덮어쓰지 않았다.

## 미실시 / 상태 유지

실제 브라우저·효과 실행·동작 재생/속도·실제 RAF 정리·320px/200% 글자·모션 감소·키보드·포커스·스크린리더·실물 기기 검증은 이번에 미실시다. 브라우저 공식 배포 경로 접근 제한을 우회하거나 다른 경로로 설치하지 않았다. 생성/서버 합성 검사를 실사용 검증으로 대체하지 않는다.

전체 테스트·전체 프로덕션 빌드·운영 배포는 실행하지 않았다. 개인 의료 적합성·자세 전문가 검수·장비 안전 인증도 하지 않았다. AB는 정지 준비, 회복은 7/9 부분, 데드버그는 두 미연결 검토 초안 그대로다. 추천·강도·수행 처방 변경, 미연결 3종 해제, 새 종목, 실제 DB·Azure 호출·비밀정보 접근·사용자 PC 접근은 없다. 진단 작업 파일과 `scripts/qa-pr189-sync.mjs`는 수정하지 않았다. 커밋·push·병합·배포는 이 작업에서 수행하지 않았다.
