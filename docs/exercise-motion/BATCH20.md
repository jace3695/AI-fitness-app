# 20차: 기본 몸풀기 단계별 시범

기준은 격리 브랜치 `5021d93`이다. 참조 저장소와 공통 운동 목록·페이지·저장 구조는 변경하지 않았다. 독립 `ExerciseMotionDemo` 디스패처에 기본 몸풀기 분기만 추가한다. 이전 6~19차 순차 통합 후 이 패치를 적용한다.

## 완성 범위

기존 `basic-warmup`의 6개 안내 그룹을 7개 수동 선택 장면으로 구성했다. 목 좌우 보기, 어깨 앞뒤 돌리기, 골반 좌우 이동, 작은 무릎 굽힘, 지지대 잡고 왼쪽/오른쪽 발목 움직이기, 제자리 걷기다. 걷기는 기존 자체 애니메이션을 재사용하고 나머지는 새로운 원본 벡터 기하다. 외부 영상·모델·그림을 복제하지 않았다.

목의 완전한 원 돌리기 대신 작은 좌우 보기, 발목은 양손 고정 지지대가 있는 변형으로 명시했다. 지지대가 없거나 균형이 불안하면 발목 장면을 건너뛰도록 안내한다. 발을 들거나 다음 준비 자세로 이동하는 과정은 시연하지 않는다. 단계는 자동 전환되지 않으며 변경할 때마다 재생·반복·느린 속도·진행률을 초기화한다.

## 소유 파일과 연결

새 런타임 파일은 `app/lib/routineMotion.ts`, `app/components/RoutineFigure.tsx`, `app/components/RoutineMotionDemo.tsx`이다. 독립 표시 진입점 `app/components/ExerciseMotionDemo.tsx`에 분기를 추가했다. 검사 파일은 `app/lib/routineMotion.test.ts`, `scripts/check-warmup-routine.cjs`이다. 별도 연결은 `<ExerciseMotionDemo exerciseId="basic-warmup" />`로 한다. 공통 페이지 적용은 부모가 수행한다.

## 검증

전체 단위 검사 48개 통과. 새 3개 검사는 각 장면 201프레임의 분절 길이, 고정된 발·손 지지, 발끝 길이, 반복 경계와 서로 다른 움직임을 검사한다. strict TypeScript 및 임시 headless Edge에서 7단계의 320px 배치, 200% 글자, 44px 조작 영역, 모션 감소, 키보드 슬라이더, 0.5배 속도, 단계 전환 시 정지, 자동 단계 전환 없음, 언마운트 검사를 통과했다. 브라우저 네트워크 요청은 전부 차단했다.

어깨 반복 경계의 부동소수점 잔여값을 명시적으로 0 처리했다. 브라우저의 합성 시간 검사에는 React 렌더 완료 대기를 추가해 속도 검사 타이밍을 안정화했다. 발목 장면 캡처를 직접 검토했다. 증거는 `batch20-evidence/after.json`과 7장면 PNG다.

## 한계

의료 처방·개별 추천·허리 질환 안전성 보장이 아니다. 전문가 자세 검수 미실시. 임시 fixture 검사는 앱 본체·실물 기기·스크린리더 음성 검사를 대신하지 않는다. 기본 정리운동, 폼롤러 준비/회복은 아직 제작 작업이 남았으며 이들을 승인 차단으로 취급하지 않는다. 데드버그의 기존 제한과 AB 준비를 실제 굴리기로 확대하는 결정은 별도 범위 확인이 필요하다.

최신 집계는 움직이는 시연 25종(앱 통합 보고 10 + 로컬 미통합 15), AB 정지 준비 도해 1종, 자산 미구현 4종이다. 부모 앱 최종 검사는 승인 대기 상태를 그대로 유지한다.
