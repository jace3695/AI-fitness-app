# 남은 세 항목의 정확한 상태와 필요한 입력

2026-10-20, 23차 이후. 요청 당시 남은 카탈로그 항목은 정확히 **5개**였다: 기본 정리운동 (`basic-cooldown`), 폼롤러 준비 (`foam-roller-prep`), 폼롤러 회복 (`foam-roller-recovery`), 데드버그 (`dead-bug`), AB 슬라이더 준비 자세 (`ab-slider-ready-position`).

기본 정리운동은 21차 8장면, 폼롤러 준비는 22차 부위 7장면+몸풀기 7장면으로 구현·격리 검증 완료했다. 호흡 정리는 정지 안내임을 표시한다. 현재 미완료는 아래 **3개 카탈로그 항목**이다. 이를 3개의 동일한 승인 차단이나 전부 미제작 상태로 표현하지 않는다.

| 정확한 항목 | 현재 산출물 | 남은 이유 | 필요한 입력 |
|---|---|---|---|
| 폼롤러 회복 | 9단계 중 7개 움직임 시범 및 2개 보류 화면 | “바깥 허벅지”만으로 외측 대퇴 근육·TFL·IT밴드 직접 압박 구별 불가. 접촉 부위를 임의로 바꾸면 기존 안내 의미가 달라짐 | 전문가가 확인한 대상 연부조직, 피할 구간, 지지 자세/변형. 좌우 2장면을 그 정의에 맞춰 추가한 뒤 전체 완료 검증 |
