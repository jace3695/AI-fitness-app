# 6차: 덤벨 플로어프레스

기준 `2f31bb5`. 기존 3→4→5차 패치 다음 `batch6-additions.patch`를 적용한다.

동일한 3차원 좌표로 사선/옆면을 동기화했다. 사선은 양팔과 덤벨 간격을 읽도록 높이를 펼쳤고 이를 화면에 명시한다. 옆면은 상완·머리·발의 바닥 접촉을 확인한다. 팔꿈치 과신전을 그리지 않으며 덤벨이 서로 닿지 않는다. 준비 자세에서 반복만 표현하며 덤벨을 들고 눕고 일어나는 과정은 범위 밖이라고 밝힌다.

독창적인 코드/SVG이며 외부 그림·영상·모델을 사용하지 않았다. [Sweat의 원문 동작 설명](https://sweat.com/exercises/dumbbell-floor-press)에서 굽힌 무릎/발 지지, 팔꿈치가 바닥에 가볍게 닿는 하강, 위로 밀어올리는 흐름을 확인했다. 기존 카탈로그의 잠그지 않는 팔꿈치 조건을 유지한다. 중량 처방, 안전 보장, 기존 문서의 권장 무게를 새 시범에 옮기지 않았다.

신규: `floorPressMotion.ts`, `.test.ts`, `FloorPressFigure.tsx`, `check-floor-press-motion.cjs`.
기존 독립 시범 `ExerciseMotionDemo.tsx`, `exerciseMotion.ts`에 ID/렌더러만 등록한다. 공통 목록/페이지/저장 구조 및 OCR은 변경하지 않는다.

검사: 401프레임 상완/전완 길이, 좌우 대칭, 손목 수직 적층, 고정 지지점, 바닥 관통 없음, 손 간격, 주기 복귀, 두 투영 좌표 범위. 브라우저 검사는 strict 타입·320px·200% 글자·44px 조작부·키보드·터치·배속·reduced-motion을 포함한다. PNG는 검증 증거이며 런타임에 포함하지 않는다.

한계: 단순 관절 모델은 견갑골·척추 곡선·손가락 그립·실제 하중을 나타내지 않는다. 사선은 길이 측정에 쓰지 않는다. 전문가 자세 검수·실기기 검증은 미실시이며 허리 질환에 안전하다는 의미가 아니다.
