# 13차: 한 손·양발 지지 원암 덤벨 로우

12차 이후 적용한다. 고정된 지지 손·양발·몸통, 길이가 일정한 상완·전완·다리, 뒤로 당겨지는 팔꿈치와 덤벨을 자체 3차원 좌표로 구성했다. 사선과 윗면은 동일 좌표를 투영한다. 무릎을 받침대에 올리는 변형은 사용하지 않는다.

지지 방식은 기준 앱 `app/data/exerciseGuides.ts`의 “의자/테이블 지지 원암 덤벨 로우”에 맞춘다. [ACE Single-arm Row](https://www.acefitness.org/resources/everyone/exercise-library/126/single-arm-row/)에서는 팔꿈치를 굽혀 상완을 뒤로 당기고 몸통 회전을 억제하는 원리만 참고했다. ACE의 무릎 벤치 지지를 같은 변형이라고 주장하지 않는다. 외부 영상·이미지·모델을 복제하지 않았다.

새 파일: `supportedRowMotion.ts`, `.test.ts`, `SupportedRowFigure.tsx`, `check-supported-row-motion.cjs`. 독립 디스패처에 해당 ID만 등록했다. 공통 목록·페이지·저장 구조는 수정하지 않는다.

검증: 401프레임 고정 접촉·몸통·팔과 다리 길이·덤벨 상승·밴드 로우와 다른 경로·닫힌 주기 검사. 타입·격리 Edge·320px·200% 글자·키보드·터치·느린 재생·모션 감소 검사를 통과했고 시작/당김 화면을 검토했다. 실제 받침대 안정성, 힘, 관절 부하, 전문가 자세 검수와 의학적 적합성은 검증하지 않았다.

한쪽 팔 동작만 제공하며 덤벨을 집거나 좌우를 바꾸는 과정은 제외한다. 중량·횟수·각도 처방 없음. 허리 질환에 안전하다고 보장하지 않는다. 앱 미통합 상태다.
