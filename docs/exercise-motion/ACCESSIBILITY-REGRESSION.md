# 5종 시연 모바일·접근성 회귀 보강

## 작업 범위

독립 저장소 `motion-extension`에서만 편집·검증했다. 주 저장소의 기존 기준 `36bb28d5b01a720b973fb9e45dd18f95b07f7375`에서 벽 푸시업 추적 코드 두 파일만 읽어 로컬 검사 복사본으로 가져왔다. 다른 주 저장소 파일·작업트리·계정·개인 기록은 검사하지 않았다.
벽 시연 기준 복사 커밋은 `fc2b7f5`이며, 이 커밋 자체를 주 저장소에 적용하면 안 된다(이미 존재하는 파일이다).
독립 저장소의 기존 4종과 벽 푸시업을 임시 Edge 프로필에서 실행했다. 로그인된 사용자 Edge 탭에 연결하지 않았고 모든 페이지 요청을 차단했다. push·배포·유료 호출·개인 데이터 이용 없음.

## 이번에 확인한 결함과 수정

| 확인 사항 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 벽 푸시업 reduced-motion | 초기 설정·동적 변경 미반영 | 초기 reduce에서 재생 비활성화, 재생 중 reduce로 변경 시 정지, 해제 후 자동 재개 없음, 정지 자세·슬라이더 사용 가능 |
| 벽 푸시업 재생 상태 | 버튼 문구만 변경 | 기존 4종과 같이 `aria-pressed`도 제공 |
| 5종 터치 조작 영역 | 재생 높이 36px, 체크박스 라벨 20px, 슬라이더 16px, 자세 버튼 20~30px | 재생·체크박스 라벨·슬라이더·자세 버튼 최소 44px 높이, 모든 측정 대상 너비도 44px 이상 |
| 검사 스타일 | 이전 합성 CSS가 모든 버튼에 padding을 추가하여 작은 영역을 가림 | 실제 컴포넌트 클래스에서 Tailwind CSS 생성. 전역 버튼/input 크기 보정 없음 |

44px는 이번 제품 조작성 검사의 기준이며 WCAG 적합성 인증으로 표현하지 않는다. 체크박스 자체의 그림 크기를 키운 것이 아니라 연동된 라벨 전체의 터치 영역을 확장했다.
새 운동·처방·운동 좌표·안전성 문구는 추가하거나 수정하지 않았다.

## 새로 검증한 범위

5종 모두: 벽 푸시업, 앉아서 무릎 펴기, 가벼운 덤벨 컬, 지지형 양발 종아리 들기, 지지형 옆 다리 들기.

- 기본 320px 터치 화면에서 각 조작 영역 측정, 라벨 가장자리 탭이 실제 체크박스를 전환하는지 확인.
- 모바일 슬라이더 트랙 탭, 재생/일시정지 탭과 정지 후 위치 유지.
- 키보드 Home/End/ArrowRight, Tab 순서, Space 체크박스, Enter 재생/Space 정지, 슬라이더 `:focus-visible` 확인.
- 기존 4종뿐 아니라 벽 푸시업도 포함하여 제어된 rAF 시계에서 실제 컴포넌트 정상/0.5배속 진행량 2:1 검사.
- reduced-motion 초기 설정과 재생 중 동적 변경, 설정 복원 후 자동 재개 없음.
- 320px 화면에서 기본 글자 및 200% 글자 크기의 가로 넘침 없음. 확대 스크린샷은 `accessibility-evidence/`에 보관.
- TypeScript strict 검사 통과, 브라우저 pageerror 없음.

중복 축소: 기존 7개 좌표/시계 단위 테스트, 기존 전체 재생·반복 흐름 스크립트와 전체 앱 빌드는 재실행하지 않았다. 변경된 조작·표시 및 벽 시연의 접근성 차이를 검사했다.

## 재현

`node scripts/check-motion-accessibility.cjs <설치된 node_modules 절대경로>`

필요한 기존 설치 패키지: TypeScript, React, React DOM, Tailwind CSS, Playwright 및 설치된 Edge. 다운로드나 설치는 수행하지 않는다. 실행 과정에서 Tailwind CSS 및 번들은 현재 작업공간 `accessibility-evidence/generated/`에만 생성한다.
`--baseline`은 현재 코드의 측정만 저장한다. 보관된 `before.json`은 수정 전 코드에서 실행한 결과이므로 수정 후 다시 덮어쓰지 않는다.
`after.json`과 5개 확대 화면 PNG는 수정 후 결과다.

## 순차 통합

`accessibility-fixes.patch`만 적용한다. 이미 두 지지형 시연이 통합된 코드가 전제다.
패치는 기존 `ExerciseMotionDemo.tsx`와 `WallPushupDemo.tsx`만 UI 수정하고, 새 검사 스크립트 2개 및 보고·증거 파일을 추가한다. `.gitignore`와 벽 운동 좌표 모듈은 포함하지 않는다.
격리된 기존 코드 복사본에서 `git apply --check`, 실제 적용, `git apply --reverse --check`를 확인했다. 주 저장소에서는 부모가 최신 변경과 충돌 여부를 다시 확인한 뒤 순차 적용한다.

## 남은 한계

모바일은 320px Edge 터치 에뮬레이션이며 실물 iPhone/Android·WebKit 검증이 아니다. 스크린리더 음성 출력·전체 WCAG 감사·OS 잠금은 미검증이다.
실제 주 앱 로그인·카드 펼치기/접기·페이지 이동은 검사하지 않았다. 글자 확대 시 긴 설명은 세로 스크롤을 요구하며, 가로 넘침과 조작 가능성을 검증했다.
새 안전성 판단이나 전문 자세 인증은 하지 않았다.
