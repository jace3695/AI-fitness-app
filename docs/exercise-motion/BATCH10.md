# 10차: 덤벨 고블릿 스쿼트

9차 다음 `batch10-additions.patch` 적용. 신규 `gobletMotion.ts`, `.test.ts`, `GobletFigure.tsx`, `check-goblet-motion.cjs`. 공통 목록/페이지/저장 구조와 OCR은 변경하지 않는다.

기존 맨몸 스쿼트 코드를 호출하거나 이름만 변경하지 않았다. 3차원 좌표로 발 고정, 무릎/발의 정면 방향, 상체, 양손의 덤벨 윗부분 접촉, 수직 덤벨을 별도로 구속했다. 정면은 양손·양무릎을, 옆면은 하강과 가슴 앞 덤벨을 표시한다. 덤벨을 집어 들거나 내려놓는 과정은 범위 밖이라고 명시한다.

[NASM Goblet Squat](https://www.nasm.org/resource-center/exercise-library/goblet-squat)의 세로 덤벨, 양손 윗부분 받침, 가슴 가까이 유지, 고관절/무릎 굽힘과 복귀를 참고했다. 허리 부담 감소·모두에게 적합하다는 주장, 중량·횟수 처방은 옮기지 않았다. 외부 이미지·영상·모델은 사용하지 않았다.

검사: 401프레임 상완/전완/대퇴/하퇴/몸통 길이, 발 접촉, 무릎 방향, 양손-덤벨 접촉, 수직 하중, 팔꿈치/무릎 비간섭, 폐쇄 주기, 두 시점 범위. strict 타입·격리 Edge·320px·200% 글자·44px·키보드/터치·배속·동작 줄이기 검사를 수행했다. 증거 `batch10-evidence/`.

한계: 단순 관절 모델이며 실제 압력 중심·그립 강도·척추 곡선은 검사하지 않는다. 예시 깊이나 하중을 개인별 목표로 삼지 않도록 안내한다. 전문가 자세 검수·실기기 검증은 미실시다.
