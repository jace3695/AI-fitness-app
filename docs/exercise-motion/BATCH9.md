# 9차: 밴드 팔로프 프레스

8차 다음 `batch9-additions.patch` 적용. 신규 `pallofMotion.ts`, `.test.ts`, `PallofFigure.tsx`, `check-pallof-motion.cjs`. 독립 플레이어와 ID 등록만 확장하며 공통 목록·페이지·저장 및 OCR 변경 없음.

몸통과 골반은 고정하고, 두 손이 모인 채 몸 앞으로 이동한다. 어깨-손 목표로부터 2분절 팔꿈치 위치를 계산해 상완/전완 길이를 보존했다. 윗면은 손의 전방 이동과 측면 고정점을 함께 보여 준다. 풀어파트처럼 손 간격을 벌리거나 외회전처럼 전완만 회전하지 않는다.

[PureGym Pallof Press](https://www.puregym.com/exercises/abs/pallof-press/)의 가슴 높이 고정점, 옆으로 선 몸, 양손 전방 밀기와 제어된 복귀를 확인했다. 원문의 재활 효과·모두에게 적합하다는 주장이나 저항 권장값은 채택하지 않았다. 독창적 SVG/좌표이며 외부 서비스 영상·모델·그림은 사용하지 않았다.

검사: 401프레임 팔 길이·손 중심 이동·손 간격·고정 어깨/몸통/발/고정점·잠기지 않는 팔꿈치·주기 복귀·투영 좌표. strict 타입·격리 Edge·320px·200% 글자·44px 조작·키보드/터치·배속·동작 줄이기 검증 통과. 증거는 `batch9-evidence/`.

제한: 한 방향의 측면 저항 예시다. 반대쪽은 고정 방향부터 재준비한다. 실제 힘·복부 활성·미세 척추 자세와 밴드 설치 적합성을 평가하지 않는다. 전문가 자세 검수와 실기기 검증 미실시. 허리 질환에 안전하다는 보장이 아니다.
