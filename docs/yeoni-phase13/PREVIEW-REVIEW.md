# Preview 실제 AI 연결 확인

대상: 승인한 `c80eee6`과 같은 파일 내용인 GitHub `5aa4da5` / Vercel `dpl_9WYVr56L9gDuoPGcKo7LixaVk117`.

검수 주소: https://ai-fitness-app-git-agent-yeoni-cat-an-ec20ab-jace3695s-projects.vercel.app/assistant/character-check

이 절차는 사용자 브라우저에서 진행하는 **별도 기능 검수**다. 사용자 브라우저의 로그인 세션은 자동 검증 브라우저와 공유되지 않는다.

1. 검수 화면을 연다. 로그인 통신 오류가 나면 여기서 멈추고 오류 문구와 발생 시각만 기록한다. 비밀번호·인증코드·토큰은 공유하지 않는다.
2. 로그인 후 `최신 기록 다시 확인` 또는 `조언받을 기록 확인` **오른쪽의 밑줄 글씨 `예시 기록으로 먼저 보기`**를 누른다. `가상의 예시 기록`과 `실제 내 기록을 사용하지 않는 예시` 표시를 확인한다. `서버에 저장된 기록 기준`과 `아직 분석할 기록이 없어요`가 보이면 아직 실제 기록 조회 화면이다. 새 기록을 만들 필요 없이 예시 버튼을 선택하면 된다.
3. 기본 질문을 유지하고 Google 자료 활용 안내를 읽은 뒤 체크한다. `무료 AI 조언받기`를 한 번 누른다. 오류가 나면 재요청하지 않는다.
4. 생성된 실제 답변이 캐릭터 패널에 표시되는지, 고양이형/인간형을 바꿔도 같은 답변이 유지되는지 확인한다. 새 답변에 맞는 저장 음성이 없으므로 음성 비활성과 글 표시가 정상이다.
5. 새로고침 후 이전 조언이 자동 재생·재생성되지 않는지 확인한다.

기록할 결과: 기기/브라우저, 확인 시각, 예시 기록 표시 여부, AI 요청 성공 또는 오류 문구, 캐릭터 답변 표시 여부, 새로고침 후 자동 재요청 여부. 화면을 공유할 때 계정 정보는 가린다.

이 검수는 새 음성 생성이나 PHASE 14/15의 실제 오디오·잠금·Bluetooth·장시간 발열 검수를 대신하지 않는다. 그 항목들은 이후 별도로 진행한다.
