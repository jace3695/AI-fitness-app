# 체성분 일반 채팅·분석 문장·화면 이력 연결

이 문서의 909개/74항목은 1차 연결 시점이다. 후속 통합 검토에서 발견한 보호 공백과
최종 후보 범위는 [`body-coach-release-candidate.md`](./body-coach-release-candidate.md)를 따른다.

2026-10-20. 기준 HEAD `3777f3cb89762099f2af79ab16567b9da32bd932`.
이전 체성분/운동 결합 변경을 보존한 후속 미커밋 작업이다.

## 기존 데이터 흐름 확인

| 경로 | 기존 동작 | 이번 변경 |
|---|---|---|
| `AssistantClient.sendChat` → `/api/assistant/chat` | 입력 및 최근 대화 문맥을 앱 서버로 전송, 서버 대화 DB 저장. 일반 fallback은 AI router 정책에 따름 | 인바디·체성분·BMI 등 명시적 체성분 질문은 요청 전에 로컬 분기 |
| `FreeAdvicePanel` → `/api/ai/free-advice` | 요약 미리보기 및 Google 전송 확인을 거치는 별도 경로 | 수정·자동 활성화·동의 확대 없음 |
| `FitnessAiCoachPanel` → `/api/fitness/coach` | 무료 모드도 앱 서버에서 계산하고 `fitness_ai_review_history` 저장 시도 | 기존 요청 유지. 신규 체성분 문장/이력은 서버 payload에 넣지 않음 |
| `BodyCompositionCoach` | 독립 무료 점검 및 6종 분석 버튼에서 로컬 결합 표시 | 같은 계산 결과의 분석 문장과 화면 메모리 이력 추가 |

이번 작업에서 외부 API/DB는 실제 호출하지 않았다. “로컬”은 새 체성분 분기에 대한 설명이며
앱의 모든 일반 대화·기존 운동 분석이 브라우저만 사용하도록 바뀌었다는 뜻은 아니다.

## 구현

- `localBodyConversation.ts`: 로컬 질문 식별, 기존 결합 결과의 설명 문장, 후속 서버 대화
  문맥에서 `localOnly` 메시지를 제거하는 순수 함수. 서버 문맥의 최근 8개 제한은 제거 후 적용한다.
- `readLocalBodyReview.ts`: 기존 로컬 저장소·설정·선택 계획을 읽어 기존 결합 엔진을 호출한다.
  쓰기/네트워크 기능이 없다.
- 일반 채팅에서 명시적 체성분 질문은 질문과 답변 모두 `localOnly`로 표시한다.
  기존 인증 소유자와 로컬 동기화 소유자가 일치해야 읽으며, 읽기 실패는 외부 fallback을 호출하지 않는다.
- 로컬 답변에는 TTS 버튼/캐릭터 음성 생성 결과를 붙이지 않는다. 이후 일반 질문을 보내도
  로컬 질문/답변은 서버 문맥에 포함하지 않는다. 원래 일반 명령의 확인/전송 경로는 유지한다.
- 같은 화면의 로컬 대화는 최대 10쌍이며 기존 일반 대화 순서를 보존한다.
  기록 변경, 계정 변경, 새로고침/화면 종료 시 없어진다. 계정 전환 후에는 화면 재진입 전
  로컬 읽기를 막는다. 로컬 대화만 비우는 버튼은 DB를 호출하지 않는다.
- 로컬 대화만 존재할 때 기존 DB 대화 삭제 버튼은 활성화하지 않는다.
- 분석 패널의 문장 이력은 현재 화면에 최대 5개이며 동일 내용은 중복하지 않는다.
  기록/계정 변경 때 비우고, 독립 비우기·접기·키보드 조작을 제공한다.

`localStorage`, `sessionStorage`, 서버 DB에 새 이력을 쓰지 않는다. 따라서 재시작 후에도
복구되는 영구 이력 연결은 **미구현**이다. 저장 위치, 계정별 분리, 보존/삭제, 클라우드 동기화
제외 여부를 결정해야 하며 이 작업에서 동의나 저장 범위를 넓히지 않았다.

## 추천 설명과 전문 판단 경계

문장은 기존 수행·통증·피로·컨디션 규칙의 유지/조정/보류 이유, 기존 계획 구성, 변경 전후,
준비 조건과 검증된 출처의 체성분 비교를 설명한다. 맨몸·보유 장비 목록을 안내하지만
제품 하중·밴드 저항을 추정하거나 장비를 이유로 자동 교체하지 않는다.
슬라이딩보드·힙브릿지 제외 필터, 기존 통증/안전 규칙은 그대로다.

체성분 키워드가 있는 저장/삭제/진단 요청도 로컬에서 처리하되 실행 불가를 명시한다.
키워드 라우팅은 자유 대화를 이해하는 새 AI가 아니며 일반 의료 질문 전체의 분류기가 아니다.
체성분 수치에서 질환·근손실·의료적 운동 적합성이나 처방 강도를 새로 판단하지 않는다.
의학적 처방 매핑, 서버 결과 문장 재작성, 영구 이력/일반 외부 AI 문맥 연결은 보류 범위다.

## 검증 방식

`localBodyConversation.test.ts`는 12개 순수 단위 검사로 질문 경계, 기록 변경/진단 불가,
누락 자료, 안전 보류, 장비 안내, 서버 문맥 제외 및 비변경을 확인한다.

`local-body-chat-browser.mjs`는 실제 `AssistantClient`를 렌더링하되 인증·DB·일반 API와
음성 등 주변 UI를 합성 대역으로 사용한다. 외부 네트워크 차단, DB 쓰기 시 즉시 실패,
후속 일반 질문의 payload 확인을 포함한다. 호스팅 인증/실제 계정 검사가 아니다.
처음 검사 도구의 모듈 경로·합성 인증 객체 문법·접힌 메뉴 선택 오류는 수정했으며,
제품의 외부 경로를 열거나 보안 설정을 바꾸어 통과시키지 않았다.

이전 897개 결과는 이전 변경 시점이다. 최종 결과 및 로그는 아래에 별도로 기록한다.

## 선별 변경과 후속 결정

이번 후속 변경: `AssistantClient.tsx`, `BodyCompositionCoach.tsx`,
`localBodyConversation.ts`와 단위 검사, `readLocalBodyReview.ts`,
두 브라우저 검사 및 이 문서. 이전 미커밋 `bodyCompositionCoach`/`bodyWorkoutReview`와
`FitnessAiCoachPanel` 연결에 의존한다. 이전 전체 개발 PR을 운영에 합칠 범위가 아니다.
모든 변경은 로컬 검토 상태로 유지했다.

현재 로컬 경로에 추가 승인 차단은 없다. 영구 이력이 필요하다면 저장 매체와
계정별 보존·삭제·동기화 제외 설계를 먼저 결정해야 한다. 실제 DB 쓰기나 외부 AI에
건강 문맥을 보내는 변경은 이번 권한에 포함되지 않았으며 자동 진행하지 않았다.
