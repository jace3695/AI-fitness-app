# 체성분 분석 이력 로컬 구현 상태

기준 커밋 a08d9cf6b8cebf41dbc74916aa675fc25d61636b 이후 미게시 후보다. 이번 주 일요일 2026-10-25 KST는 전체 기능 목표이며 이 문서는 전체 완료 선언이 아니다. 이전 first-use-readiness 문서의 1~2작업일은 중간 사용 가능 범위였고 추가 기능 전체 기간이 아니다.

## 구현

- `app/components/BodyAnalysisHistory.tsx`: 저장 내용 확인, 명시적 동의, 계정 저장, 명시적 조회, 이전 이력 추가 조회, 개별 삭제 확인. 기록 갱신·계정 전환·늦은 응답을 분리한다. 응답 유실 재시도는 동일 UUID를 사용한다.
- `app/components/BodyCompositionCoach.tsx`, `app/assistant/AssistantClient.tsx`: 실제 무료 점검과 비서의 로컬 체성분 설명을 이력 저장 후보에 연결했다. 기존 조언 URL 입력 유지 수정도 보존했다.
- `app/api/fitness/body-analysis-history/route.ts`: 인증 소유자와 예상 소유자 일치 검사, 소유자별 읽기/삽입/삭제, 변경 불가 스냅샷, 충돌 검증, 동일 시각의 UUID 보조 정렬을 포함한 페이지 조회. DB 오류를 성공이나 빈 목록으로 바꾸지 않는다.
- `lib/body-analysis-history.ts`: 날짜·내용·스키마·UUID 검증.
- `schema-draft.sql`: 서비스 적용 전 검토용 SQL 초안. 사용자별 RLS와 열 단위 삽입 권한, 업데이트 금지, 사용자 삭제 시 참조 정리를 포함한다. 마이그레이션 폴더에 넣거나 서비스에 적용하지 않았다.

저장하는 것은 사용자가 동의한 고정 규칙 분석문과 기준일이다. 원본 사진·원본 건강 기록·일반 대화 전체를 저장하거나 외부 AI/음성으로 전달하는 기능이 아니다. 일반 점검에는 자동 업로드가 없다.

## 남은 차단점과 다음 단계

1. Supabase CLI 도움말 실행이 작업공간 밖 `C:\Users\박재민\.supabase` 생성 단계에서 EPERM으로 종료됐다. 다른 경로나 계정으로 우회하지 않았다. CLI 마이그레이션 생성·서비스 적용은 미실행이다. SQL 초안 검토 및 승인된 환경에서의 공식 마이그레이션 준비가 필요하다.
2. 이력 실제 저장을 사용 가능으로 판정하려면 DB 변경 승인 후 두 폐기 가능한 테스트 계정으로 생성·유실 응답 재조회·삭제·계정 분리를 검증해야 한다. 기존 개인 기록과 백업은 대상이 아니다.
3. 외부 AI 연결·모델·한도·전송할 데이터·테스트 계정 승인은 아직 없다. 무료 모드와 유료 호출 차단을 유지했다. 일반 대화 전체의 영구 이력과 새 답변 음성은 이 분석문 저장 완료에 포함하지 않는다.
4. 운동 잔여 3종 동작 시범은 정확한 동작/안전 검증이 필요하다. 검증되지 않은 도해를 정확한 시범으로 활성화하지 않았다. 기존 운동 비교·다음 날 상태·안전 추천 구현은 재개발하지 않았다.
5. 일본어 및 공통 캐릭터는 별도 작업 소유권을 유지했다. 일본어 작업의 원본 읽기 거부를 대리 복사로 우회하지 않았다. 별도 결과를 자동 병합하지 않았다.
6. 원격 push, main 병합, 게시·배포, 실제 기록·서비스 스키마/권한 변경, 외부 AI 호출은 실행하지 않았다. 이 후보를 게시하려면 변경 범위와 실제 검증 결과를 먼저 검토해야 한다.
