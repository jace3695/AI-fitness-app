# 무료 AI 조언 연결 — 2026-09-14

사용자 지시에 따라 추가 비용이 드는 작업은 보류하고, 음식 사진과 같은 무료 Gemini 전용 프로젝트로 요청형 조언을 연결한다. 연이 한국어 목소리는 `ko-KR-Chirp3-HD-Zephyr`를 유지한다.

## 이번 구현

- `/assistant`, `/language`, `/fitness`, 가계부의 **분석 → AI 상담**에 공통 무료 AI 조언 화면을 추가했다.
- **조언받을 기록 확인 → 보낼 요약 확인 → 자료 활용 동의 → 무료 AI 조언받기** 순서다. 화면 진입·미리보기만으로 외부 AI를 호출하지 않는다.
- **예시 기록으로 먼저 보기**는 계정 기록을 조회하거나 저장하지 않는 고정 합성 예시다. 미리보기·결과 모두 실제 내 기록과 구분해 표시하며, 동의 후에만 같은 무료 Gemini로 조언을 요청한다. 예시도 무료 AI 이용 한도를 사용한다. 사용자가 임의의 기록 JSON을 서버에 주입할 수는 없다.
- 서버가 인증된 사용자 본인의 기록을 읽어 최근 28일의 고정 숫자 항목만 계산한다. 운동 수행·통증 신호·기록한 물 섭취, 일본어 활동일·복습 항목 수, 수입·지출·저축 합계가 대상이다. 새 과정과 기존 일일 학습의 같은 날짜는 중복 집계하지 않는다.
- 이름·이메일·거래처·개인 메모·대화 원문은 자동 요약에 포함하지 않는다. 선택 질문은 입력한 문장 그대로 Google에 보내며 화면에서 이를 안내한다. 무료 서비스의 자료 활용 안내에 동의해야 요청할 수 있다.
- 미리보기 후 숫자 요약이 달라지면 다시 확인하도록 한다. 기록 없음, 조회 실패, 1,000건 조회 상한으로 인한 누락은 구분해 AI 요청을 중단한다. 기록이 없는 날을 활동 없음·건강함으로 추정하지 않는다.
- 조언은 요약·오늘 할 행동 최대 3개·기록 근거·분석 한계로 표시한다. 계획·금액·기록을 자동 수정하거나 조언을 DB에 저장하지 않는다. 이 단계의 조언은 화면을 벗어나거나 새로고침하면 사라진다.
- 언어 홈은 페이지 진입만으로 빈 학습일·수정 시각을 저장하지 않도록 바꿨다. 실제 ‘직접 완료’·‘완료 취소’ 동작은 계속 저장한다.

## 비용과 음성 경계

- `GEMINI_FREE_API_KEY`와 `GEMINI_FREE_TIER_CONFIRMED=true`가 모두 있어야 한다. 기존 유료 키와 공통 AI 라우터는 사용하지 않는다.
- 현재 사진 분석과 동일한 `gemini-3.5-flash-lite`로 요청당 한 번만 호출한다. 검색·유료 모델 전환·자동 재시도는 없다. 무료 한도 소진 시 기본 기록·통계를 계속 이용할 수 있다.
- 확인 변수는 운영자의 **결제 계정이 없는 프로젝트라는 확인**이며 Google의 결제 상태를 실시간으로 조회하는 기능이 아니다. 해당 프로젝트에 결제를 연결하기 전에 확인 변수를 해제해야 한다. 사진과 조언은 같은 프로젝트의 무료 한도를 공유한다.
- 한국어 TTS는 비용 차단을 유지한다. API 응답에 Zephyr 선택과 대기 이유를 표시하고, 가계부와 빠른 명령에서 임의의 기기 목소리로 바꾸지 않는다. 일본어 학습·운동 타이머의 별도 음성 경로는 이번 변경 대상이 아니다.
- Google Cloud 화면이 현재 브라우저에서 `Site Unavailable`로 표시되어 TTS 계정의 결제 상태·남은 무료 문자수는 확인하지 못했다. Zephyr 실제 재생, 월 문자수 사전 집계·동시 요청 차단은 **미구현/미검증**이다. 유료 기능을 켜거나 결제를 연결하지 않았다.

공식 조건: [Gemini 가격·자료 처리](https://ai.google.dev/gemini-api/docs/pricing), [Gemini 프로젝트 단위 한도](https://ai.google.dev/gemini-api/docs/rate-limits), [Google TTS 가격](https://cloud.google.com/text-to-speech/pricing). TTS의 무료 제공량이 있다는 사실만으로 계정의 추가 과금이 차단되지는 않는다.

- 신규 테스트는 소유자 필터, 최근 28일·한국 날짜 경계, 새 일본어 과정 포함, 개인정보 제외, 부분 조회 차단, 미동의 차단, 잘못된 요청 형식, 오래된 미리보기 차단, 무료 한도·실패 시 유료 대체 없음, Zephyr 선택 보존을 확인한다.

## 계정 변경 없이 실제 Gemini를 확인하는 방법

테스트 계정의 가계부는 프로필·지출·수입·저축이 모두 0행이었다. 실제 Gemini 응답 검증용 임시 프로필과 합성 지출 1건을 추가하는 작업은 자동 승인 검토가 **호스팅 계정 변경에 대한 명시적 승인 부족**으로 거절했다. 다른 방법으로 쓰기를 시도하지 않았다. 동일 계정의 운동·식단 상태와 언어 상태 전체 행 해시가 전후 일치하고, 가계부 네 테이블도 0행을 유지함을 재조회했다.

더 안전한 대안으로 계정의 금융 기록을 추가하는 방법을 중단하고 **서버에 고정된 가상 예시**로 검증하도록 구현했다. 이 경로는 로그인 확인 후 실제 계정 기록의 조회·쓰기를 모두 생략한다. 예시와 본인 기록은 요청 종류·미리보기 해시·화면 문구로 구분하며 예시 확인을 본인 기록 전송 동의로 재사용할 수 없다.
