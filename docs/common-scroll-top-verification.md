# 공통 TOP 버튼 및 운동 화면 전환 검증 — 2026-09-07

## 변경과 첨부 자료 확인

일본어 전용 TOP 버튼을 인증된 앱의 공통 메뉴에 연결했다. 홈, 운동, 가계부, 식단, 일본어, 자기계발, 통합 달력, 통합 설정과 각 하위 화면에서 같은 컴포넌트를 사용한다. 로그인/PIN 잠금 화면에는 공통 메뉴가 표시되지 않는다.

- 문서를 300px 초과해 내리면 TOP 버튼 하나를 표시하고 맨 위로 이동하면 제거한다.
- 버튼 크기는 64×48px이며 접근성 이름은 ‘맨 위로 이동’이다. 포커스 표시와 키보드 실행을 지원한다.
- 하단 메뉴·앱 설치 버튼과 간격을 두고 안전 영역을 반영한다. 767px 이하에서는 하단 여백을 더 확보한다.
- ‘전체’ 메뉴가 열리면 TOP을 제거한다. 모달이 열렸을 때 숨기는 CSS도 추가했다.
- 스크롤 리스너는 passive와 requestAnimationFrame을 사용하고, 경로 변경·해제 시 리스너와 예약 프레임을 정리한다. OS 동작 줄이기 설정에서는 즉시 이동하고 등장 애니메이션을 생략한다.
- 일본어의 기존 TOP 표시를 제거해 중복되지 않게 했다.

사용자가 첨부한 약 116초 영상은 Edge의 iPhone 16 Pro Max 440×956px 에뮬레이션이다. 변경 전 일본어 TOP이 하단 ‘전체’ 메뉴와 겹치는 장면, 휴대폰에서 과정 카드가 좁은 3열로 표시되는 장면을 확인했다. 과정 카드는 767px 이하에서 한 열로 표시하도록 개선했다. 이 영상은 수정 후 320·390px 실사용 검증의 증거로 사용하지 않는다.

처음 첨부된 Vercel 환경변수 화면에는 GEMINI_API_KEY와 Google Calendar 설정, Supabase 공개 설정이 보이며 GOOGLE_TTS_API_KEY는 보이지 않았다. 비밀 값은 읽거나 문서에 기록하지 않았다. 직전 앱 프리뷰의 음성 요청은 2026-09-07 09:54:48 UTC에 HTTP 503 및 `[japanese-tts] configuration_missing`으로 확인됐다. TOP 검증 당시에는 음성 요청을 다시 실행하지 않았다. 이후 키 등록 및 성공 재생은 아래 추가 검증에 기록했다.
