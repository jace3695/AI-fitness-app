# 운동 완료 명령 — 2026-09-16

6단계의 운동 완료 명령을 확인·이력·되돌리기 흐름으로 연결한다. 원래 6단계 전체는 부분 완료이며 식단과 다른 기록 명령은 후속이다.

## 지원 범위

- 연이 대화 또는 빠른 명령에 `오늘 운동 완료했어` 입력 → 날짜·변경 내용 확인 → 확인하고 저장.
- 한국 시간의 오늘에 사용자가 운동을 완료했다는 사실을 `직접 완료 기록`으로 저장한다. 휴식일에도 실제 수행한 사실을 기록할 수 있다. 계획을 수행했다거나 계획의 모든 동작·횟수·세트를 마쳤다고 추정하지 않는다.
- 운동 종류·세트·횟수·통증·피로·난이도는 자동으로 채우지 않는다. 사용자 지정 계획·날짜별 계획과 유산소·철봉·폼롤러 기록을 유지한다.
- 이미 완료한 날은 추가 저장하지 않는다. 일부 완료·중단·통증·세트 등 일반 운동 상세 기록이 있는 날은 운동 화면에서 확인하도록 안내한다.
- 과거·미래 날짜, 부정·조건·질문·상세 내용이 섞인 명령은 저장하지 않는다. 계획 변경이나 수행 중인 세션의 완료 기능은 이번 명령에 포함하지 않는다.
- 공통 실행 이력의 운동 탭에서 변경 전후·시각을 조회하고 다시 확인하여 되돌린다.

## 저장·복구

- 로그인한 본인의 RLS 권한과 invoker 함수로 기록과 이력을 한 트랜잭션에 저장한다. 인증 키 추가나 유료 호출이 없다.
- 요청 UUID는 같은 내용으로 재시도하면 같은 영수증을 반환한다. 응답 유실·새로고침 후에도 같은 탭에서 대기 요청을 복구한다. 이미 실행한 요청은 만료 후에도 결과를 재조회할 수 있다.
- 확인은 15분간 유효하다. 한국 시간 날짜가 바뀌거나 운동/비서 기록이 초기화되면 미실행 요청을 거절한다.
- 확인한 오늘의 기록만 비교·수정한다. 다른 날짜나 설정의 후속 변경은 보존한다. 같은 날짜의 유산소 등 어떤 기록이든 이후 달라졌으면 되돌리기를 거절한다.
- JSON 문자열 형식의 이전 저장 자료도 지원한다. 문자열의 공백·키 순서는 정규화될 수 있으나 날짜와 값은 보존한다.
- 운동 또는 비서 초기화 시 실행 이력도 지운다. Auth 계정 삭제는 기존 외래키 cascade를 사용하며 Auth 내부 역할에 앱 권한을 추가하지 않는다.
