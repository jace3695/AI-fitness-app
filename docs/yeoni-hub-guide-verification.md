# 공통 연이 안내와 동작 비용 개선 — 2026-09-07

## 변경 목적과 범위

일본어에서 사용하던 고양이 연이를 홈·운동·식단·가계부·자기계발·달력과 설정 화면에 재사용한다. 안내는 기존 화면 데이터 또는 정해진 문구를 사용하므로 별도 AI 요청이나 데이터베이스 변경이 없다. 그림 연습은 추가하지 않는다.

- 공통 말풍선: 앱 첫 화면은 짧은 인사/현황, 입력·운동·연습·초기화 화면은 작은 정지 안내.
- 통합 설정과 일본어 설정에서 캐릭터 표시, 절약(기본), 홈 반복, 모든 움직임 끄기를 즉시 변경한다.
- 설정은 `yeoniAppearanceSettingsV1`로 이 기기에 저장한다. 같은 출처의 다른 탭에도 storage 이벤트로 반영한다. 개인 기록 초기화 대상에는 포함하지 않는다.
- 새 설정이 없으면 기존 일본어의 숨김·정지 선택을 초기값에 반영한다. 기존 학습 설정의 필드는 이전 버전/클라우드 호환을 위해 보존한다.

## 비용을 줄인 부분

- 기본 동작은 유한한 CSS 애니메이션이다. 홈 반복은 사용자가 선택할 때만 활성화한다. 기존 138,256-byte WebP를 재사용하고 새 이미지·라이브러리·3D 렌더러는 추가하지 않는다.
- 화면 밖, 숨겨진 문서, 입력 포커스, 열린 모달에서는 캐릭터 재생을 정지한다. OS 동작 줄이기도 존중한다.
- 장식용 JavaScript 반복 타이머를 추가하지 않았다. 페이지 상태 이벤트는 공통 구독으로 묶고, 정지 상태에서는 캐릭터의 화면 관찰자를 설치하지 않는다.
- 자기계발 경과 시간은 작은 자식 컴포넌트만 갱신한다. 루틴 목록과 주·월간 통계를 매초 다시 렌더링하지 않는다. 문서가 숨겨지면 표시용 타이머를 정리하고, 다시 보이면 실제 시각으로 따라잡는다. 저장 시간도 시작·종료 시각으로 계산한다.
- 767px 이하 고정 메뉴의 backdrop blur를 불투명 배경으로 바꿔 스크롤 중 필터 합성 비용을 줄인다.

물리 기기의 온도·전력·배터리 소모를 측정한 결과는 아니다. 발열이 없어진다고 보장하거나 개선율을 추정하지 않는다.
