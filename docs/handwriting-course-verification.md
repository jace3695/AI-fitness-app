# 비공개 손글씨 학습

사용자 요청: 필림 교재는 본인만 사용. 공개 GitHub에는 앱 코드만 보관한다.

## 구성
- 원본과 53개 연습지는 GitHub/public 디렉터리에 넣지 않는다.
- 등록용 묶음은 사용자에게 비공개 파일로 전달하고, 앱에서 로그인한 본인의 growth-resources 버킷 경로에 등록한다.
- Storage의 기존 SELECT/INSERT 소유자 RLS를 유지한다. 원본 파일명과 전체 수업을 검증한 후 업로드하며, 재등록 시 기존 파일의 SHA-256을 대조하고 덮어쓰지 않는다.
- 자료 열기는 인증된 download 호출로만 수행한다. 공개 URL 또는 서명 URL은 생성하지 않는다.
- 수업 진도는 기존 growth_sessions의 metrics에 저장한다. DB 구조 변경 없음.
- 원본 PDF 54쪽 가운데 표지를 제외한 53쪽을 12단계·53수업으로 안내한다. 앱의 학습 지시와 자기 점검은 원 강의 설명과 구분한다.
- 종이 연습은 직접 입력한 시간, 화면 연습은 실제 획의 접촉 시간을 저장한다. 글씨 품질 자동 채점 없음.
- /growth/handwriting/free에 기존 자유 연습을 보존한다.

## 검증 상태
- 비공개 구조 변경 이전 전체 테스트 606개 및 빌드 통과.
- 비공개 구조의 코드 검사·단위/DB 테스트·빌드·실제 브라우저 검증 진행 중.
- 운영 계정의 실제 교재 등록은 해당 계정 로그인 후 진행해야 한다. 임의 이메일로 소유자를 조회하거나 지정하지 않는다.
- 실제 iPhone/iPad/Apple Pencil의 새 수업 사용감은 사용자 확인 전.
