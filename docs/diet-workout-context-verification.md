# 운동·식사 기록 함께 보기 — 2026-09-17

## 범위와 한계

식단에 한국 날짜로 어제까지 28일의 운동 표시·운동 후 식사 응답·마지막 식사 시각을 함께 표시한다. 기존 운동 기록에는 실제 시작/종료 시각이 없고 저장 시각만 있어, 이번 단계에서는 시간 간격을 계산하지 않는다. 실제 운동 시각 입력과 시간 간격 비교는 후속 범위다.

- 운동 완료·일부·중단 및 유산소·철봉의 명시적 표시를 사용한다. 저장 시각·목표·메모·소요 시간만으로 운동을 추정하지 않는다.
- 운동 표시가 있는 날의 식사 응답만 예/아니요/미기록으로 집계한다. 운동 미확인은 휴식이 아니다.
- 날짜별 근거에 양쪽 기록을 함께 표시한다. 마지막 식사가 운동 후 식사라고 추정하지 않으며 미기록·잘못된 시각을 구분한다.
- 오늘 입력, 오늘/미래 날짜, 기간 밖 기록과 잘못된 날짜를 제외한다. 동기화된 기존 조회 결과만 사용하며 데이터 쓰기·DB 변경·AI 호출이 없다.
- 저장 형식을 해석할 수 없으면 오류 안내를 표시한다. 기존 공통 동기화 상태와 입력 보호를 유지한다.
