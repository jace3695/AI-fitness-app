# 일반 답변 립싱크 후속 작업 — 2026-10-08

저장 표본 PoC의 PHASE 16 운영 완료와 별개인 확장 작업이다.
운영은 승인된 5298b32/main 62c2141 기반으로 유지한다.

## 이번 구현

- 기존 한국어 Cloud TTS Zephyr 음성·요청·문자 한도 예약 유지.
- 명시적으로 켠 Preview에서만 생성 MP3/발화문을 인증된 정렬 서버에 한 번 전달.
- 음성/문장 해시, 언어, 음성, 음소, 구간, 실제 재생 길이를 검증.
- 기존 답변 읽기 audio.currentTime을 기존 Character Controller에 전달.
- 정렬 실패/초과/미지원이면 음성만 재생하고 자동 재생성하지 않음.
- 페이지 숨김/중지/종료/언마운트 시 채널 해제. 새 애니메이션 루프 없음.
- 서버 설정이 없으면 기본 비활성. 운영 환경변수 변경 없음.

## 검증 결과

- 전체 Node 검사 738/738 통과.
- Python worker 검사 7/7 통과(엔진 모의 실행, 기존 정렬 파일 변환).

- 이 결과는 실제 MFA 서버 실행, 신규 답변 음성 또는 iPhone 검증이 아니다.
- 앞선 운영 브라우저 검사에서 ‘앱 소개’는 `/about` 정상 도착을 재확인했다.
  주소 연결 오류는 재현되지 않아 기능 코드를 변경하지 않았다.

## 아직 완료하지 않은 범위

실제 정렬 서버 미배치. 후속 검증에서 임시 conda 환경에 MFA 3.4.2와
한국어 v3 모델을 설치하고 기존 5.376초 MP3로 실제 worker 실행에 성공했다.

4.20초였다. 음소 구간 66개와 해시·앱 입력 검증이 통과했다.
두 모델 SHA-256은 기존 PHASE 5 출처 기록과 동일하다.

[`services/yeoni-alignment/README.md`](../services/yeoni-alignment/README.md)에 있다.
