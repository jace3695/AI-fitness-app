# 고양이 원본 보존 동작 v3

2026-09-30. 사용자가 고양이 정지 수정본을 확인하고 다음 단계를 요청하여 동작 재연결을 진행했다. 인간형 v3와 고양이 reference-v2 모두 정지 외형 사용자 확인 완료다.

## 변경 이유와 방식

기존 생성 atlas는 원본과 눈·몸·꼬리 비율이 달랐다. 이번에는 확인받은 원본과 눈·입 파츠를 그대로 포장한 `preserved-motion-v3.png`를 사용한다. 첫 칸의 픽셀을 보존하며 다시 그리지 않는다.

원본 그림에 연속적인 2D 변형 좌표를 적용하여 머리·몸·꼬리 움직임을 연결한다. 얼굴 안의 눈·코·입은 같은 회전·이동을 받아 눈 전체가 납작해지지 않는다. 목과 꼬리 밑동은 이어진 면으로 움직여 분리 파츠의 빈틈을 만들지 않는다. 기존 Canvas2D와 공통 Controller의 정규화된 프레임 계약, 음성 시계, 30fps 상한과 정지 정책은 유지했다. 새로운 렌더링 패키지나 TTS 생성은 없다.

고개 회전은 최대 약 2.3도, 고개 수직 이동 4px, 꼬리 회전 약 2.9도, 응원 몸 들기는 최대 5px(360px 설계 기준)로 제한했다. 초기 극단값 검수에서 배경과 꼬리 주변 격자 압축을 발견하여 범위를 줄였고, 삼각형 사이에 가는 밝은 선이 생기는 래스터화 문제도 보완했다. 이동·회전 중 픽셀의 보간은 발생한다. 정지 원본 일치와 움직이는 동안의 원본 인상 유지는 별도 검증한다.

## 동작과 정책

- 기본: 원본 눈 표정으로 깜빡임, 작은 숨쉬기·꼬리 움직임.
- 몸짓: 끄덕임·갸웃·꾸벅 인사·가벼운 응원. 최신 요청 하나만 실행하고 원래 자세로 돌아온다.
- 감정 12개 의미 입력은 유지한다. 승인된 눈 모양과 작은 고개 자세를 조합한다. 홍채 전체 찌그러뜨리기나 원본에 없는 입선을 그리지 않는다. 미세한 감정 표현은 제한적이다.
- 말할 때는 승인받은 7개 입 상태를 사용한다. 무음/일시정지/종료/오류와 `closed` 구간은 원본의 닫힌 입으로 돌아간다. 표정이 발화 입을 덮어쓰지 않는다.
- 기본·립싱크·감정 미리보기 세 곳과 입모양 표본을 새 렌더러로 연결했다. 기존 생성 atlas 파일은 이력으로 남지만 새 미리보기에서는 사용하지 않는다.

## 중요한 범위

**이번은 원본의 흰 배경을 유지하는 동작 PoC다.** 투명 배경, 독립 귀·앞발, 큰 고개 회전/새 시점, 완성된 분리 리깅은 아니다. 원본 한 칸의 해상도도 313×313 그대로다. 움직임을 붙였다는 이유로 이 한계를 숨기거나 대형 화면용 고해상도 자산 완성으로 보고하지 않는다.

사용자 실제 청취·한국어 정렬 경계 승인, 물리 iPhone 발열/배터리/화면 잠금/Bluetooth 지연은 남아 있다. 기존 저장 MP3만 재사용한다. 운영 페이지 연결·병합·배포는 없다.

## 검증

단위 검사는 중립 좌표의 정확한 일치, 얼굴 기준점 사이 거리 유지, 동작 극단값 조합에서 목·꼬리 격자가 뒤집히거나 과도하게 압축되지 않는지를 확인한다. 브라우저에서는 승인 정지 21조합의 픽셀 일치, 거의 중립인 동작의 밝은 격자 경계 유무, 움직이는 눈·입 21조합, 네 몸짓의 시작/중간/종료를 비교하고 실제 Canvas 프레임 영상을 만든다. 자동 테스트와 직접 시각 검수를 구분해 최종 결과를 추가한다.

```sh
node scripts/yeoni-cat-review/pack-motion.mjs
node scripts/yeoni-cat-review/check-motion.mjs
YEONI_BROWSER=webkit node scripts/yeoni-cat-review/check-motion.mjs
```

현재 기존 기능 PoC **5/16단계(1~4·6)**. 이번은 해당 고양이 PoC의 원본 보존 보완으로 단계 수를 늘리지 않는다. 인간형 PHASE 7의 원본 보존 자산 준비, PHASE 5 사용자 청취는 진행 중이다. 다음 개발 항목은 인간형 A안 원본 보존 자산·기본 동작 준비다.
