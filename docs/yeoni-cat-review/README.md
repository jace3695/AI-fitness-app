# 고양이 연이 — 공식 원본 재대조 및 외형 수정 v2

2026-09-30. 인간형 v3 외형을 사용자가 확인한 뒤, 다음 단계 전에 고양이도 원본과 비교하고 필요한 부분을 수정해 다시 보여 달라고 요청했다. 인간형 PHASE 8로 넘어가지 않고 이번 검수를 진행했다.

## 기준과 발견한 문제

공식 원본은 `public/yeoni-cat-sprite-v1.webp`의 4×4 시트다. 첫 칸 `[0,0,313,313]`을 중립 기준으로 사용한다. 이전에 생성한 `poc-atlas-v1.png`와 `poc-speech-atlas-v1.png`는 원본이 아니다.

- 원본의 세로로 둥근 눈이 기존 Canvas 합성에서 가로로 눌렸다. 감정별 눈 높이 축소는 눈꺼풀 대신 홍채와 하이라이트 전체를 찌그러뜨렸다.
- 새로 생성한 머리·앞발·별의 형태와 몸 비율이 원본에서 바뀌었다. 꼬리도 원본보다 몸 바깥으로 떨어져 보였다.
- 원형 벡터 입과 단일 미소/아쉬움 선이 원래 코 아래의 고양이 입선과 조화롭지 못했다.
- 기존 12감정 모음, 립싱크 입 6종, 인사·갸웃 정지 증거와 7초 대기 영상의 1초 간격 프레임을 다시 확인했다. 종전 기능 검사 통과는 위 외형 문제를 검출하지 못했다. 이 자료를 외형 승인 근거로 사용하지 않는다.

## 이번 수정

`public/yeoni/cat/reference-v2/base.png`는 공식 원본 첫 칸을 손실 없이 자른 이미지다. 다시 그리거나 배경을 지우지 않았다. 머리·귀·코·볼·수염·몸·발·목걸이·꼬리를 기본 이미지에 그대로 둔다. 뜬 눈과 기본/닫힌 입에는 대체 파츠를 얹지 않는다.

- 반쯤 감은 눈과 눈웃음은 **같은 공식 시트** 2·3번째 칸에서 해당 눈만 가져온다. 홍채 전체를 납작하게 변형하지 않는다.
- 아·이·우·에·오·작게 열기는 공식 첫 칸을 입력으로 한 내장 이미지 편집 결과에서 작은 입 영역만 사용한다. 첫 ‘이’ 후보는 닫힌 입과 구분되지 않아 폐기하고 재편집했다.
- 입 영역 `[129,163,51,36]`, 눈 영역 `[85,126,50,48]`/`[175,126,50,48]`에만 적용한다. 가장자리 2px는 원본 그대로 남기고 안쪽으로 부드럽게 합성한다.
- 생성 이미지의 나머지 얼굴·몸은 사용하지 않는다. 편집 프롬프트, 생성 원본 해시, 잘라낸 자산 해시와 좌표는 `manifest.json`에 기록했다. 원본의 낮은 해상도 자체가 개선된 것으로 보고하지 않는다.

## 확인 화면과 검증 범위

[원본·수정본 비교](Yeoni_Cat_Reference_Preview.html). 기본 모습, 얼굴 확대, 같은 좌표 원본 겹침, 눈 3종 × 입 7종을 확인한다. 스크립트 없이도 선택할 수 있으며 초기 상태는 원본과 동일하다.

원본 첫 칸과 기준 PNG의 복호화 픽셀이 일치함을 확인했다. 정지 합성 21조합의 전체 모습을 원본과 비교해 눈·입 잔상, 붙임 경계, 코와 입의 연결, 이/에 및 우/오의 구분을 직접 검수했다. 실제 Chromium/WebKit 결과는 후속 증거 기록에 추가한다.

**이번 수정본은 정지 외형 비교 자산이며, 기존 Canvas 동작 렌더러 교체나 새 동작 리깅 완료를 뜻하지 않는다.** 원본의 흰 배경을 보존하므로 투명 분리 자산으로 가장하지 않는다. 기존 머리·꼬리 분리 자산과 왜곡된 눈 표현은 최종 외형으로 채택하지 않으며, 이 원본 기준을 보존하는 분리·동작 보완이 다음 작업이다. 사용자에게는 이 범위를 명시하고 검수한 정지 비교본을 제시한다.

인간형 v3 **정지 외형 사용자 확인 완료**. 인간형 PHASE 7의 분리 자산 준비와 PHASE 5 실제 청취는 남아 있다. 기존 기능 PoC의 5/16단계(1~4·6) 구현 기록은 유지하되, 고양이 외형/동작 자산 보완이 추가로 필요하다. 이번 외형 검수로 완료 단계 수를 늘리지 않는다. 운영 병합·배포·새 TTS 생성은 없다.

## 재현

node scripts/yeoni-cat-review/export.mjs
node scripts/yeoni-cat-review/check.mjs
YEONI_BROWSER=webkit node scripts/yeoni-cat-review/check.mjs
