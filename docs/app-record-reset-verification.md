# 앱별 기록 초기화 및 일본어 실사용 검증

작업일: 2026-09-06. PR #186의 일본어 개선에 사용자 추가 요청을 반영했다.

## 삭제 범위

| 앱 | 삭제 | 유지 |
|---|---|---|
| 운동 | 운동·세트·철봉 진도, 체중·체성분, 컨디션·메모, AI 분석·선택 이력 | 운동표·설정·체중 목표·알림, 식단 |
| 식단 | 식사·단백질·물·공복, 외식·증상 기록 | 식단 설정·시작일, 운동·체중 |
| 일본어 | 가나·수업 진도·점수·초안, 오답·복습·달력, 저장 단어·문장 | 교재와 학습·음성·캐릭터 설정 |
| 자기계발 | 루틴 실행·타자·손글씨 연습 기록, 주간 코칭 | 루틴·목표, 자료함 파일·작품, 운동·일본어 원본 |
| AI 연이 | 대화·기억·할 일·대기·프로젝트·앱 등록 일정 | Google 원본 일정·연결, 알림, 타 앱, AI 요금·한도 |
| 가계부 | 전체 기간 지출·수입·저축 | 예산·반복지출·통화·보안 설정 |

통합 달력에는 별도 원본 기록이 없어 각 앱 설정으로 연결한다. 통합 설정에서도 모든 앱의 기록 관리에 접근할 수 있다. 로그인·비밀번호·PIN·생체인증은 초기화 대상에 포함하지 않는다.

## 구현과 보호

- 앱 이름·대상 계정·삭제 및 유지 범위 표시, 확인 체크 및 `초기화` 입력 후 최종 삭제 버튼 활성화.
- 기존 가계부는 비밀번호 재확인 및 최종 확인을 유지한다. 화면에 로드된 배열을 반복 삭제하던 동작을 전체 기간의 DB 트랜잭션으로 교체했다.
- `reset_my_app_records`는 `auth.uid()`에서 대상을 결정하고 SECURITY INVOKER로 RLS를 적용한다. 사용자 ID를 입력받지 않는다. 공개·비로그인 실행을 금지한다.
- 각 앱의 테이블과 JSON 키를 명시한다. 다른 앱·설정 키를 전체 접두사 삭제하지 않는다. 일부 삭제 실패 시 전체 DB 작업을 롤백한다.
- 요청 UUID를 재사용해 응답 유실 후 같은 작업을 재확인할 때 다시 삭제하지 않는다. 계정 전환 전후 사용자 ID를 검증한다.
- 초기화 세대 정보를 동기화 병합에 반영해 이전 기기 기록이 자동 복원되지 않게 한다. 자기계발의 이전 완료 백업 자동 이전도 중단한다. 같은 기기의 다른 탭은 새로고침한다.
- 사용자가 직접 선택하는 백업 복원은 현재 초기화 세대를 유지한 새 복원 작업으로 처리한다.
- 다른 기기·탭에서 진행 중인 입력과 분석은 끝낸 뒤 초기화하도록 안내한다. 브라우저를 오래 열어 둔 이전 배포의 동작까지 보장하는 것은 아니다.

## 확인한 실사용 및 수정

- 프리뷰 실제 로그인 후 새 일본어 홈·캐릭터 확인.
- 5분/처음 배워요 선택 → あいうえお → 오답 안내 → 재선택 → 묶음 저장 성공.
- 새로고침 후 다음 가나 묶음(か 행)으로 이어지는 것을 확인.
- 인사말 수업의 표현 → 문장 → 대화 → 한 문제씩 화면 진입 및 오답 안내 확인.
- 첫 글자 듣기 실패를 실제로 발견했다. Vercel 로그에서 `POST /api/language/tts 401` 확인. 인증 토큰을 보내는 기존 `authenticatedFetch`로 수정하고 인증 전달 회귀 테스트를 추가했다.

## 자동 검증·DB 확인

- 143개 테스트·ESLint 통과. 운영 빌드에서 타입 검사와 45개 정적 페이지 생성 성공.
- 신규 검증은 앱별 삭제 범위 분리, 초기화 전후 두 기기 병합, 초안 부활 방지, 명시적 백업 복원, 로그인 저장값 보존 및 음성 인증 전달을 포함한다.
- 원격 Supabase 마이그레이션 `20260906141943_add_app_record_resets` 설치 성공. 함수 설치 자체로 기존 기록을 삭제하지 않았다.
- 함수 권한 조회 결과 SECURITY INVOKER, 빈 search_path, anon 실행 금지, authenticated 실행 허용을 확인했다.
- 보안 Advisor에서 이번 변경에 대한 새 RLS 경고는 없었다. 기존 [유출 비밀번호 보호 미활성 경고](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)는 별도 계정 보안 설정이며 이번 범위에서 변경하지 않았다.
- CLI 설치 경로의 네트워크 승인 취소 이후 다시 설치하지 않았다. 연결된 Supabase의 마이그레이션 기능으로 설치했고, 서버가 반환한 버전 번호로 SQL 파일을 기록했다.

## 아직 완료하지 않은 실제 검증

수정된 프리뷰의 음성 성공, 수업 완료·점수·복습·초안 복원, 작은 화면·확대, 각 초기화 화면의 확인/취소와 실제 삭제 후 재조회·타 앱 보존 검증이 남아 있다. 자동 테스트와 DB 함수 설치를 실제 삭제 검증으로 대체하지 않는다.

실제 삭제는 해당 계정·앱·삭제 범위를 사용자가 확인한 뒤에만 실행한다. 현재까지 이 기능으로 개인 기록을 초기화하지 않았다. 핵심 실사용 검증이 통과하기 전에는 PR을 병합하거나 운영 프런트엔드를 배포하지 않는다.
