# 최근 운동·식사 시각 조회 검증

## 범위
- 어제까지 최근 28일에 직접 저장한 운동 시작·종료 시각을 날짜 역순으로 조회한다.
- 같은 날짜의 저장된 마지막 식사 시각과 간격을 표시한다. 미저장 입력은 제외한다.
- 기록·미기록 일수, 마지막 식사 시각 누락을 구분한다. 기록 없는 날을 휴식으로 판단하거나 식사·운동 효과를 추정하지 않는다.
- 목록을 펼칠 때만 현재 계정의 기간 내 기록을 읽는다. 조회 실패를 기록 없음으로 표시하지 않으며 다시 불러오기를 제공한다.
- DB 스키마·권한 변경 없이 기존 `workout_actual_times`를 조회한다. 운영 배포와 실제 iPhone 검증은 마지막 단계로 유지한다.

## 로컬 검증
- 단위·DB 585/585, 타입 검사, 린트 통과.
- 윤년·연도 경계의 28일 범위, 잘못된 날짜·타 계정·중복·기간 외 기록 거부, 식사 시각 미기록과 간격 계산, 입력 불변성을 검사했다.
- 브라우저 검사에 320px 화면, 새로고침, 미저장 입력 제외, 조회 오류·빈 목록 구분, 다른 계정 기록 제외, 다시 불러오기를 추가했다.
