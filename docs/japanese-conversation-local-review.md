기준 커밋: `d58558255f7e9ceb273b254b874b601af826a050`

이번 변경은 로컬 작업이며 커밋·push·운영 병합·배포하지 않았다. 기존 인바디 릴리스 manifest에 포함된 15개 파일은 SHA-256이 모두 일치한다.

## 구현

- 기존 카페·여행·일상·업무·친구 상황에 두 가지 선택형 답과 마무리, 다시 연습을 추가했다.
- 자유 생성 대화, 자동 교정, 발음 채점이나 자동 학습 완료를 제공한다고 표시하지 않는다. 여행 소요 시간과 업무 연락 시간은 가상 연습용임을 명시했다.
- 직접 고른 예문만 기존 `savedSentences`에 저장한다. 기존 항목을 보존하고 같은 일본어·뜻·분류의 중복 추가를 막는다. 카페는 기존 복습 분류인 일상에 매핑하며 메모에 원래 상황을 남긴다.
- 예문 불일치는 오답으로 판단하거나 `wrongSentences`에 기록하지 않는다.
- 저장 직전 사용자와 로컬 기록 소유자를 확인한다. 계정 전환 후 늦게 끝난 확인 결과는 저장하지 않는다. 계정 변경 시 재진입 안내를 표시한다.
- 듣기는 무료 모드의 기존 기기 음성을 사용한다. 상황 변경, 초기화, 다른 선택, 복습 이동, 뒤로 가기, 숨김, pagehide, 컴포넌트 해제에서 취소한다. 지연 결과에 의한 재생 재개를 차단한다.
- 반복 저장 클릭 중 알림의 등장으로 버튼이 움직이는 문제를 발견해 알림 공간을 확보했다.

## 검증 범위

- 전체 단위 검사: 894개 통과(이번 추가 8개 포함). 첫 제한 환경 실행은 localhost EACCES로 5개 실패했고, 허용된 실행 환경에서 전체 재실행하여 894/894 통과했다.
- 타입 검사 및 전체 린트: 통과. 최종 소스의 프로덕션 빌드도 통과했다(서비스 자격 증명을 빌드 환경에 전달하지 않음).
- 로컬 브라우저: Edge, 실제 회화·복습 React 페이지와 기존 음성 유틸리티에 합성 인증·저장소·SpeechSynthesis를 연결했다. 외부 요청은 차단하며 외부 요청 시도와 페이지 오류는 0건이다.

## 미검증 및 제한

실제 테스트 계정의 Auth/DB/RLS와 LanguageCloudSync 서버 왕복은 실행하지 않았다. 합성 저장소 전환 검사는 실제 클라우드 동기화 검증을 대신하지 않는다. 실제 기기 음성 청취, WebKit, 물리 모바일·일본어 IME 검증도 미실행이다. 네트워크 장애와 실제 계정 동기화를 포함한 실사용 승인은 별도다.

유료 음성·AI 호출, 외부 건강정보 전송, 새 서비스 생성, 보안 설정 및 DB 스키마 변경은 하지 않았다.
