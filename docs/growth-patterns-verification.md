# 루틴 요일별 실행 패턴 — 2026-09-17

7단계 개인화의 첫 후속 범위다. 자기계발 → 주간 코칭에서 루틴을 고르고, 어제까지 28일의 평일·주말 완료/진행/중단 기록과 요일별 근거를 본다. 현재 사용 중인 루틴만 표시하며, 그림 연습은 기존 제외 조건을 유지한다.

## 계산과 안내

- 기록일을 기준으로 집계한다. 기록 없는 날은 실패가 아니며 과거 예정일·성공률을 현재 일정에서 추정하지 않는다. 오늘·미래·범위 밖·잘못된 날짜는 제외한다.
- 같은 날짜의 여러 세션은 하루이며 완료 > 진행 > 중단 순으로 표시한다. 시간 미기록 세션도 완료 사실로 집계한다. 다른 루틴의 기록은 합산하지 않는다.
- 평일 4일·주말 3일 이상의 서로 다른 기록일이 있어야 비교 안내를 한다. 기록일 중 완료 비율 차이가 25%p 이상이면 더 높은 쪽의 일정 검토를 제안한다. 요일이 차이의 원인이라고 단정하지 않는다. 그 미만은 현재 일정 유지 안내다.
- 제안은 자동 적용하지 않는다. ‘루틴 일정 확인하기’로 자기계발 홈에 이동해 기존 ‘루틴 편집’에서 사용자가 검토한다. 새 기능의 조회·선택·표 펼치기는 서버 기록을 변경하지 않는다.
- 조회 실패는 빈 기록과 구분하고 다시 불러오기 버튼을 제공한다. 조회된 세션이 1,000건 이상이면 서버 기본 조회 한도로 전체 기간을 확인할 수 없어 분석을 차단한다. 대량 이력 페이지 처리는 후속이다.
- 기존 주간 코칭 생성/확인 적용 흐름은 유지한다. DB 마이그레이션·신규 API·추가 AI/TTS 호출은 없다.
