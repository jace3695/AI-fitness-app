# 연이 공통 디자인과 실사용 검증 — 2026-09-07

## 검토 결과와 변경

첨부된 약 40.5초 화면 영상과 로그인된 실제 앱을 비교했다. 앱마다 배경·강조색·카드·글꼴이 달라 같은 캐릭터가 별도 위젯처럼 보였고, 가계부의 전역 CSS가 다른 앱으로 이동한 뒤에도 배경과 글꼴에 영향을 주는 문제를 확인했다.

- 연이의 보라색에 맞춰 공통 배경 `#f5f4fa`, 흰 카드, 강조색 `#6554b8`, 말풍선 `#f0ecfb`, 제목색 `#302a46`를 연결했다. 운동·식단·자기계발 요약 카드도 같은 보라색 계열을 사용한다. 수입·지출·성공·오류의 의미 색상은 유지한다.
- 헤더, 하단 메뉴, 카드 모서리, 주요 여백과 TOP 버튼을 통일했다. 일본어의 학습 버튼과 안내 카드도 같은 팔레트를 사용한다.
- 홈의 중첩 안내 카드를 줄이고 캐릭터 이미지의 흰 배경이 카드와 자연스럽게 이어지게 했다. 작은 화면에서는 한글 단어가 불필요하게 쪼개지지 않도록 조정했다.
- 가계부 CSS를 앱 경계 안에 제한해 앱 이동 후 배경·글꼴이 바뀌는 누출을 수정했다.
- 320px에서 확인한 가계부 월 입력칸, 홈 로그아웃 줄바꿈, 하단 전체 메뉴 글자 크기, 자기계발 주요 버튼 배치를 보완했다.
- 고정 메뉴와 식단 카드의 배경 흐림 효과를 제거했다. 새 이미지·반복 JavaScript 타이머·라이브러리는 추가하지 않았다.
